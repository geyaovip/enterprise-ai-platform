# 企业 AI 应用平台

项目工作名：**企业 AI 应用平台**（`enterprise-ai-platform`）。

已确认的建设顺序：

1. 建设供多个业务应用共用的平台能力。
2. 先接入现有 ERP，供真实客户在共享云服务中试用；架构同时考虑未来的客户专属部署。
3. 再接入现有 CRM、MES。三套应用在新平台中稳定运行并完成验收后，才考虑移除旧项目。
4. 后续开发建筑行业应用。

[`enterprise_ai_platform_v0.1_codex_spec.md`](enterprise_ai_platform_v0.1_codex_spec.md) 是原始规划草案。草案中的“建筑应用先行”及里程碑顺序尚未按上述决策更新，因此目前不能直接作为实施指令。新平台尚未开始编码。

开发前文档从 [文档索引与决策记录](docs/00-文档索引与决策记录.md) 开始阅读；按功能、架构、UI、路由、开发、运维和迁移任务进入对应文档。文档描述目标和验收条件，尚未表示新平台功能已交付。

[总体架构](docs/03-架构与数据安全.md)先定义平台通用能力与独立应用边界；[应用接入契约](docs/10-应用接入契约.md)说明 ERP、CRM、MES 及未来应用如何复用平台。目标是统一公共能力和用户体验，而非合并旧系统的业务数据库。

[领域边界与协作契约](docs/12-领域边界与协作契约.md)进一步明确各应用的数据所有者、关键业务规则与跨应用映射；先以 ERP 的采购确认、分批入库及库存/应付切片验证。AI 聊天和业务页面使用相同的应用命令。
