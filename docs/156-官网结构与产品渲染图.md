## 渲染图

使用内置 ImageGen 分别生成六张图，并转换为 WebP。共同设计要求为紫白摄影棚、半透明紫色玻璃、瓷白材质、柔光和居中留白。以 AnswerBit 首屏截图作为氛围参考，产品素材独立构图。所有渲染图均为概念示意，画面无后台界面、可读文字或业绩数字。

| 文件 | 画面 |
| --- | --- |
| `platform-ark-render.webp` | 玻璃方舟连接资料、数据与确认结果 |
| `platform-erp-render.webp` | 库存货箱、阶梯刻度和采购单 |
| `platform-crm-render.webp` | 两张客户卡片归入同一回访组 |
| `platform-mes-render.webp` | 拆解零件、物料清单和待核对提示 |
| `platform-geo-render.webp` | 放大模型回答中的品牌提及与引用 |
| `platform-content-render.webp` | 同一瓶装产品的两种光线与参考构图 |

素材路径为 `apps/web/public/marketing/`。主视觉为 1536×1024，应用图为 1200×800，合计约 169 KiB。应用、数字员工和场景栏目的业务说明使用 HTML 文案，渲染图支持放大和键盘关闭。
