## 实现和结果

- 对合并格中已有多个件号/序号线索的内容做有界补读。双语/英文识别只合并原图数字基线，按坐标拆行，保留重复序号，不填顺序号或推断隐藏件。轻微弯斜边框采用有限容差，表头边缘标点剥离后仍按别名精确匹配。
- 拆出的数量未经专用数量校验时只保留候选，不自动采用；多型号数量列仍需明确型号。没有降低置信阈值、取消核对、复制历史数量或自动匹配企业物料。
- 相机JPEG/MPO仅读取首帧，保持1200万像素上限；超过Pillow上限也映射为IMAGE_TOO_LARGE，警告不污染接口错误码。第二帧明细不混入第一帧。未增加任意MPO扩展名上传、全帧展开或自动缩图。
- 69个输入来自56个去重原始文件，摘要全部校验。清晰NASA装配图12份新增84行＋3份历史45行均精确对应序号/身份列/数量。5页扫描的166条印刷件号72→127（43.4%→76.5%），不是采购BOM准确率；其余8页扫描只诊断、不报告准确率，空白页单列。28张产品/PCB/示意图、12份NIST与空白页共41个负例/限制控制未生成BOM，其中2个像素限制和1个页数限制明确拒绝。
- 第一轮2扫描页＋3装配图在冻结后检查；扫描第18页仍失败，第二轮进入回归修复。最终结果不得继续称盲测，原中间证据保留。
- 28旧受控变体/320条严格整行仍228，清晰机械两路径70/70，电子5项目6文件229条八字段全部对应；新增MPO首帧/二帧隔离、3次像素限制的Service验证通过。API构建通过，无新增UI改动，因此未重复浏览器全流程；D-109原图复核和事实快照浏览器证据仍单列历史。

## 可复跑资料

源码入口：`tools/bom-corpus-regression.py`、`tools/fixtures/bom-expanded-20261028.json`、`apps/api/tests/bom-camera.cjs`。实际主批次用该回放工具执行。每次运行使用新结果目录，校验原件摘要，冻结解析器和辅助文件，最多2并行、125秒外层兜底；底层仍是115秒期限/110秒CPU/768MiB地址空间。不存在自动付费、网络重试或模型补读。

```sh
python3 tools/bom-corpus-regression.py \
  --suite tools/fixtures/bom-expanded-20261028.json \
  --inputs test-corpus/public-bom/derived/D110/inputs \
  --results var/operations/bom-replay-new \
  --python /absolute/path/to/offline-python-wrapper
```

Python运行环境需要现有Pillow/OpenCV/Tesseract/Poppler等解析依赖；本轮固定工具镜像`local-bom-review-python:20261028-complete`，镜像摘要和依赖版本见`environment.json`。需隔离运行，不能把生产API/数据库用作测试环境。`--evaluate-only`仅从已保留结果计算指标，`--compare /path/evaluation.json`遇已评分样本件号/整行回退、错量增加或协议回退时非零退出；未标注诊断页没有准确率门槛。

本地/云端公开资料库新增`labels/D110/`和`derived/D110/inputs/`，69主批次＋3派生相机控制共72输入，原件用相对链接复用CAS；标注、基线、最终结果、回归和报告一并保留。它们是测试资料，不是客户BOM长期附件功能。跨资料人工经验卡仍未实现；历史同源物料参考沿D-109。
