当前收尾口径按 [D-022](00-文档索引与决策记录.md#当前开发收尾口径d-022)：知识链采用内置引擎，RAGFlow Cloud 与生产定时备份暂缓；真实客户场景由用户后续专门测试。下方客户准入清单继续用于后续测试，尚未测试的项目不因此标为通过。本轮先完成可复核的工程实现与验证。

ERP、CRM、MES 在统一新项目中从零开发。旧应用是功能与规则参考，不是要迁入新项目的后端或数据库。新系统经真实客户试用及验收前，旧项目、数据、备份和线上实例继续保留；任何下线或删除另行决定。

## 客户数据开通

首个 ERP 客户可能从新租户空库开始，也可能需要导入现有业务数据；具体情况见 [Q-002](00-文档索引与决策记录.md#待确认的决策)，不能预设旧三套系统的数据一定是目标来源。

1. **空库开通**：创建企业、首位管理员、权限和 ERP 启用状态；录入或导入经客户确认的主数据，验证备份与恢复。
2. **确需导入时**：先盘点来源系统、客户授权、字段、ID、数据量、文件和历史状态；形成新模型到来源数据的显式映射，不直接复制旧表。
3. **试导入**：在隔离环境用脱敏或经授权的数据重复运行，核对记录数、金额、数量、库存余额、关联及审计来源；重复执行不得生成重复对象。
4. **切换与回退**：确认备份、导入日志、客户负责人、切换窗口及可恢复路径；切换后用真实账号验证关键读写。旧环境保留到观察期及数据可恢复性验证结束。

业务代码开发、数据库迁移和客户数据导入是三件不同的工作。日常数据库 schema 变更遵循统一迁移链与备份要求；客户数据导入只在真实需求明确后编写专属映射。

## CRM、MES 与建筑应用

CRM 按统一架构新建线索、客户关系、商机、跟进和服务流程；与 ERP 客户/商机需要协作时，先按 [Q-003](00-文档索引与决策记录.md#待确认的决策) 确定引用、关联或共享提升。MES 新建物料、BOM、计划、工单和报工流程；与 ERP 商品需要协作时，先按 Q-004 确定关系。两者各自需要真实流程、权限、租户隔离、AI 和运维验收。建筑应用在三套新应用稳定后另立需求与首客试用计划，共享行业能力按 [14 准入规则](14-共享能力准入与模块公开契约.md) 评审。
