## 范围与所有权

知识领域继续持有空间、文档原件、版本、访问授权和稳定引用；新增 `native` 适配器复用 PostgreSQL/Worker，以 pgvector 计算向量相似度。RAGFlow 适配器保留；Cloud 套餐未升级，仍待真实接入；AnythingLLM 本次不实现。

轻量版支持 UTF-8 TXT/Markdown/CSV、PDF、DOCX、XLSX；D-021 增强版加入 PNG/JPEG 与扫描 PDF OCR、混合检索和结构分块（发布状态见 [32](32-轻量知识库检索与识别增强.md)）。PDF 通过 Poppler 提取文字，DOCX/XLSX 用受限 Python 标准库解析；旧版 DOC/XLS 仍需转换。限制单文件 8 MiB、解压总大小 32 MiB、抽取文本 180000 字、分块 256 个、处理时限，避免大文档阻塞业务。

## 配置与客户选择

运营管理员配置每企业的内置/RAGFlow 接入档案及加密密钥。内置档案的地址是嵌入模型 API 地址，支持方舟 multimodal 和 OpenAI embeddings 格式；端点遵守服务端允许名单，不能用聊天模型冒充嵌入模型。企业管理员在预先配置的档案中选择；成员只查看当前状态并使用统一文档界面。模型调用会向所选供应商发送需嵌入的文字，设置页明确说明。

选择新引擎先创建候选代次、从平台原件重建索引，当前引擎继续服务；候选全部当前有效文档成功后，以版本校验事务启用。失败、撤销交付或候选配置被修改时停止切换，原引擎继续服务。切换期间新增/更新原件进入候选最新版本检查。支持取消及按上次成功切换的旧配置重建回退。对尚未配置的引擎显示待配置。

## 关键不变量

- 检索 SQL 在向量计算前限定企业、引擎代次及明确授权的原文版本；结果返回后仍重新检查文档/权限/当前引擎。
- 嵌入维度、模型、协议与配置代次不能混用；方舟现选模型为 2048 维，使用 pgvector `halfvec` 计算，避免 2000 维 vector 索引约束。本版授权范围内精确检索，不启用全库 ANN 导致授权结果被截断。
- 引用保留原文定位与版本，重新索引同一片段保留稳定 ID；新引擎分块方法不同则生成新引用，历史可访问引用仍关联平台原版本。
- 只有全部分块成功才提交可用索引；失败不暴露部分结果。禁止跨企业 dataset/source ID 查询与删除。
- 删除文档清理所有引擎代次的索引及原件；引擎切换不删除平台原件、权限或引用身份。

## 迁移与部署

新增轻量索引表、引擎档案与切换记录；关系表迁移不强制安装扩展，旧 RAGFlow 环境仍可运行。启用内置引擎前须安装 pgvector 0.8.1（本机 QA 镜像 pgvector/pgvector:0.8.1-pg17-bookworm），执行 `CREATE EXTENSION IF NOT EXISTS vector`，并验证模型。现有生产 PostgreSQL 为 Alpine，不能直接将数据卷挂到 Debian 镜像；先一致备份，恢复到独立 pgvector 实例验证，再按发布流程切换与保留回退实例。

不增加 Elasticsearch、Redis、独立向量数据库或常驻本地大模型。PDF/Office 解析按任务启动，Worker 限制处理并发；实际资源用样本实测，不将预算当作容量承诺。
