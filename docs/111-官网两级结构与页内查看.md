# 官网两级结构与页内查看

日期：2026-10-29；决定：D-111。用户要求“最多二级页面”，避免从目录连续跳转岗位、工作和示例。本批已发布，**首页计为一级，五个栏目页计为二级**；覆盖D-108的22页层级方案。

## 最终结构与行为

| 规范路径 | 本页完成的内容 |
| --- | --- |
| `/` | 概览；一步进入具体员工、工作、应用或其他栏目 |
| `/employees` | 三位员工原地切换；职责、三项工作展开、交付、确认和示例 |
| `/solutions` | 九项工作原地切换；完整资料、步骤、结果、确认及适用示例 |
| `/products` | ERP/CRM/MES原地切换；功能、流程、界面图、示例 |
| `/knowledge` | 企业资料查询、引用和访问边界 |
| `/contact` | 邮箱联系及落地方式 |

不只是缩短URL：原目录卡片和单独详情已合并，内容面板内除实际使用的/login外，没有要求继续进入其他页面的链接。工作流程通过原生details展开，员工/应用/工作通过可访问tabs切换，示例就地展示。首页的具体入口携带片段直接选择内容，不需要先进入列表再找详情。

切换仅更改当前URL片段并保留刷新/分享能力；键盘支持方向键、Home/End和单一Tab入口。原地看示例、功能图放大及Esc/焦点恢复保留。隐藏面板退出可访问树，必要的来源、数量待确认和人员办理边界仍在HTML内。

16条旧岗位/工作/产品详情与示例路径，包括尾斜杠和index.html形式，统一308到对应栏目与片段；查询来源保留，旧示例参数选择正确岗位。旧首页和产品片段继续兼容。未知旧路径保持404，sitemap只列6个栏目/首页路径。
