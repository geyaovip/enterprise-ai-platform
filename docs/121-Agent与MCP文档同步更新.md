## MES核对经验如何进入Skill

`ark-mes-bom-review`保留简短方法，仅在图纸转录、多机型、电子/线束明细或历史件匹配时加载`references/source-review.md`。该参考由构建源`integrations/workbuddy/references/bom-source-review.md`复制到正式专家和客户端调试包中；不另行增加Skill数量或市场投稿。

具体补齐：

- 原生单元格和可靠PDF文字层优先，先确认表格角色/列映射；解析0行不等于没有BOM，标题栏不当零件明细。
- 分开机械身份字段、电子编码/MPN/位号/DNP、线束导线/端子/连接器；不根据照片、形状、原理图或布局清点推断完整采购BOM。
- 数量、单位、机型、版本、每父数量及父子依据分别保留。空白、横杠、0和未知不互换，缺数量不补1；没有明确关系不跨层展开。
- 全部视觉候选逐行对原件，保留来源、原值、候选值、修改原因及核对状态，支持人工补漏。字段变化后重新确认，草稿不等于发布或可采购。
- 历史同源/已发布BOM只作为当前企业候选与差异参考，不覆盖本图原字串/未知数量，不承诺自动学习或跨客户共享。
- 平台GLM/Kimi沿用D-119实际分流和每页最多两次；异常/未知用量停止、不自动重试。不把整份长Skill追加到业务提示，不因页面刷新重新创建识别。

核查交付模板增加文件/页/表/行、原始身份、候选物料、原数量/单位、机型/装配状态、父子依据、问题/修改原因与人工核对状态。规则来源是已观察的问题及现有系统约束；本次未再次进行真实模型A/B，不声称仅更新文字就提高了准确率。

## MCP、网页与模型额度

当前MCP调用授权业务Service和确定性计算，不调用应用内聊天模型，不扣网页默认每账号累计3次试用。网页额度用完不使合法MCP授权失效；WorkBuddy自身的模型费用和次数限制另行适用。

网页企业自定义聊天按保存型号使用，不受累计/月度AI次数限制，但权限、订阅、计量及非AI任务约束保留。这个规则不解除BOM视觉任务用量保护，也不授予MCP读取/配置模型密钥的能力。

MES的图纸上传、GLM/Kimi后台识别、来源图复核、人工补行和BOM草稿写入/发布目前通过网页提供。当前7个MCP工具没有这些入口，也无通用知识检索或历史纠错入库工具。Agent会引导用户到当前企业MES→BOM→新建BOM完成，而不编造工具、任务回执或代调网页Cookie接口。发布后再用现有MCP读取BOM并预览需求。
