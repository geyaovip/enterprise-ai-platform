## 检查结论与本轮修改

| 模块 | 确认的问题或缺口 | 本轮结果 |
| --- | --- | --- |
| 三端通知 | 已读与未读混排；无法批量处理；前端依赖业务应用列表，全部应用停用时可能隐藏仍有权查看的管理通知 | 增加未读筛选、全部标为已读，三端共用。批量标记只覆盖打开列表时的时间范围，保留之后到达的通知；仍按当前成员、企业、应用和 BOM 权限过滤。读取统一通知不再依赖前端额外判断 ERP 是否启用。 |
| 业务任务中心 | 无标题或状态筛选；选中任务离开当前列表后详情可能停止追踪；读取失败时容易表现为没有任务 | 服务端先筛选再分页，浏览器 URL 保留搜索条件；详情独立追踪活动任务，读取失败显示重新加载。重试和取消保留版本、幂等及后果确认。 |
| 任务撤权恢复 | 任务失去应用授权后只能看到遮盖标题，详情无法打开，无法从页面取消后续执行 | 增加受限任务取消入口；标题查询仅匹配当前有权读取的命令范围，避免通过搜索猜测被遮盖的历史标题。仍不能读取受限任务输入和结果。 |
| AI 分析与识别任务 | 停止执行没有完整忙碌和错误恢复；服务端可能把已完成或失败的任务改为取消 | 增加停止确认、同步提交锁、错误反馈和状态回查。服务端仅允许停止 queued/running，终态返回 409，不覆写结果；详情追踪不再依赖列表是否含活动任务。 |
| 知识文档管理 | 只能翻页找文档；归档后不便查找；更换条件时可能闪现空结果 | 增加按文档标题查找及全部/使用中/已归档筛选，服务端先过滤后分页。保留空间 ACL、版本、原件和归档恢复能力；更换条件时显示加载状态，末页无记录时返回有效页。列表查找不调用知识模型。 |
| ERP、CRM、MES、品牌内容 | 对既有核心闭环进行业务回归 | 检查采购/销售/库存/账款、客户导入与运营、生产与 BOM、画布及图片/视频任务。覆盖结果见下表，未因“完整”新增与当前场景无关的业务模块。 |
| 企业管理、平台运营 | 核对应用/服务状态和公共通知的消费方式 | 真实浏览器检查企业配置入口、三种企业模型配置状态及三端通知。没有把隔离环境的未配置状态冒充服务可用。 |

新增实现复用现有 Prisma、Service、通知贡献者、DataResult、ChoiceSelect、Pager、ConfirmDialog 和业务任务机制，无新增数据库迁移，也没有另建一套任务或通知系统。
