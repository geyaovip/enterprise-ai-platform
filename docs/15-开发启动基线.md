## 已确定的架构

| 项目 | 稳定规则 |
| --- | --- |
| 技术栈 | [ADR-001](ADR-001-技术栈决策.md)；Node按.nvmrc/engines，pnpm按packageManager，确切依赖按锁文件 |
| 运行单元 | 一个Monorepo、三个独立React/Vite前端、模块化NestJS API、PostgreSQL和独立Worker |
| 身份与授权 | 共用用户/会话/租户/组织，企业和应用分别交付启用，成员及对象权限由服务端逐请求核对 |
| 业务所有权 | ERP持有交易/库存/账款；CRM持有客户经营领域；跨应用只用公开契约和事务事件 |
| UI | docs/ui为公共规则，packages/frontend为共享实现，应用适配不复制主题/组件/AI布局 |
| AI | 应用Provider/事实/Tool＋平台Runtime/确认/计量/审计；两个管理域只读，不是业务应用 |
| 任务与协作 | 持久状态、版本、幂等、取消/重试与回执；ERP收货/库存/应付仍同事务，跨应用最终一致 |
| 知识/支持 | 原件、版本、ACL和引用由平台拥有；内置引擎为默认，支持访问限范围/限时且可撤销 |
| 共享准入 | 业务对象先归应用，真实第二消费者明确后按14评审；不预建Party或空行业模块 |
