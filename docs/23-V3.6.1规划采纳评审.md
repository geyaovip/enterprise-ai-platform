## 指定实现后的接入条件

1. **OpenClaw**：直接接入，但共享云的互不信任租户不能共用一个 Gateway 信任边界；验收成员会话隔离、撤权、确认、幂等回执、用量、升级和退出路径。已选定不等于可以未经安全验证对客户开放。
2. **RAGFlow 和知识产品**：直接开发并接入；用经授权的文档样本验证解析、检索前权限、引用、删除与重建索引、故障恢复。引擎仅保存派生索引，不成为平台知识权限或业务数据的权威来源。
3. **三个前端**：分别交付员工、租户管理员、平台运营方入口，服务端隔离其权限；共享 API 与设计组件，迁移当前 Web 管理页面时保留可回退路径。

以上均进入第一阶段完成定义，详细清单见 [24](24-首阶段新增能力与验收.md)。客户试用还须通过 [08](08-迁移与上线验收.md) 和 ERP 完整功能矩阵。

## 输入文本中的执行歧义

总体规划同时写有“OpenClaw 为 V1 默认且唯一主基础设施”和“优先 PoC、通过后再决定”，第一阶段方案一处禁止开发 ModelGateway，推荐顺序又列有 ModelGateway；其强制规则还引用了 V3.3 Contract。D-016 已明确供应商和范围，故不再等待比较性 PoC；具体迁移、权限和验收以本目录契约为准。
