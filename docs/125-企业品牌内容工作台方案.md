企业品牌内容工作台作为现有平台内的新业务模块建设，面向营销、电商和销售人员，先完成“商品或产品营销素材包”的生产闭环。核心价值是品牌一致性、批量产出、修改效率和团队管理。

架构采用现有平台，功能按业务需求开发，择优提取开源代码。首版沿用公共 UI 与组件，采用适合创作的预览、素材、对话和多尺寸结果布局；即梦是创作流程与信息层级的主要参考。独立主题后置。

## 本轮设计选择

### 后续确认：模型与测试费用（2026-10-30）

用户指定火山方舟为首批媒体渠道：图片使用 `Doubao-Seedream-4.5`，视频使用 `Doubao-Seedance-1.0-pro-fast`，复用当前已有方舟 Key。供应商型号/API标识、账户权限和能力在接入时核实，不把用户指定型号视为已接通；凭据仅由服务端配置引用，不写入文档、前端或日志。视频型号先确定，交付顺序仍沿首版图文、后续视频。

用户不设置本项目测试总预算上限，同时明确要求节省费用、不要随意测试。实施时先完成离线与替身验证，仅为必要接口联调和效果验收使用少量真实调用；缓存可复用结果，不做无目的模型对比或反复生成，超时/提交结果未知不盲目重发。记录实际及未知用量；这一测试授权不改变企业生产预算、并发与权限规则。本次只同步决定，未发起真实调用。

- 首版先做文案和图片，包含品牌资料、营销产品资料、可编辑版式、局部修改、批次、审核和导出。视频作为下一阶段。
- 主要工作对象是有品牌、产品、版本和交付规格的内容项目。对话用于表达意图与辅助操作，内容版本和业务回执由服务端保存。
- 保持商品、Logo、价格、参数等关键元素可控；生成背景和装饰素材后，通过模板或图层组合输出。
- 默认采用单件预览与多尺寸结果板。无限画布与节点编排不进入首版必需范围。
- 拟用技术标识 `appId=content`，显示名“品牌内容”，路由前缀 `/content`；目前均未注册。

## 接入结论

现有注册器、可信上下文、业务命令、任务与计量为接入基础，但新模块并非只加一个前端路由。`App.tsx`、共享对话及部分导航仍有 ERP/CRM/MES 分支；图片生成、媒体存储、按张计量和供应商异步恢复也尚需建设。具体核对入口与拟扩展点集中在接入文档。

本方案未改变现有应用的 AI 开关、默认开通策略、聊天试用政策或数据归属。首版统一 UI 的决定优先于本次讨论中早先的独立视觉建议；现有其他应用继续遵循公共规范。
