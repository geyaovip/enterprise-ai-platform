# D-145 品牌内容资产与画布发布

2026-11-03 已上线。品牌内容「资产」分为生成历史和画布。搜索和批量操作在顶部，类型、范围、时间和排序独立展示。默认卡片用于预览，进入批量模式后显示选择和可用操作。侧栏保留分开的创作记录和画布，移除创作搜索，「全部」打开资产的画布选项卡。旧画布地址及新建链接继续可用。

本版同时发布图片和视频生成偏好、参考图与视频首帧、画布配置保存及复制、图片裁剪旋转镜像、视频截帧，以及项目素材回用。图片处理沿用 Pillow，取帧和比例选择复用 Toonflow 的 MIT 实现，参考附件沿用 Loomic 的 MIT 组件。新视频流程支持提交后刷新追踪、播放和 MP4 下载。企业模型设置对仍有生成任务的渠道保留变更保护。
