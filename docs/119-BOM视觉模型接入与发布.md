## 2. 处理路径和模型分工

| 场景 | 线上行为 |
| --- | --- |
| XLS/XLSX、CSV/TSV/TXT、受支持PCB6 | 本地单元格/原生结构解析，保留列映射、位号、MPN、装配状态、版本及机型数量列 |
| 有可靠文字层明细表的PDF | 优先原生解析，不为已可读取的表重复支付视觉费用 |
| 清晰图片或无法可靠原生解析的普通PDF页 | GLM：`glm-5-3-flash-260828`，思考开启、low、温度0 |
| 本地检测为密集表、透视/倾斜或低对比页 | 直接Kimi：`kimi-k3-1-pro-261024`，low、温度1，不传thinking |
| GLM结构无效、缺量、行号缺口、机型/位号/数量矛盾等 | Kimi最多复核一次；未用Kimi的完成页也允许用户手动复核一次 |
| Kimi仍存在问题、两模型冲突、没有确认可用明细 | 保留来源与差异，转人工核对/补录，不增加第三次调用 |
| 不希望调用模型 | 明确提供“本地整理（不调用模型）”，继续保留原有本地OCR与解析链路 |

模型只转录图面可见事实，不根据外形猜隐藏件，不自动补数量1，也不把外形/名称相似当成历史同件。多机型数量在用户选型前保持未确定；所有视觉行都要求逐行和装配确认。改变产品、物料、数量、单位或适用机型会使已核对状态失效。

本版按页准备图像，最长边3000像素，没有承诺自动裁出所有小表。复杂整页照片/细小明细应先裁剪并保留表头、首尾行；原图查看支持1/2/4倍放大、区域内滚动和原件下载。模型不提供虚构定位框。

## 4. 本轮真实测试覆盖与结论

共 **11个输入**，含同源PDF/图片、整页/裁剪对照，不能算成11个独立客户样本。9个输入完成，2个因连接/超时没有取得可评价的完整结果。使用D116修正后的标注及D113照片标注；原生结果在业务规范化之后比较，模型结果不做件号模糊修复。

| 类型 | 本轮输入数 | 结果与边界 |
| --- | ---: | --- |
| 中文线束清单图片 | 1 | GLM：15/15行指定字段匹配，包括序号、名称、规格、数量、单位 |
| 中文电子替代料表图片 | 1 | GLM：18/18行指定字段匹配，包括MPN、位号、制造商与数量 |
| 混合数量/单位线束图片 | 1 | GLM：5/5行指定字段匹配，8PCS等数量原文独立保留 |
| 密集电子BOM图片 | 1 | Kimi：49/49行指定字段匹配，包括MPN、位号、数量与装配状态，约170秒 |
| 完整线束PDF | 1 | 原生解析不可用后用Kimi：6/6行指定字段匹配，包括长度；缺失单位不补造，约69秒 |
| 有文字层的线束PDF | 1 | 原生解析5/5行指定字段匹配，0模型调用 |

| 单零件图负例 | 1 | GLM误把标题栏当成1行，Kimi明确返回无BOM；修复合并后复用这两份真实回执回放为0行并转人工，未重复付费 |
| 多机型机械图片 | 1 | 初始Node连接失败，用量未知；没有完整答案，不评价准确率。调整建连方式后用其他不同样本验证，未重发此图 |
| 复杂整页模拟照片 | 1 | Kimi触发300秒上限，端到端约306秒，用量未知，停止且未重试 |
| 同一模拟照片的表体裁剪 | 1 | Kimi：38行读出，身份/数量严格匹配37/38；第15行数量原文7误读为1，必须人审，约107秒 |

照片是受控模拟透视/成像变体，**不是实际纸图手机拍照正例**。裁剪试验是另一输入，不覆盖或清零整页失败记录；37/38也不是完整采购BOM准确率。父子层级、隐含件、全部版本适用性和完整装配关系，本轮没有新的全面验收证据。

沿用的D118原生扩测证据为17份XLSX的858行指定字段、8份PDF和14张图片等；本次没有声称把全部公开资料库重新跑了一遍。新接入链路的代表样本与旧原生大范围回归分开记录。

## 5. 测试发现并修复的问题

1. **负例合并错误**：原合并逻辑在Kimi判定无BOM时会恢复GLM正候选。现在以Kimi有效结果进入待核对区，保留GLM原结果和差异供追溯，不恢复标题栏伪明细。最终编译代码对真实缓存回放为0行，新增对应故障回归。
2. **视觉候选保存失败**：没有几何框时，前端曾带上null框与图幅，触发来源校验。现在没有可信框就不提交这两字段，实际页面已完成采用、改量、复核、保存草稿。
3. **资料版本丢失**：仅填写版本、未填写产品编码时曾丢掉版本元信息，已修复并增加断言。
4. **连接与计量保护**：视觉请求使用独立的单次IPv4连接、30秒建连等待及300秒总时限，不重发请求体；缓存/推理明细超出实际输入/输出也会拦截。初始未知用量记录继续保留。
5. **刷新与人工复核体验**：任务及原件在服务端持久保存；刷新只读取原任务；新选资料不留旧完成态；403/404清理本浏览器失效指针，不跨成员恢复结果。增加源图放大，避免手机上整行缩得过小。
