## 范围和结果

检查新平台三个前端及公共包的79个TSX文件，以及官网生成模板的五个公开页面和404。包括ERP/CRM/MES、登录/企业引导/邀请、AI/知识、通知/消息、企业管理/运营管理、订阅/支持、连接授权、导入、编辑/详情/打印与确认弹窗。完整逐文件记录见[源码清单](../output/ui-copy-20261028/source-coverage.md)与[结构清单](../output/ui-copy-20261028/source-inventory.json)。源码全量检查与实际浏览器覆盖分别记录；没有逐一运行所有角色、路由和业务状态。

本次更新16份前端文件（含新增公共InfoTip）。当前工作树已有大量历史未提交改动；只沿现有实现精简，不覆盖其他业务增量。CRM总览的整体布局原已存在于当前工作树，本次只将分群说明移入info提示等；不能用生产基线与本地截图的全部差异充当本次改版成果。

| 区域 | 本批处理 | 必要内容 |
| --- | --- | --- |
| 公共登录/引导 | 移除重复“使用邮箱验证码登录”、获取验证码前教学和重复placeholder；标题后留出明确间距 | 邮箱/六位验证码标签、获取/倒计时、登录主操作、验证码发送状态、校验/错误恢复 |
| 邀请与知识 | 移除常驻有效期介绍和重复空间名placeholder；更正旧账号关联文案 | 实际生成链接的有效期、可信传递/一次性使用提示及身份/权限信息 |
| ERP基础资料导入 | 导出按钮明确为“导出筛选资料 CSV”；导出范围与CSV限制改为相邻info | 校验预览、错误定位、导入数量、库存/历史单据边界与新增客户归属/商品初始单位库存在最终确认中直接可见 |
| CRM | 分群条件、待办展示上限和币种口径改为info；删除草稿教程和重复历史说明 | 实际方案正文、统计范围、预览有效期、负责人交接影响、逐客户任务完成条件与结果真实性边界 |
| MES资料整理 | 文件类型/数量/容量要求进入info | 件号/用量/来源核对、禁止无依据填入、BOM发布及库存/生产影响提示 |

| 官网 | 主标题直接说明平台/产品，删除叠加eyebrow、区块口号、重复卡片介绍、收尾和页脚口号；产品摘要改为具体功能范围 | 产品能力、适用岗位、业务流程、登录/导航、语义标题、alt、SEO/结构化数据 |
| 其他页面 | 核对后保留必要业务内容，不为了“精简”机械删除 | 字段/单位/状态、金额/库存、授权/删除、失败恢复、来源与审计记录 |

`InfoTip`为公共包实现，应用经`@suite/frontend/components`复用。支持焦点/点击/鼠标进入展开、具体可访问名称、aria-describedby与tooltip关联、可进入阅读、Esc/失焦/外部关闭、视口边缘处理和粗指针44px触达。弹窗内的提示挂载到所属dialog，避免被原生模态的顶层遮挡。浏览器检查发现Esc同时触发原生dialog取消，已补充preventDefault，验证先关提示、第二次Esc再关弹窗。

公共规则维护在[UI02](ui/02-组件与交互.md#界面文案与信息密度2026-10-28d-093)，同步UI00/03/05/07及ERP/CRM/MES适配；不复制多套规则。
