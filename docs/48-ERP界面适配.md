## 业务页面与职责

2026-10-23：应用身份与切换沿[公共UI06](ui/06-应用身份与切换.md)：顶部进销存ERP胶囊、箱体图标、销售/采购/库存/财务用途。应用不与业务菜单混排；企业业务设置仅在ERP上下文展示，返回恢复上次有权菜单页。实施见52。

工作台按工作台、销售、采购与库存、财务、企业服务组织导航。完整路由以 [05](05-路由与接口契约.md) 及 `apps/web/src/App.tsx` 为准，功能追踪见 [17](17-ERP功能追踪矩阵.md)。

| 场景 | ERP适配要求 | 领域依据 |
| --- | --- | --- |
| 客户/商机 | 自有/公海、负责人、跟进、领取/转派范围；展示当前有权对象 | 02/12/17，客户转派公开契约 |
| 采购/销售 | 草稿、退回修改、审批/变更、分批履约和业务回执区分；保持发起/复核职责 | 02/19/30/37 |
| 库存/多仓 | 基础单位、明确换算、实际流水和版本；低库存建议与真实可用量区分 | 02/30及ERP库存Service |
| 账款/收付款 | 金额、余额、币种、凭证可核对；人工到账/认领/复核与银行/税务外部动作区分 | 05/30/37 |
| 补货/持续任务 | 核对依据→草稿→确认→步骤/等待→真实结果；取消不回滚已提交交易 | 40/41/43 |
| 经营事件 | 展示来源、责任人、当前影响和办理入口；正常业务恢复后核验解除 | 40/41 |
| 导入/期初 | 预览与确认分开，明确基础资料和库存/账款初始化的差异 | 28/30 |
| 打印/报表 | 服务端金额、CNY与数量单位；纸面不带操作导航，不把报表当法定财税凭证 | 30/36 |

现有ERP金额为CNY、通常两位小数，数量最多六位小数；显示和计算的特例以业务契约为准。这些是ERP领域规则，不成为CRM等应用的公共默认值。

## AI适配

- `erp.assistant`负责有权ERP事实、知识与受控Tool；业务字段、版本、权限、确认和回执与普通页面相同。
- 顶栏常驻“询问AI”；原 `/ai`、`/erp/ai` 深链接复用同一浮窗，显式对象分析展示已保存对象上下文。
- 快捷操作为业务分析、库存核对、采购草稿、单据进展；问题4000字符上限和当前内存输入保留沿现有接口。
- 企业管理与平台运营的助手使用独立管理域，只读范围和服务企业要求见 [46](46-三端AI助手与系统账号注册.md)，不当作ERP Tool入口。

新UI本地记录见 [45](45-三端UI统一规范与验收.md)、[46](46-三端AI助手与系统账号注册.md)；33～36为旧版视觉历史。后续改公共组件按 [UI验收](ui/05-应用接入与验收.md) 回归三端和ERP关键业务，真实模型/客户及生产发布另留证。
