# 客户试用操作指南

> 文档属性：操作手册。执行前核对适用环境/版本与前置条件，历史命令样例不代表当前线上配置。状态入口：[47](47-项目现状与文档维护.md)；公共UI：[ui/00](ui/00-公共UI规范.md)。

更新：2026-10-20。本指南的采购/销售/库存/财务步骤来自既有ERP契约与历史工程验证；真实客户场景由用户安排。当前环境状态见 [47](47-项目现状与文档维护.md)，业务功能和限制见02/17。下方账号开通方式保留既有已发布流程；D-043/D-044新版注册和AI入口在文末单独说明，使用前先核对部署版本。

## 入口与账号

- 工作台：https://enterprise-ai-platform.492746023.workers.dev/login
- 企业管理员从工作台“企业管理”进入成员、部门、服务及知识权限管理。
- 账号由企业管理员或平台运营配置，初始凭据通过双方约定的私下渠道交付；管理员可生成成员邀请和受控恢复链接，由双方约定渠道交付；当前不会自动发送邮件。
- 首次使用后点击左下角的头像与昵称，在展开菜单中进入“账号设置”修改初始密码。修改后原登录会话失效，需要重新登录。
- 左下角账号菜单也提供退出登录；有多个企业时显示“切换企业”，管理入口按账号权限显示。
- 不共享账号。按实际职责为销售、采购、仓库、财务配置各自成员；管理员维护企业设置并处理审批。

## 从空库开始

1. 管理员或采购添加商品和供应商；管理员或销售添加客户。
2. 已有表格时展开基础资料页面的“批量导入与导出”，下载对应模板，在表格软件中另存为 CSV UTF-8 后选择文件。
3. 先检查预览和错误提示，再确认整批导入。重复编号不会覆盖已有资料；客户默认由当前账号负责，可由管理员调整。
4. 导入商品的初始库存为 0。真实到货通过采购入库登记；切换系统时通过“期初导入”校验库存数量/成本与应收应付；开始交易后通过指定仓库的盘点流程纠错。不能把导入基础资料当成入库。
5. 创建采购订单或销售合同前，核对单据数量、单价和业务对象。

## 采购与库存

- 采购人员建草稿、修改并提交审核；由另一位分配到该金额范围的审核人处理，退回后由发起人修改。
- 管理员直接确认自己创建的草稿是专门审计的操作，不能代替团队约定的职责分离流程。
- 审核通过后，仓库在“我的待办”或采购订单详情按实际到货数量办理分批入库；系统同时更新库存和应付记录。
- 有待审采购变更时不能办理入库。采购变更仅支持现有行的数量和备注，已入库数量不会被倒退。
- 库存与预警页可查看余额、出入库单据、流水及低库存预警；盘点应依据实际核对结果办理。

## 销售与收付款

- 销售维护自己的客户、商机和跟进记录，创建并提交销售合同。按金额与代理设置分配审核人，仓库按实际数量办理分批出库。
- 库存不足会阻止出库；成功后联动库存和应收记录。不要重复新建单据来规避版本或库存冲突。
- 财务在应收应付页面登记真实收付款金额和凭证参考号。到账流水、收款认领和内部开票登记均需按实际业务核对。
- 收款认领与开票流程要求发起人与复核人分离，请提前配置至少两名具备相应权限的成员。当前不提供税务开票、银行转账或银行自动对账接口。

## 待办与协同

- “我的待办”集中显示指派给自己的任务、当前有权处理的审核/入库/发货，以及到期商机跟进，可按类型和关键词查找并翻页。
- 点击事项进入对应业务页面。完成实际业务操作后刷新，已处理事项会移除。
- “任务与公告”可以安排任务、查看站内通知和公告。手工任务的完成只改变任务状态，不会自动审批或修改关联业务单据。
- 到期任务和最新商机跟进由后台分批生成站内提醒；当前不等同于邮件、飞书、企微或钉钉推送。

## AI 与企业知识

- 是否可用取决于企业授权、当前成员的独立 AI 环境和实际知识引擎配置。未配置时页面会提示并限制不可执行的操作。
- 当前可使用进销存、站内协同、持久任务、经营事件和内置知识库；已绑定且实连通过的成员可使用 AI。其他成员需先由运营配置独立执行环境并检查，不能共享已验证成员的绑定。RAGFlow Cloud 暂缓。
- 服务开通后，AI 仍只能在当前账号权限下访问业务与授权知识，重要写入需要人工确认。以最终业务回执、单据和审计为准。

### 内置轻量知识库增强

- 内置知识库可以独立上传和搜索，不需要先开通 AI 聊天或 RAGFlow。支持 UTF-8 MD/TXT/CSV、PDF、DOCX、XLSX 与 PNG/JPEG。
- 扫描 PDF 和图片自动识别中英文；单文件最多 8 MiB，PDF 最多 120 页，其中扫描或空白页最多 20 页；图片最多 1200 万像素。旧 DOC/XLS 请先转换。OCR 结果可能有误，应通过原件核对。
- 关键词和向量共同检索，商品编号等可直接作为关键词；默认使用轻量本地规则重排序。Markdown 章节/表格/代码块等结构用于分块，旧文档点击“重新处理”后应用。
- 原件和索引保存在平台；当前嵌入调用已配置的火山方舟。本地 OCR/规则排序不额外发送内容；如运营方配置可选的云端 OCR/模型重排序，图片或授权片段会发送至所选服务，页面会提示。
- 发布与验证状态以 [32](32-轻量知识库检索与识别增强.md) 为准；这不代表真实客户扫描质量、容量或 AI 业务动作已验收。

## 试用前共同确认

- 哪些真实资料可以进入试用企业，是否导入旧系统历史数据，哪些文档允许进入第三方知识服务。
- 成员分工、审批复核人员、打印样式、试用周期和支持联系渠道。
- 备份保留、恢复目标及故障响应安排。当前采用手动联合备份，生产定时任务暂缓；试用不附带未经约定的 SLA 或财税/银行接口承诺。

## 已发布增补功能的操作顺序

1. **启用企业**：在经营概览查看启用清单，补齐基础单位、客户/供应商账期、打印抬头，邀请不同岗位成员；在企业业务设置安排普通/高金额审核人和有截止日期的代理。
2. **切换期初**：核对切换日期，使用表单或 CSV 导入库存数量/成本与未结应收应付。读取文件后点击校验、修正错误行、核对并整体导入；已有库存交易商品不能重复初始化。
3. **报价与成交**：在销售报价填写商品、折扣、税率、含税口径和有效期；接受后生成销售草稿，再提交审核。取消报价保留记录，不能转换。客户约定价格仅影响后续未手填成交价的新单据。
4. **履约与仓库**：按实际到货/发货选择仓库；调拨填写调出/调入、数量与原因。待发占用是全企业未分仓数量；盘点必须按所选仓库实盘，不能把企业总量填写为单仓量。
5. **售后纠错**：通过原单发起退货，选择原批次及数量，由其他审核人核对。通过后同步库存和账款；财务按真实回执登记应退差额。错误收付款用冲正，不删除流水；冲正认领收款会撤回整笔分配。
6. **变更与关闭**：已确认销售仅变更剩余数量，重新审核；退回变更恢复原方案。部分履约关闭剩余部分时保留已发/已收和账款事实。
7. **预收预付与对账**：先登记真实预付款，再选择同一单位未结账款抵扣；未用部分可以退回并留回执。经营报表按未税净销售额计算，账龄按到期日；对账单可导出或打印。历史成本标注估算时，需结合旧系统资料解释毛利。
8. **知识服务**：当前使用内置知识库，在知识空间上传资料，待处理状态为可检索后搜索并核对引用。RAGFlow Cloud 暂缓；AI 结合业务与文档执行仍需先开通成员 AI 助手。

## 内置轻量知识库（已上线）

企业管理 → 知识库管理可查看当前服务。内置方案支持 PDF、DOCX、XLSX、UTF-8 MD/TXT/CSV 及 PNG/JPEG；图片和扫描 PDF 自动执行中英文 OCR，旧 DOC/XLS 仍需转换。文档处理完成后可搜索并打开原文引用，表格显示工作表与行号、PDF 显示页码；旧版本原件仍按授权访问。格式与大小限制见上方“内置轻量知识库增强”。

平台运营配置可选方案后，企业管理员选择“准备并切换”；准备期间当前服务继续可用，全部成功后自动启用。支持取消或回退到上次方案。使用云端嵌入模型时，原件与索引保存在平台，文档文字和问题会发送到该模型服务。RAGFlow Cloud 当前账号未升级，仍不可用于真实 API 检索；本指南不表示该 Cloud 方案已开通。

## 内置知识库已开通（2026-10-08）

“小盖的工作室”当前使用内置轻量知识库。在企业管理 → 知识库管理中创建空间、设置权限并上传 UTF-8 Markdown（`.md`）、TXT、CSV、PDF、DOCX、XLSX 或 PNG/JPEG，单文件最多 8 MiB。待状态显示“可检索”后搜索，点击引用核对原文位置或下载原件。

“平台使用指南”空间已放入 `内置轻量知识库使用说明.md`，可搜索“支持哪些文件格式”体验。该空间默认受限，管理员按需要授权成员。图片和扫描 PDF 已支持自动中英文 OCR，旧 DOC/XLS 仍需转换；嵌入计算当前使用方舟云端。知识搜索开通不自动开通成员 AI；一名成员的真实模型、业务 Tool 和授权知识引用已完成生产验证，其他成员的实际服务状态以本人配置为准。

## 任务、补货与经营事件

- **补货建议**：核对在库、未发货需求、采购在途与建议量，选择商品/供应商生成采购计划。草稿未提交不会计入在途；数据变化导致依据过期时刷新建议。
- **任务中心**：打开计划详情核对真实商品、数量、金额和执行步骤，确认后才推进。采购审批仍由指定审批人办理；等待期间到业务单据处理，分批入库完成后任务自动核验并继续。失败可重试未完成步骤；取消只停止后续执行，不取消已经提交的单据。
- **经营事件**：负责人查看缺货、延期及逾期依据，点击“开始处理”后到对应业务办理。管理员可以转交给有对应权限的成员；正常业务恢复后自动解除，不用手动把风险假装标为解决。按分钟分批扫描，变化不会保证即时出现。
- **通知**：左下角铃铛读取本人通知，详情跳转后仍需业务授权；收到通知不代表现在仍有操作权限。

## 订阅与支持

企业管理 → **订阅与支持**可查看当前套餐、有效成员、本月 AI/任务、知识存储、已知费用、人工账单及支持申请。额度在服务端校验，不能通过前端界面绕过；缺失价格或用量不是免费，也不冒充供应商账单。

平台运营申请支持后，企业管理员核对原因和访问范围，批准 1/2/4/8 小时或拒绝；授权后可以随时撤销。支持只提供所选运行、任务状态或操作记录摘要，不包含业务正文、任务参数和凭据。人工账单的收款登记需要实际凭证，未连接外部支付。

演示企业和账号为假数据，正式环境目前保留供测试；账号私下交付，不在本文公开密码。电商CRM已进入开发前方案，尚未实现/发布，入口不能当成可试用功能。
