# 选中与焦点样式统一（D-071）

2026-10-24。用户反馈AI标题被大幅紫框框住，并要求所有页面统一优化。

## 原因与实现

AI打开时主动聚焦标题按钮，按钮又占满中间列，触发公共键盘轮廓，因此看起来像一个宽输入框。现在默认聚焦非操作面板，标题按文字宽度居中；菜单打开用浅紫底，键盘Tab仍有2px柔和轮廓。

公共focus.css覆盖三端的按钮/链接/菜单、表单、文件选择器及应用搜索焦点。表单改为淡紫边框和轻光晕，保留aria-invalid错误状态与高对比系统轮廓。普通弹窗聚焦标题，显式原生autofocus字段保留；危险确认仍聚焦取消，未改业务确认、权限或数据。

ERP、CRM、MES、企业管理、平台运营共同消费共享样式；官网五页统一链接/按钮焦点。仅发布前端，基于D-070隔离源码构建，D-063业务AI增量不进入本批；CRM AI保持开启，无付费模型调用。

## 验证与发布

三端TypeScript及Vite构建通过；公开页面、Cloudflare路由与SEO现有验证通过。本地浏览器核验AI初始面板、Tab标题、输入光晕、普通弹窗标题、显式原生autofocus、危险确认取消和手机首末Tab循环。五类AI面板共20组宽度320/332/390/768px布局无横向溢出；这是公共组件与布局验证，不等于逐业务页面验收。

三个前端已发布，118项线上资源/策略核对通过，API健康且ERP/CRM/MES AI均保持开启并配置可用。浏览器实际核验五域面板、应用切换搜索和官网键盘跳转；没有逐一打开全部业务路由或发送真实模型问题。操作证据位于`var/operations/20261024-focus-style/`，无密钥入文档。此轮没有更改API/数据库/Runtime，不重新执行真实模型验收。

回退：按versions-before.json对三个Worker分别执行wrangler rollback至D-070版本；旧发布哈希资源保留，避免已打开页面的懒加载失败。
