# 官网数字员工工作分类与流程优化

后续状态：D-104/105/106最终官网内容已于2026-10-28按[107](107-官网场景与数字员工优化发布.md)发布；下文保留当时本地实施与验收记录。

日期：2026-10-28；决定：D-106；环境：本地源码、构建与浏览器。未发布生产，业务UI版本仍沿1.18。

## 授权与范围

用户在参考智能问问细分岗位方式后要求继续优化官网。沿D-104/105，将ERP管家、CRM运营官、MES生产官细分为九类可理解的工作场景，保留真实能力及人员确认边界。本轮未新增Agent运行时、业务API、数据库迁移、模型调用、市场投稿或部署。

## 实施结果

| 员工 | 工作入口 | 关键边界 |
| --- | --- | --- |
| ERP管家 | 库存补货、采购跟单、账款核对 | 数量有依据；采购、入库与财务确认由岗位办理 |
| CRM运营官 | 客户运营、销售跟进、客户服务 | 客户沟通、阶段变化与服务审核由岗位办理 |
| MES生产官 | BOM核查、计划准备、进度追踪 | 人员核对物料与版本；理论需求不等于齐套或产能；待审不计完成 |

首页和方案页共用九类工作目录，支持三组分类筛选及全部重置，合并原先重复的场景与员工卡片。产品页的职责列表链接到各自三项工作；每项工作展开资料、步骤、交付和确认点。保留三组示例、正式品牌、头像、主视觉、五条公开路由与原登录入口。旧场景锚点及示例跳转兼容；知识完整流程单独保留。

实现：`apps/web/marketing/jobs.ts`新增工作数据，`site.ts`共用目录和流程渲染，`site.css`适配九类工作卡片及隐藏行为，`site.js`同步结果播报单位。现有public-pages断言由六类目录调整为九类；未编写重复实现的单元测试。公共约定同步至[UI07](ui/07-公开官网与产品页.md)。
