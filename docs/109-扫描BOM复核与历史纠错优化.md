# 扫描BOM复核与历史纠错优化

2026-10-28，D-109。用户同意先提升复杂图片的完整行识别，补齐原图复核、人工补行及经审核历史复用，再推进ERP/MES齐套和制造成本报价。本批为第一阶段本地实施，已完成回归和浏览器验证；尚未发布、无数据库迁移。

## 本批实现

- 数字列按独立网格单元留白拼接，分别在两种尺度读取，再按TSV坐标对应回原始行；跨越单元格边界的字串不采用。数量须满足两尺度一致及置信要求，未通过时做有限单格补读，单格最多四档并去重，至少两种不同尺度结果一致才采用，仍不明确则留空。不按序号推断件数、不默认用量、不降低置信阈值。
- 仅明确且均匀的网格行使用列批读；合并旧扫描保留逐行拆分。图片保持原坐标逆变换；清晰PDF继续读取文字层，不套用图片识别规则。子进程超时正确反馈DOCUMENT_TIMEOUT。
- 核对区增加原图逐行放大、整页位置标记、PDF单页本地渲染、待处理筛选、人工补行。手机和平板支持定位原图和返回当前明细。
- 人工补行保留原文件摘要、页/行和说明，必须选有效企业物料、填写用量并逐行确认。来源坐标和核对说明随BOM草稿保存。
- 已发布BOM中，人工确认的同一原件同一行可作为物料候选；限定当前企业/父产品、文件摘要、定位、原始身份及版本，不跨文件模糊学习，不复制历史数量。保存/发布再次检查权限及版本。
- 采用后修改物料、用量、损耗或父产品撤销事实核对；换单位清空原数量。新核对快照绑定产品、物料、用量和单位，服务端拒绝沿用过期核对。
