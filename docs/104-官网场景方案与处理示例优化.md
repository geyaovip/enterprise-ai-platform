# 官网场景方案与处理示例优化

后续状态：D-104/105/106最终官网内容已于2026-10-28按[107](107-官网场景与数字员工优化发布.md)发布；下文保留当时本地实施与验收记录。

2026-10-28，D-104。用户在参考文文实验室网站后要求整体优化官网，补充具体场景和解决方案。本批直接修改现有五个公开页面，沿用现有知行方舟品牌、渲染素材与五条公开路由；已本地实施与验证，未发布、未提交Git。生产状态沿D-103，不覆盖D-101/102等其他本地修改。

## 内容与体验

| 页面 | 调整 |
| --- | --- |
| 首页 | 平台身份之后先看BOM、采购履约、客户跟进；三个示例展示输入资料、处理步骤、结果与确认点；再选择应用、知识能力与落地方式 |
| 应用与方案 | 六类任务可按生产制造、采购财务、客户经营筛选，共享企业知识保留在各组；展开知识查询流程，补齐原生折叠常见问题 |
| ERP | 采购与订单履约、到账认领与应收核对；库存缺口示例展示24−8−4=12、48−20=28及确认要求 |
| 客户CRM | 客户分群与跟进；按有效订单数及7～30天筛选，样例3人选出A/C并形成两人回访草稿；产品名称覆盖当前销售与客户服务范围 |
| MES | 从资料到BOM草稿、从计划到报工审核；样例中不明确的紧固件用量仍待确认，不补造数量 |

场景统一回答“准备哪些资料、怎么处理、拿到什么结果”，保留适用岗位、业务确认点及来源追溯。首页卡片只放选择所需内容，详细步骤放到方案；删除重复结尾说明，不叠加口号或教学段落。参考网站用于组织内容，没有复制其客户案例、成效数字、技术认证或能力承诺。

示例为可访问的HTML表格、列表与状态，明确“示例数据”，不是实际产品截图、模型执行或客户案例。官网脚本仅处理菜单、tab切换和筛选，不读取企业数据、不调用API或模型、不创建业务对象。联系按钮复用D-084已授权邮箱，不发送邮件或创建空咨询表单。

桌面示例输入/输出并列、手机上下阅读；平板场景两列、手机单列；表格横向滚动限制在表内，页面无横向溢出。tab支持方向键、Home/End及单一Tab入口；筛选有选中状态和读屏结果播报，FAQ采用details/summary；菜单Esc关闭恢复焦点、选择导航后关闭，锚点避开固定页头。
