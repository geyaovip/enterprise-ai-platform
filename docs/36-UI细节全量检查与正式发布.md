| 运营指标散落、审计空表无反馈 | 运行数字使用普通段落，审计只显示空表头 | 运行指标使用共享卡片，审计明确空状态；加载有反馈 |

## 边界

本轮发布前端及 UI 细节修正，没有部署后端、迁移数据库、提交生产业务写入或改变成员权限。审查覆盖当前管理员账号可达的页面与主要弹窗，不代表所有角色、所有业务数据组合或真实客户流程已验收。生产 AI 仍为 configured=false，内置知识 configured=true；真实客户场景由用户后续专门测试，生产定时备份及 RAGFlow Cloud 按既有决定暂缓。没有新增 AI 开通或容量承诺。

## 2026-10-09 区块标题与右侧入口对齐补充

用户补充截图后明确只更新新平台同类问题，旧电子 ERP 本轮没有修改。新平台报表“商品销售与毛利／导出报表”已经对齐；实际打开 QA 对账预览后发现“打印／导出”组继承 `.form-actions` 的 4px 上边距，中心线比标题低 2px。修复后两者中心线同为 324.609375px，边距均 0。

共享主题将区块标题的零边距规则限定到 panel 内直接标题，提高选择器优先级；标题旁的操作组清除表单边距和 padding，保持 center 对齐，文字入口与图标使用 inline-flex。未增加旧项目的近期单据功能。
