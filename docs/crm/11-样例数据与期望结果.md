## 异常和状态样本

| 输入/操作 | 期望 |
| --- | --- |
| paidAmount=100.00、refundAmount=150.00 | 金额校验失败，行/字段定位，不提交 |
| externalCustomerId 缺失或不存在 | 关联错误；不按客户名猜关联，不自动造身份 |
| 两行同版本同 externalOrderId 不同支付额 | 批次内部冲突，预览不可确认 |
| order unpaid、paidAt 为空、金额 100 | 保留交易投影，但 F/M/首购不计 |
| CSV 外部 ID 000123，XLSX 字符串单元格同值 | 保留字符串，不变为 123 |
| XLSX 计算公式或宏/加密文件 | 不执行；按受支持格式明确拒绝或字段错误 |
| paidAt 精确等于 windowEnd | 不计该窗口；精确等于 windowStart 计入 |
| rule 中 SQL 字段、未知 op、非法金额、超过条件数 | schema 拒绝，不下发到数据库执行 |
| 分群预览后 source 数据版本或权限改变 | 任务确认拒绝旧预览，要求重新计算 |
| 确认 C004 任务后新增匹配客户 C005 | 原任务目标仍只有 C004，新评价可以有 C004/C005 |
| 创建 AI 草稿只收到文字“成功” | 无真实回执不能标成功；必须有保存的任务 ID/status |

样例的期望值在实施前经业务口径确认；调整 04 的口径时同步调整本页和真实测试，不把实现输出直接抄为期望值。

## 模板与保存筛选的固定结果

按04默认阈值、active、CNY，仍只使用基础四客户：

| 模板 | 命中 | 必须排除/原因 |
| --- | --- | --- |
| T-01高价值沉睡 | C004（1人） | C002的R=null不作R>90；C001 R13 |
| T-02首购未复购 | C003（1人） | C004历史1单但R196；C001历史2单；C002有效0单 |
| T-03近期购买活跃 | C001/C003（2人） | C002无有效购买；C004 R196 |
| T-04新客未购买 | 无（0人） | C002创建于08-01，客龄74天；其他人有购买 |

独立变体V-01：新增C005，来源创建时间2026-10-10T10:00:00+08:00、active、无订单，同有权渠道。客龄4，T-04只新增C005；基础看板的金额/有效订单不变。再把C005来源创建时间改为null，它从T-04退出且进入来源时间未知数量，不能用导入日期补足。

独立变体V-02：新增C006，两笔有效订单分别为2026-05-01和2026-10-04，各100.00、未退、完整一行明细。历史有效2单、窗口F1、R10；T-02不得包含它，T-03包含它。此变体不改变基础题集期望，运行后恢复seed。

相同已应用经营条件“R≤30且status=active”在列表、POST /segments/preview、模板T-03、保存后的分群得到同一规范化ruleHash及C001/C003；页码/排序变化不改ruleHash。未应用编辑值不进入保存；q名称搜索非空时不能偷偷存成更宽的人群。
