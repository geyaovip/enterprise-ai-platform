## CRM 专用交互

### 客户与指标

列表主列为客户名/渠道标识、标签、最近有效购买、窗口订单数、窗口净消费；手机号/邮箱默认脱敏，不把多渠道身份自动汇成一条同人记录。详情先展示经营信息，订单和来源按时间线展开。每项指标可查看窗口、时区、口径和截至时间；“数据待更新”和“数据未导入”有不同表现。

### 分群规则

使用字段、操作符、值的条件行和“同时满足/任一满足”切换，输入控件依字段类型改变。不提供 SQL 输入框、自动化画布或通用对象编辑器。删除条件、无效区间和空值条件可键盘操作并就地提示。

点击“预览人群”后展示当前有权人数、样本、条件摘要和计算时间。条件改变即作废旧预览；保存规则和创建任务分别有清楚动作。预览未完成、策略/权限/数据版本变化时不能拿旧人数提交。

任务待确认期间预览过期时，在任务详情“重新预览目标”读取同一已保存规则，展示人数变化及新截至时间；复核人明确确认后绑定新结果。方案/窗口继续只读，不要求为刷新预览撤回整份方案；修改规则或方案才撤回draft。

### 导入工作区

依次显示渠道/模板、文件与字段映射、校验预览、确认、后台结果。界面区分“已选择文件”“校验完成”“等待确认”“正在导入”“已导入/部分导入”“指标待更新”。

预览优先显示新建/更新/无变化/冲突/错误数量；错误可定位到工作表/行/字段，不展示未授权原文。确认卡写明渠道、数据类型、更新影响和实际提交数量。切页后能从批次 URL 继续查看；取消后的已提交数量保持可见。

### 运营任务

创建任务时带入分群规则、计算时间和目标人数，允许编辑名称、目标、负责人、截止日期、方案全文、执行清单和基准/观察窗口。draft 可保存未齐字段，提交前完整校验；确认展示方案版本和目标冻结后果。详情区分“AI 建议”“任务草稿”“已确认任务”“人工执行记录”“订单观察结果”。确认后方案和窗口只读，负责人/期限变更按 01 复核。

执行记录使用短弹窗；完成需摘要。无外部触达回执时不出现“消息已送达”或系统计算的送达率。效果卡同时显示观察人数、窗口、币种和证据来源，避免单一提升百分比造成误解。

### AI 和对象跳转

目标企业入口显式选择有权应用后，从 CRM 客户/分群/任务进入时自动带应用、对象和版本，返回链接留在 CRM。切企业/应用清空旧会话片段与对象缓存。工具卡片沿用现有公开参数、等待确认、执行、失败/待核实和真实回执，禁止泄露联系方式或内部 JSON 原文。

无 AI 服务时保留普通客户查询、手动分群和任务流程。实际进度与首字时间分别测量，继承 [公共性能口径](../ui/05-应用接入与验收.md#响应速度与实际操作效率d-032)，不把进度文字计为回答首字。

## 五项优先体验（C-005）

以下由 [有赞与微盟调研](12-有赞与微盟参考调研.md)形成，用户已确认优先范围；规则及阈值见 04，验收见 10，UI继承平台公共规范。

- 分群首页先提供少量“常用人群”模板与“自定义分群”；模板显示可编辑条件、当前有权人数/更新时间及“查看客户/创建任务”。高价值金额和时间阈值需可核对，未导入会员/访问行为时不展示相关可用模板。
- 客户列表默认经营筛选与高级条件分层；“保存为分群”沿同一类型化规则和权限计算，避免第二套保存条件数据结构。高级条件不一次铺满会员资产字段。
- 客户详情将概况、购买记录、运营记录、来源资料分开；最近/累计净购买和退款说明前置。积分、储值、会员权益等未交付内容不以大量空卡片占据主区。
- 从分群带入任务保留评价结果、条件、计算时点和有权人数，负责人/期限核对后确认；回到原分群不丢失查询上下文。
- 导入入口按客户、订单、明细提供模板；批次结果就地可查预计/实际、新增/更新/无变化/失败和重算状态。空客户页提供有权“导入客户数据”入口。

历史订单数、客龄及所有模板已纳入 04/07；条件不满足数据或授权要求时显示原因，不提供点击后才发现无实现的入口。

## 查询、选择与返回现场

查询/排序/分页、待选与已采用、重置及返回现场继承 [公共组件契约](../ui/02-组件与交互.md)。CRM额外约束如下。

保存为分群前显示当前已应用的经营条件，编辑中未查询的值不参与；有名称搜索 q 时明确要求清除后预览。分页、排序不进入规则。模板只是可编辑起点，采用后需重新预览，不自动保存。预览显示截至时间、有效期、来源范围及“可用于任务/指标待更新”，失效说明原因和下一步，不能自动把新人数用于旧确认。

选择器打开复制当前值，确认前仅改待选集合；取消不写回。多选跨搜索/分页保留待选项，明确“本页全选”，首版不提供未实现的全结果批量选择。关闭/取消采用不删除已上传暂存文件；文件保留和取消批次后果按 04/06 显示。

| 页面 | 页面内返回的逻辑父级 |
| --- | --- |
| 客户详情 /crm/customers/:id | 客户列表及其已应用查询 |
| 分群详情 /crm/segments/:id | 分群列表及筛选 |
| 任务详情 /crm/tasks/:id | 任务列表；“查看来源分群”是独立关联链接 |
| 新建导入 /crm/imports/new、批次详情 /crm/imports/:id | 导入记录列表；向导上一步只回前一步且保留输入 |
| CRM 授权/指标口径 | 各自导航顶层；企业管理返回沿平台规则 |

业务返回使用可信路由构造的父级，不读取任意外部 returnUrl；浏览器前进/后退另遵路由历史。从客户进入分群/任务时，来源链接不改目标资源父级，不形成返回循环。详情页签/列表条件可用 URL query 恢复，URL 不含个人字段或整份名单。

## 表单、弹窗与未保存保护

公共表单/弹窗/焦点和离开保护沿ui/02；CRM保存能力如下，不能因统一样式删除业务确认。

| 场景 | 保存能力与离开方式 |
| --- | --- |
| 任务 draft | 支持保存未齐草稿；离开提示“是否保存修改？”，副按钮“不保存”、主按钮“保存”；Esc/关闭留页。保存失败留页，不保存仅放弃本轮修改，不删旧草稿 |
| 分群规则/客户编辑/标签/授权 | 保存须满足完整校验；未保存离开用“继续编辑/放弃修改并离开”，不伪装有半成品草稿能力 |
| 导入文件/映射 | 文件已暂存与映射已保存分别提示；离开不自动确认导入；保存映射只更新批次草稿并作废旧预览；取消已提交部分前说明保留数量 |
| AI 方案尚未采用 | 保留当前输入，采用替换前展示差异并确认；关闭聊天不覆盖背景表单，保存任务须单独业务确认 |

路由离开、切企业/应用和关闭编辑层共用离开保护；浏览器刷新/关闭只使用浏览器实际支持的提示，不能承诺页面销毁前异步保存一定成功。跨企业切换清空旧对象、名单、选择和流式响应，正在提交的结果留原企业可查询。

## 真实异步状态与AI工作区

导入完成对勾、当前处理标记、后续编号来自真实阶段；行/组计数分开，未知耗时不伪造百分比。关闭展示不取消已入队任务；显式取消只停止未提交组，已提交数量仍可见，批次URL/通知可恢复。指标重算失败与导入应用失败分开。

AI外壳/历史/新对话/输入/焦点沿 [公共AI规范](../ui/04-AI对话与工作单.md)；四类CRM工作单、600字符问题限制、采用冲突、服务器草稿与回执沿 [14](14-AI对话框与工作单.md)。保存任务草稿与经理确认启用对应不同结果，不能合并为一条“成功”。

## 响应式、可访问性与交接验收

视口、断点和键盘/焦点/对比度仅按 [公共验收](../ui/05-应用接入与验收.md)，侧栏抽屉为<960px，手机规则为≤767px；此前将二者混用的描述由本规则覆盖。

CRM专项A-18/30/31/32见10：客户长名/连续英文、敏感字段、空值/零、规则预览失效、窄屏导入确认、跨页待选、任务离开保存失败、AI采用冲突、服务不可用、撤权和旧响应丢弃。使用同环境当前ERP作视觉参照，原生手机键盘/安全区和辅助技术分别留证；文档/构建/静态截图不计作已通过。

## 2026-10-22 接入事实

CRM页面位于`apps/web/src/crm`，仅添加业务布局，不维护第二套主题。经营概览/报表可选币种，客户列表复用类型化筛选与分页，分群预览可保存或直接建任务；任务有状态/本人筛选、方案历史、冻结与追加日志；导入工作区展示映射、校验、真实提交数、错误及补偿；设置集中渠道、CRM岗位、口径和标签。AI沿公共入口与外壳，当前发布闸门及模型验收状态见15。
