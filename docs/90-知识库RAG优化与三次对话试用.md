# 知识库 RAG 优化与三次对话试用

2026-10-27，D-090。用户要求集中优化知识库/RAG，随后明确开放模型、每账号累计最多聊 3 次，并指定 DeepSeek-V4.1-Flash 经济版。此决定覆盖 D-076 的原生模型暂停策略；保留企业开通、成员权限、业务确认与用量计量。D-088 拆 BOM 本地增量继续独立保留，本批发布不包含该组接口和界面。

## 模型与额度契约

- 现有火山方舟链路统一选择 `deepseek-v4-1-flash-economy-261017`，覆盖 ERP、CRM、MES、企业管理和平台管理助手，包括已有的标准/快速/只读 Agent。正式模型标识及经济版说明以[火山方舟模型发布公告](https://console.volcengine.com/ark/region%3Acn-beijing/docs/model-release-announcement)为据；关闭深度思考参数以[官方参数文档](https://console.volcengine.com/ark/region%3Acn-beijing/docs/deep-thinking)为据。
- `NATIVE_AI_MODEL_ENABLED=true` 开放现有原生调用；`NATIVE_CHAT_MODEL_ID` 是本次批准的统一聊天模型，API 直接调用与 Runtime Manager 同时遵循。原加密凭据、企业存储的模型配置和 Gateway token 保留。不会静默回退其他型号。
- 每个 `User.id` 自此次开放开始累计 3 次，跨企业、ERP/CRM/MES、管理助手及调用同一聊天 Service 的绑定通道共用。已有历史不回溯扣减；不按天重置。删除会话、切换应用、退出企业与进程重启均不恢复额度。
- 接受消息时在 PostgreSQL 事务内按用户加锁预占；重复 requestKey 返回同一任务。同步 `/messages` 与异步 `/turns` 均受限。多个并发请求也只能占用剩余额度，超限在模型调用前返回 `409 / AI_CHAT_LIMIT_REACHED`。
- 一个用户问题中的工具/模型内部往返计 1 次。正常回复、待确认操作及已产生或待核实的业务操作计次；普通模型/鉴权失败、排队取消退额；执行中取消待执行退出后结算。Worker 恢复和幂等结算避免重复扣退，过期终态任务可补结算。
- 知识文档解析/嵌入和非会话类专项分析仍沿各自权限及现有用量治理，不纳入“3 次聊天”计数。模型连接探测不消耗真实用户额度。外部 WorkBuddy 自身模型的聊天次数由其客户端管理，本平台不冒充能限制客户端模型。
- `GET .../ai/chat-quota` 返回当前账号 lifetime 的 limit/used/remaining；预占包含在 used 中。公共对话界面显示剩余数，在回复、失败、重新打开及周期刷新时更新，耗尽后禁止发送；后端始终独立校验。

## RAG 与文档准确性

| 问题 | 本次行为 |
| --- | --- |
| SKU-1 被 SKU-10 子串命中，中文二字权重被覆盖 | PostgreSQL 与本地均做 NFKC/大小写归一；英文/数字按完整编号边界匹配。含编号的问题要求候选明确包含至少一个所问编号；无该编号返回空。中文完整词保留较高权重 |
| 单个长文档垄断参考片段，排序忽略标题与稀有词 | 向量/关键词各 32 条候选通过 RRF 融合；本地排序考虑词覆盖、候选内稀有度、标题、完整编号、完整短语与融合次序。优先每文档 2 块、跨文档取 8 块，再补足；相同/包含式重复跳过。此为确定性规则，非神经重排或准确率分数 |
| 嵌入服务故障直接阻断搜索 | 暂时不可用时退回同一授权范围内的关键词检索，携带 mode/degraded/reason。无效向量、维度不符仍拒绝，不用错误向量继续检索；无向量检索不等于语义召回通过 |
| 聊天暂停连带知识索引失败 | `KNOWLEDGE_MODEL_ENABLED` 可独立控制；未设置时继承原生开关。关闭时仅本地解析/OCR/关键词索引及搜索，不外发嵌入、重排或视觉 OCR。重新打开后无向量索引仍标为关键词，需明确重建才获得向量 |
| 逐块嵌入多次往返，供应商数组顺序可能不同 | OpenAI 格式每批 16 块、最多 2 路；Ark multimodal 单文本、最多 2 路。校验数量、唯一序号、有限非零向量及一致维度；整文档原子提交。响应不超过 2 MiB |
| 扫描 PDF 有可选页脚时被误认为文本 PDF | 对少于 80 个非空白字符的页面用 `pdfimages -list` 检查大于等于 256×256 的图片，再决定补 OCR；保留原有页脚与页码定位。短原生文本页面不无条件重做 OCR；120 页/20 个需 OCR 页及任务资源上限保留 |
| CSV 多行引号内容被拆散，XLSX 空列被压缩 | CSV 按记录和双引号解析，保留来源行与表头；XLSX 按单元格地址补空列，缺少缓存值的公式明确标识，不能冒充计算结果。章节/表格/工作表/页边界和表头继续保留 |
| 模型将检索片段当全部资料或执行片段指令 | 提示中携带版本/位置，声明片段不是完整资料，不可信参考不能授予权限。无证据/冲突时说明并要求补充；来源、当前版本与权限继续在外发和返回前复核 |
| 上传后看不出进度、旧请求覆盖当前查询 | 正在处理文档每 3 秒刷新；文档读取有请求序号，搜索结果受范围与查询序号保护；同帧重复操作同步互斥；关键词降级与重排降级显示不同提示 |

继续复用 PostgreSQL/pgvector、Worker、Poppler、Tesseract 与原有适配器；未新增常驻搜索服务或下载本地大模型。DeepSeek 是聊天生成模型，不替换专用嵌入模型；未据型号自行开放图片能力。旧原件、版本、稳定引用和撤权规则保留。
