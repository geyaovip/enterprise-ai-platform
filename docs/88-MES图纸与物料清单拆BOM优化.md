# MES 图纸与物料清单拆 BOM 优化

后续状态：2026-10-28已随[D-099](99-BOM知识与UI联合发布.md)发布，以下“未发布”为本阶段当时状态；当前版本、线上核验和回退以99为准。

2026-10-27，D-088。用户要求优化图纸到 BOM 的完整链路并测试；明确客户会使用装配图、无明细加工图、多页或多份图纸及 Excel/CSV 清单，均需验证。本批为本地实现和隔离验证，未发布线上；生产状态继续沿 D-087。

## 实际改动

- MES BOM 表单增加本地资料整理路径，支持 PDF、PNG/JPEG、XLSX、CSV、TSV、TXT 和带表头的粘贴明细；最多 6 份文件、合计 8 MiB、PDF 合计 24 页、图片 1200 万像素。超过限制明确失败，不截断后标成功。
- PDF 使用 Poppler 的文字坐标与表格边界读取单元格，处理页面旋转；扫描页以及只有文字页脚的扫描表格可走单元格 OCR。图片识别表格边界后逐单元格调用本地 Tesseract；用量列收紧字符集并裁去空白后放大，修正孤立数字“1”漏读。该专用路径没有修改知识库普通文档解析或默认 RAG 配置。
- XLSX 保留稀疏列、实际工作表行号和前导零；明确合并的父件单元格可以向其覆盖行传递父件，数量单元格不据此猜填。数字零掩码按显示格式还原，公式单元格不执行也不信任缓存值。CSV/TSV 接受 UTF-8、带 BOM 的 UTF-16 和 GB18030。
- 保留父件、显式层级、各文件/页/工作表/表格的分组，不把子装配拍平成根产品的全部组件。检测来源循环或超过 10 级、重复件号/用量冲突、重复文件与重名文件。无明细加工图返回信息不足，不从外形猜零件、隐藏件或装配用量。
- 匹配限定当前企业的有效物料；未知、重名、单位冲突保留待确认。用量使用精确十进制，支持能精确表示到三位小数的分数和显式数量单位，拒绝逗号歧义、不可精确分数、零及负数。修复原 MES 用量校验对空串可能抛出内部异常的问题。
- 预览可选择装配、逐行修正数量/物料、排除重复行、查看来源及原图；修改结果会撤销核对状态，原业务表单变化继续使旧预览失效。逐装配核对后才能显式填入，保存和发布继续是原有独立业务操作。
- BOM 单装配行数上限从 50 调整为 200；仍受现有展开节点、层级和精度约束。行 JSON 新增可选 `sourceEvidence`，保存文件名、SHA-256、页/工作表/表/行、原件号/用量及核对状态；不涉及数据库结构迁移。它是来源摘要，不能替代正式图纸原件/版本台账。

## 接口、权限和运行边界

新增 `GET /api/v1/tenants/:tenantKey/apps/mes/boms/intake/options` 与 `POST /api/v1/tenants/:tenantKey/apps/mes/boms/intake`。POST 请求为：

```json
{
  "kind": "bom",
  "productId": "可选的当前企业有效父产品UUID",
  "source": {
    "text": "可选的带表头明细",
    "documents": [{"filename": "装配.pdf", "data": "纯Base64"}]
  }
}
```

返回 `groups`、每行原单元格、用量/物料匹配、单位冲突、来源定位、核对事项和文件摘要，不写 BOM 或物料。解析前后及返回前复核 `mes.bom.write`、`mes.material.read`；同一成员同一时刻仅一个任务，每实例最多两个本地解析任务，处理进程有超时、内存和 CPU 上限。

该路径使用本地文档解析和确定性检查，无需 AI 能力或模型开关，不调用 OpenClaw/视觉/嵌入服务。原 `/mes/ai/intake` 和其他应用 AI 提示模式继续由原模型闸门控制，没有借此打开模型或生产 AI。

API/Worker 镜像新增 `python3-pil`；其余复用现有 Python、Poppler、Tesseract 与中英文语言包。正式发布需重建镜像、发布后端和工作区前端，不能只上传前端文件。当前没有执行此发布。

## 尚未证明的能力

当前优先处理表头明确、结构可辨的物料明细；图片专用识别依赖可检测的表格线。任意倾斜/透视/模糊照片、手写、无框图片表、复杂跨行合并、全部 CAD/DWG/DXF 文件和几何/公差语义不在本轮已验证能力内。没有零件明细及单件用量依据的加工图，不能据此恢复完整装配 BOM。

每次只采用当前装配；未明确标识父件的不同文件/表不会自动合并，分组也不会自动批量保存。多来源版本取舍、真实客户图纸、容量及生产实际效果仍需对应验收，不能把这批 35 行的命中结果推广为通用 100% 准确率。

回退边界：无需回滚数据库结构；新来源摘要是可选JSON字段。若已保存超过50行的BOM，旧版本仍可能按旧上限拒绝编辑，须使用支持200行的版本处理，不能截断数据以迁就旧代码。
