# D-152 GEO 报告 PDF 与界面精简

2026-11-07。本地隔离验收。范围是平台原生 GEO、工作台与企业管理端共用的通知入口；原映川 GEO 工作区、服务器和数据保持独立。未部署生产、无新增迁移、真实模型调用 0 次。

1. **品牌项目与问题**：用项目名称进入，保留品牌、启停和必要的搜索标签；单页不显示分页。项目范围放到 info；首次引导添加问题，有问题且没有启用模型时，有权用户可进入模型设置。取消“启用项目”会显示归档的后果。
2. **分析任务与报告**：项目内的报告列表省掉重复的项目名；按状态显示“查看任务”或“查看报告”。报告首屏突出下载和核心指标，费用、样本不足及复测分差可见，详细口径放入 info。原始回答按需展开，保留筛选、引用和费用。发起分析和复测先预估费用，同一处主按钮随后切到确认。
3. **数据洞察**：将范围、模型、问题、分组放在同一筛选区；对比口径由 info 提供，结果和证据入口仍可直接读取。
4. **自动监测与优化复测**：每页突出“新建计划”或“新建任务”。暂停的计划不再显示无效下次执行时间；恢复时提示自动调用和费用上限。优化任务保留状态、负责人、基线和复测入口。
5. **模型、预算、权限**：三类设置独立选项卡；说明用 info，保留字段标签、预算单位和改权确认。
6. **任务中心、通知**：任务中心沿用分析状态和报告入口；未读角标与铃铛分开，保留完整读屏名称。已实测显示“15”，浅色对比度 5.49:1，深色 8.08:1，点击区高 44px；企业管理端和手机菜单相同。超过 99 时界面显示 99+。
