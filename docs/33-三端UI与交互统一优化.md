## 浏览器操作验证

- 独立 QA 数据库 `suite_phase1_qa`、API 4630、三个前端 4631/4633/4635；生产业务数据未用于写入测试。
- 商品：重复编码提交失败并保留输入；保存实际 QA 商品类别成功，重新打开编辑读取已持久化值；新建空表单触发原生 required 校验。
- 弹窗：关闭取消保留字段，确认关闭后焦点回到行编辑入口；关闭未修改表单可直接返回。提交按钮真实关联所属 form，未靠模拟成功关闭。
- 页签：企业管理、库存用左右方向键改变选中状态并移动焦点。
- 企业配置：打开二级页，复制当前 hash 刷新仍为同一企业，返回后显示列表与开通按钮。
- 知识管理：仅在 QA 开通知识能力，创建验收空间成功；管理权限和服务设置进入弹窗。此 QA 没有知识引擎，搜索保持禁用且显示未配置说明。
- 对账：实际读取 QA 客户 2026-10-01 至 2026-10-09 的往来数据；只打开结果弹窗，无财务入账操作。
- 视口：1440×1000 桌面、768×900 环境表单、320×740 长表单及 21 个导航页。长表单正文滚动，底部按钮可见；整页宽度未超过视口。

## 生产发布与复核

- Cloudflare 三端最终版本 `772eb6b1-4825-4f1b-86be-0f48dad66f98`；前一版本 `77607c6f-44ad-4a43-ac99-c91ffa71d03a` 可作为本轮前端回退入口。
- 三个前端 `tsc` 与 Vite 构建通过，线上 15 个 JS/CSS SHA-256 与本机构建一致；6 个入口/深链接返回 200。

## 验证边界

本轮是 UI 和交互改动，没有后端、数据库迁移或新的成员 Runtime 配置。新增、编辑使用原 API 和服务端权限；没有把 UI 成功等同于真实 AI、业务 Tool、全部 ERP 回归或真实客户场景验收。物理打印机及不同系统的原生打印对话框未测试；本轮修正了对账弹窗祖先被 print CSS 隐藏的问题和单据打印内容可见性。

生产定时备份、RAGFlow Cloud 与真实客户场景继续遵守 D-022。加载中截屏不计入最终视觉证据。
