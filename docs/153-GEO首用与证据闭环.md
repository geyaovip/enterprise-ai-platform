# D-153 GEO 首用与证据闭环

2026-11-07，当前企业 AI 平台 GEO，本地隔离验收。依据 [D-152](152-GEO报告PDF与界面精简.md) 之后的产品走查，优先解决模型交接、报告结论、证据与任务、监测预览。

- **指标与报告**：新分析冻结 `geo-evidence-v2`。品牌推荐绑定具体品牌和句子，排名只采纳有明确位次或推荐顺序的证据。能从报告查看所采纳的原句。报告、洞察和 PDF 在诊断样本下显示分子和分母，报告及 PDF 首屏标明 API 抽样。冻结条件和版本一致、基线及复测均全量有效、且分别达到评分覆盖要求时才展示分差。目前覆盖要求为至少 20 个有效回答、5 个问题和 2 个模型。旧报告保留既有结果并标记旧口径，可用新版建立基线。已经入队的旧版本继续按冻结版本计算。
- **首用**：提供品类推荐、选购比较、品牌核查模板，每行可编辑，单次最多 32 条，服务端去重并原子写入。没有模型时，运营可复制包含项目返回地址的配置链接。管理员从设置页回到原项目。按问题和模型的联网能力预先标注兼容组合，估价前能看到可执行数。
- **证据到任务**：从回答创建优化任务时带入问题、原句和基线，独立保留后续措施链接。来源回答必须属于同企业同基线，来源保存后保持固定。新分配对象须具备处理 GEO 优化任务权限。负责人可在统一任务中心查看未完成的 GEO 优化任务，进入项目后打开原回答。竞品缺席清单按问题汇总，引用排行可查看支撑回答。
- **监测**：完整报告可预填问题和模型并建立监测计划。新计划默认暂停，保存前展示预计执行时间、有效组合及费用预估。实际自动运行仍采用当时可用的问题与模型配置，按实际用量结算。手动启用保留确认。

本地验收包括 211 项断言、114 次 HTTP、53 次受控模型调用，真实模型调用 0 次。覆盖三类指标误判、一个样本的分差门槛、20 个有效样本的可比复测、批量去重、他人待办隔离、证据归属、监测预览和既有费用/权限流程。实际浏览器走通全新企业的管理员与运营交接、问法模板、模型不兼容拦截、报告、原句建任务、负责人待办、竞品缺席、同条件复测及 PDF 下载。手机 390px 下，监测预览的金额和执行时间会滚到可见位置并获得键盘焦点。PDF 已提取中文和渲染验收。API 编译、类型检查、三端构建和官网路由回归通过。
