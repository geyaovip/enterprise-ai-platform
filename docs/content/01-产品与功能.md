## 产品目标与首个场景

首个场景为“商品或产品营销素材包”：同一份已核对的品牌和产品资料，生成可修改的文案与图片，适配多个渠道规格，经审核后打包交付。它既能服务电商商品，也能服务企业销售的产品推广，不要求客户已开通 ERP 或 CRM。

示例任务：上传产品原图，选择品牌，输入“新品推广，价格299元，活动到11月15日”，生成方图、竖版海报和对应文案。人员确认卖点和价格，修改背景或标题，审核最终版本后导出。示例日期和价格只用于说明交互，不作为默认业务事实。

目标是减少重复录入、重复生成和手工改版。每批须能追溯资料来源、品牌规范版本、修改、审核与成本；生成数量不等于合格交付数量。

## 使用者与职责

| 使用者 | 日常工作 | 关键需要 |
| --- | --- | --- |
| 营销与电商人员 | 制作新品、促销和渠道素材 | 一次准备资料，批量产出，直接改字换图 |
| 销售人员 | 制作产品推广图和销售文案 | 产品参数准确、品牌统一、可分享已审核文件 |
| 品牌或设计负责人 | 维护规范、模板与成品审核 | 限定关键元素，比较版本，明确退回原因 |
| 内容管理员 | 配置人员、品牌和预算 | 应用内授权、模型可用性、用量与失败处理 |

平台 Membership 继续表示企业成员身份。创作者、审核者等是本应用岗位授权，不新增一套登录或企业身份。

## 首版功能

| 功能 | 首版行为 | 完成条件 |
| --- | --- | --- |
| 创作首页 | 一句话发起，上传参考，选择品牌和营销产品，继续最近项目 | 能从真实资料进入项目；缺项直接补充 |
| 品牌中心 | 多品牌，Logo、颜色、字体、表达规范、禁用词、参考图；草稿与已发布规范版本 | 项目绑定确定版本，管理员发布规范，历史输出可追溯 |
| 营销产品资料 | 产品名称、编码、核对后的卖点/参数、价格与有效期、原图、参考素材 | 可人工建立与上传，明确哪些字段允许改写或不得生成 |
| 创作需求 | 受众、用途、渠道、尺寸、标题/价格/日期、语气、必要声明 | 形成可预览的生产清单，不由模型偷偷扩展数量或范围 |
| 文案 | 标题、卖点、正文、行动语；修改、比较、采用 | 已确认事实不被改写为新承诺，保留文字版本 |
| 图片与版式 | 背景/场景图生成、参考图编辑、文字图层、Logo/商品图放置、局部重绘 | 关键文字和素材可单独调整；支持固定锁定元素 |
| 多规格与批次 | 从一个项目展开尺寸和文案变体，逐项生成、重试、取消和筛选 | 成功项保留，未知请求不自动重发，费用可追溯 |
| 版本与审核 | 保存版本、对比、提交、通过、退回、撤回；按版本审核 | 编辑审核对象后生成新版本，旧批准不自动沿用 |
| 素材与交付 | 原图、生成素材、成品、模板分开组织；图片PNG/JPEG、透明PNG、文案TXT、单项下载与ZIP包 | 包含选定版本和规格清单，导出时再次鉴权；可编辑原稿保留在项目中 |
| 应用管理 | 成员岗位、共享范围、模板、模型能力、预算及用量 | 复用平台管理边界，内容管理员只能管理有权范围 |

### 品牌与产品的一致性

品牌规范和营销产品资料均按版本引用。生成开始时冻结品牌、产品、需求和模板快照。资料更新只影响后续明确采用新版本的任务，当前任务不被静默替换。

Logo、价格、日期、型号、二维码和必要声明采用确定性图层或受控模板。原始产品图优先保留，背景单独处理；确需改变产品姿态或外观时单独提示，并要求人工核对。模型描述“已保持一致”不能代替产品外观检查。

品牌约束分三类：代码可执行的字体/颜色/锁定字段规则；需要模型辅助理解的语气与视觉风格；需要人员判断的审美、外观与商业表述。界面分别显示实际检查结果，避免汇总成没有依据的“一键品牌合规”。

### 模板与编辑

首版提供满足首场景的少量内置版式，允许选择、替换内容和调整可编辑元素。模板维护由内容管理员或授权设计人员负责，明确图层、尺寸、安全区和锁定项。不建设通用低代码 Builder，也不要求普通人员编辑节点或脚本。

图文原稿与导出文件分别保存。用户能只改价格、标题、日期、Logo或指定背景，不必重新生成整张图。多尺寸适配优先重排原有图层；确需补画面时再形成新的付费生成项。

## 内容对象与归属

| 业务对象 | 内容模块拥有的事实 |
| --- | --- |
| 品牌及规范版本 | 已授权素材、表达规范、版本和发布记录 |
| 营销产品资料及版本 | 用于创作的核对快照、原图与来源引用；不拥有 ERP 的价格、库存或交易事实 |
| 内容项目与需求版本 | 活动目的、参与人、品牌/产品引用、交付规格 |
| 模板版本与作品版本 | 版式、可编辑图层、素材引用、采用记录 |
| 生成批次与执行项 | 批次范围、执行状态、供应商请求、失败/未知及用量 |
| 审核与导出包 | 指定作品版本的决定、批注、导出文件与清单 |

首版产品资料采用人工录入和文件上传。后续若接 ERP/CRM，只通过所属应用公开 Reader 获取有权数据，保存来源ID、版本和时间；不跨模块读内部表，不把两个系统的“产品”直接合并。

## 权限与审核

| 应用岗位 | 默认能力 |
| --- | --- |
| 内容管理员 | 管理品牌、模板、应用岗位、项目共享、预算和异常处理 |
| 创作者 | 创建项目，在参与项目中编辑、生成、提交审核；不能发布品牌规范 |
| 审核者 | 查看分配的项目与指定版本，批注、通过或退回；不能代替创作者修改送审快照 |
| 查看者 | 查看共享范围内的已批准内容；下载仍须有导出权限 |

企业管理员在应用已开通时可管理应用岗位；普通岗位由本应用明确授予，不将 ERP/CRM 岗位自动映射成内容权限。首版支持企业共享与指定参与人项目两种范围。品牌已发布资料按有权成员可见，项目私有上传素材不因同企业而自动共享。

组织启用审核后，创作者不能自审；单人企业可以选择免审交付，但要明确记录管理员的审核策略。批量审核列出确切作品版本，不能把“此后所有变体”一并批准。试用预览和正式交付分开，未批准的文件不能误标为已批准成品。
