## 代码采用规则

两项目核查提交的主许可证为MIT：[Loomic许可](https://github.com/fancyboi999/Loomic/blob/21206c30054572291b9df000d84568aeca97aeda/LICENSE)、[Toonflow许可](https://github.com/HBAI-Ltd/Toonflow-app/blob/af6e884c3d8cda353acaf8ef13aea8ea754a4afd/LICENSE)。实际采用时记录文件、提交、版权声明、依赖与修改，单独核对第三方库、字体、模型和素材条件，不把仓库许可外推到全部资产和服务。

以总适配成本判断复用：依赖兼容、宿主耦合、任务可靠性、租户授权、测试和维护。简单组件或参数映射能降低成本就提取；不适配现有结构的部分按本平台实现。不整合两套画布数据、身份、积分或任务状态，不为保留开源界面而改变已定产品目标。

## 音乐、数字人和动作模仿接入评估

2026-11-03 核对公开接口和本地参考项目源码。下列能力均为候选，企业账户开通、端到端生成质量和实际用量仍待验证。

| 场景 | 火山能力 | 开源复用与采用建议 |
| --- | --- | --- |
| 广告和商品短片配乐 | 音视频理解与处理产品提供 `GenBGM` / `GenBGMForTime` 和 `GenSongV4` / `GenSongForTime`，纯音乐和人声歌曲分开，独立签名，提交后返回任务 ID。纯音乐 v5.0 文档时长为 30–120 秒。[纯音乐](https://docs.volcengine.com/docs/audio-video-understanding-and-processing/generate-pure-music-1?lang=zh)、[歌曲](https://docs.volcengine.com/docs/audio-video-understanding-and-processing/generate-vocal-songs?lang=zh) | ACE-Step 1.5 首选。已有 REST 提交、查询、音频文件接口和 Apple Silicon MLX 启动脚本，可用独立服务。先验证小型 Turbo 权重生成一段无歌词 BGM 的内存、耗时和可听性，再决定部署位置。8 GB 本机的稳定运行待实测。[源码](https://github.com/ace-step/ACE-Step-1.5)、[API](https://github.com/ace-step/ACE-Step-1.5/blob/main/docs/en/API.md) |
| 广告旁白和商品讲解 | `Seed-Audio 1.0` 走豆包语音的音频生成接口，支持提示词、音色及音频格式等参数。方舟公告中的体验入口与豆包语音的 API 鉴权分别核对。[音频生成 HTTP](https://docs.volcengine.com/docs/doubao-voice/audio-generation-http?lang=zh) | Toonflow 可复用音频参数定义和结果交互思路，抽取音色、语速、格式的映射；Vue 节点按现有 React 工作台实现。[音频设置源码](https://github.com/HBAI-Ltd/Toonflow-app/tree/af6e884c3d8cda353acaf8ef13aea8ea754a4afd/packages/nodes/audioGenerationNode) |
| 数字人口播 | 即梦 AI `OmniHuman1.5` 接受图片和音频 URL，异步提交、查询。官方建议短音频优先，支持 720p 和 1080p。[开通说明](https://docs.volcengine.com/docs/jimeng-ai/product-introduction?lang=zh)、[生成接口](https://docs.volcengine.com/docs/jimeng-ai/call-step3-video-generation-1?lang=zh) | 优先用同源 API 做单主体口播。MuseTalk 适合作为已有视频的重配音和口型同步候选，代码与自有权重可商用，所用第三方权重另行核对。[MuseTalk](https://github.com/TMElyralab/MuseTalk#disclaimerlicense) |
| 品牌角色动作模仿 | 即梦 AI `DreamActor 2.0` 输入角色图片和模板视频，异步返回 720p MP4，模板视频上限 30 秒。[开通说明](https://docs.volcengine.com/docs/jimeng-ai/action-imitation-20-product-introduction?lang=zh)、[接口](https://docs.volcengine.com/docs/jimeng-ai/action-imitation-20-interface-documentation?lang=zh) | 有 GPU 试验环境时复用 ComfyUI 官方 Wan2.2 Animate 工作流，测试全身动作和角色保留，预处理节点与权重许可分别核对。第一版优先考虑即梦 API，之后用样本和运行成本决定是否自托管。[官方工作流](https://docs.comfy.org/tutorials/video/wan/wan2-2-animate)、[模型卡](https://huggingface.co/Wan-AI/Wan2.2-Animate-14B) |

Loomic 本地版本的媒体任务封装可参考，所查口型能力来自外部视频供应商。Toonflow 有音频生成节点和第三方口型接口，未发现可以直接部署的上述三类推理引擎。InvokeAI 本地提交 `1334a24` 在模型识别中明确拦截 Wan Animate 和 Wan S2V 权重，动作试验采用 ComfyUI。LivePortrait 默认依赖的 InsightFace 检测权重受非商用限制，列为需替换依赖后再评估的肖像驱动候选。[LivePortrait 许可](https://github.com/KlingAIResearch/LivePortrait/blob/main/LICENSE)

接入顺序为短片 BGM、单主体数字人口播、动作模仿。各能力在创作框按需出现，继续走现有企业项目、素材权限、任务历史和下载入口。音乐需要补音频类型校验、时长、试听和下载。数字人和动作模仿可复用视频任务记录、进度恢复、播放和下载，新增即梦视觉服务签名、提交与状态转换。用于外部拉取的图片、音频和视频按本项目权限校验后提供短效链接，结果回存企业素材库。现有方舟 Seedream 和 Seedance 走 Bearer 鉴权，候选通道单独配置并按企业开通。优先用隔离环境完成状态、失败、权限、重复提交和下载回归，再用已授权自有素材各生成一条短样本核对效果和实际账单。
