# 在品牌内容工作台完成音视频任务

用户已提供资料时，先交付可复制的口播稿、素材清单或字幕核对建议。需要处理音视频时，引导用户登录知行方舟，选择有权访问的企业，进入「品牌内容 → AI 工具」。创作首页也可直接打开「口播成片」或「自动字幕」。

| 用户诉求 | 在 AI 工具中打开 | 需要准备 | 可下载结果 |
| --- | --- | --- | --- |
| 把稿子读出来 | 文字配音 | 最多 800 字的纯口播稿 | 标准女声 MP3 |
| 用现有出镜素材做口播视频 | 口播成片 | 已授权的单人出镜 MP4、最多 800 字的纯口播稿 | 带字幕 MP4、配音 MP3 和 SRT |
| 用现成音轨匹配人物口型 | 口型对齐 | 已授权的单人出镜 MP4、MP3 或 WAV，视频应至少与音频等长 | MP4 |
| 更换视频中的人脸 | 视频换脸 | 已授权的单人出镜 MP4、参考人像 JPG 或 PNG | MP4 |
| 从已有音视频提取台词 | 自动字幕 | MP4、MP3 或 WAV | SRT |
| 把 SRT 字幕写进视频画面 | 字幕压制 | MP4 和对应的 SRT | MP4 |
| 把已有字幕翻成另一语言 | 字幕翻译 | SRT 和目标语言 | 保留原时间轴的 SRT |

视频与音频最长 3 分钟，MP4 最大 32 MB，音频和图片最大 8 MB。字幕翻译每次最多 60 条、合计 1800 字，支持简体中文、英语、日语、韩语和西班牙语。口播成片的配音若长于素材，画面会往复播放；需要自然连贯时，优先缩短稿件或准备时长足够的授权视频。工作台会给换脸、口型对齐和口播成片加 AI 合成标识。

没有 SRT 时先用「自动字幕」，检查品牌名、术语、金额和时间轴后再翻译或压制。已有翻译 SRT 可压制到原视频，保留原声。视频译制配音成片、数字人形象克隆和声音克隆当前不提供；不要把标准配音说成克隆了用户的声音。

用户在工作台检查素材授权、费用提示及提交范围后操作。费用不明时以工作台提示与账单为准。通过该工具的「处理记录」查看状态并下载；遇到「待核对」先查原记录。只看到了稿件、素材或操作指引时，说清待提交或待核对。检查成片时实际播放，并核对口型和原声、字幕内容和时间轴、合成标识及文件完整性。

品牌内容 MCP 负责获授权项目和素材查询，以及图片、参考改图和视频生成的预览、确认提交与回查。上表中的音视频工具由用户在工作台操作。现有 MCP 的生成回执不能代替这些工具的处理记录。需要摆放素材或继续创作时，从「创作 → 画布」打开独立画布。
