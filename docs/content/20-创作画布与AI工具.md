# 创作画布与 AI 工具

2026-11-13 已上线。创作、画布和十五项 AI 工具可在工作台使用，生产验证见[发布记录](#生产发布)。交互参照 [即梦创作首页](https://jimeng.jianying.com/ai-tool/home?createTab=canvas) 和 [蝉镜 AI 工作台](https://mcp.chanjing.cc/help-center/getting-started/workspace-overview.html)。

## 入口与结果

- 品牌内容侧栏隐藏应用切换器下方的企业名称。创作、探索、AI 工具、资产和主体沿用各自的导航与权限。
- 创作顶部的「画布」进入 `/content/canvas`，可搜索、打开和新建画布。创作记录的「画布」进入同一项目的画布，画布的「生成」回到对应记录。只读岗位可打开有权查看的已有画布。资产页保留独立的画布管理视图，原 `/content/canvases?new=1` 链接沿用资产页兼容路径。
- 首页输入框继续支持自由创作，下方展示商品场景图、短视频脚本、口播成片和自动字幕。提示词模板仍可从首页打开。侧栏「AI 工具」提供全部工具和图片、视频、音频、文案、素材处理筛选。

| 工具 | 输入与结果 | 执行方式 |
| --- | --- | --- |
| 商品场景图 | 商品原图、商品名和场景。成图保存到创作记录，可下载或加入画布 | 企业现有 Seedream 生图与参考图链路 |
| 活动海报 | 活动主题，可选活动信息和视觉风格。输出一张海报图片，发布前核对画面文字 | 企业现有 Seedream 生图链路 |
| 社媒配图 | 内容主题，可选平台、画面风格和参考图。成图保存到创作记录 | 企业现有 Seedream 生图链路 |
| 图生视频 | 首帧和镜头或动作，可调清晰度、时长和比例。输出可播放、下载的 MP4 | 企业现有 Seedance 异步任务链路 |
| 社媒文案 | 已知事实、平台和可选语气。在创作助手确认发送，保存标题、正文和话题建议 | 现有内容助手和企业文字模型 |
| 短视频脚本 | 主题卖点、时长和可选语气。在创作助手确认发送，保存口播与分镜 | 现有内容助手和企业文字模型 |
| 图片处理 | 本地 PNG、JPEG 或 WebP，可裁剪、旋转和镜像，下载 PNG | 浏览器处理 |
| 视频截帧 | 浏览器可解码的本地 MP4 或 WebM，选择首帧、当前帧或尾帧，下载 PNG | 浏览器处理 |

图片和视频表单沿用既有生成预览、原请求编号、任务状态和结果下载。工具草稿按企业、成员与工具留在当前浏览器会话。文案的内容通过路由状态传给现有助手，用户发送后由原会话保存。画布列表增加可选 `projectId` 条件，和租户及成员项目可见性条件同时应用。无需数据库迁移。

## 外部服务

初版八项工具复用火山方舟和内容助手。后续服务及接入范围见本页音视频工具扩展。下列能力需要额外服务。

| 后续功能 | 需要的服务 |
| --- | --- |
| 数字人形象或声音克隆 | 形象或音色训练及授权服务。[蝉镜开放平台](https://doc.chanjing.cc/faq/basics.html) |
| 通过平台链接拉片或采集爆款 | 合规的内容读取授权或授权数据接口。本地视频分析可单独用上传、抽帧和语音转写实现 |
| 从分镜自动生成全部画面的成片或批量成片 | 分镜、画面生成、配音、字幕和合成编排 |
| 自动发布 | 目标平台的开放接口、应用审核和账号授权 |

## 2026-11-13 音视频工具扩展

首页常用工具显示商品场景图、短视频脚本、口播成片和自动字幕。全部工具增加音频分类，原八项继续提供。新增视频换脸、口型对齐、自动字幕、字幕压制、文字配音、口播成片及字幕翻译。结果提供预览、下载和下一步入口。自动字幕或翻译的 SRT 可以进入压制，标准配音可用于对口型。口播成片使用授权出镜视频和脚本，顺序执行配音、对口型、识别字幕及应用内压制，同时交付 MP3、SRT 和 MP4。

| 功能 | 运行依赖 |
| --- | --- |
| 视频换脸、口型对齐、自动字幕 | `MEDIAKIT_API_KEY`。调用 AI MediaKit，结果保存到应用私有存储 |
| 文字配音、口播成片的配音 | `CONTENT_DOUBAO_VOICE_API_KEY`。豆包语音 2.0 标准女声 |
| 压制及合成标识 | API 和 Worker 镜像提供 FFmpeg、FFprobe。应用内处理，避免额外压制 API 费用 |
| 字幕翻译 | 企业现有文本模型。中、英、日、韩、西语，SRT 保留原时间轴 |
| 形象克隆、声音克隆 | 本轮暂缓 |

### 标准配音与口播真实验收

豆包语音合成 2.0 返回可播放的标准女声音频。同一流程串接 MediaKit 口型对齐和 ASR，再由 FFmpeg 压制字幕及标识，完成 3.71 秒的口播视频。使用火山官方示例的视频片段和测试文案。首次口播的独立配音已完成，随后并行的模拟 Worker 误领取该隔离库中的任务并因配置指纹不符终止。关闭模拟 Worker 后使用专用队列复验成功。第二次任务中配音、口型对齐和 ASR 各提交一次。采用按量价估算，账单待核对。未发布生产。

### 从脚本到成片

先用「短视频脚本」准备分镜与口播稿。只有配音需求时，用「文字配音」下载标准女声 MP3。有已授权的单人出镜 MP4 时，可把纯口播稿粘贴到「口播成片」，从处理记录下载 MP4、MP3 和 SRT。已有视频且只需翻译字幕时，用「自动字幕 → 字幕翻译 → 字幕压制」，成片保留原声。各工具的输入、输出和交接条件见[操作指引](21-音视频工具操作指引.md)。
