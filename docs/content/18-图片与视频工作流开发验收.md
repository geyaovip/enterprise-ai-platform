# 图片与视频工作流开发验收

2026-11-03，本页功能已随 D-145 上线。下方保留开发阶段的本地验收记录。生产验收和回退见[发布记录](../145-品牌内容资产与画布发布.md)。

2026-11-03，本地实施。生产仍为 D-144。内容工作台和画布共用生成偏好。图片默认 2K、单张，可按模型能力选清晰度、比例、多张参考图和一至三张候选。候选各自保留任务和用量记录。素材来自本地、项目资产、企业资产或已上传图片的产品主体。技能填入可编辑草稿，创作助手入口沿用现有企业对话渠道。

视频支持提示词或单图首帧。创作框可以直接切换，图片结果和画布提供首帧交接。已接入 Seedance 1.0 Pro Fast，默认 720p、5 秒，其他有效规格按该模型支持范围提供。提交后通过同一项目恢复任务状态，视频保存到私有项目资产，可播放、拖动进度和下载 MP4。 [方舟任务参数](https://docs.volcengine.com/docs/ark/create-video-generation-task-api?lang=zh)

画布可保存图片与视频设置，刷新后恢复。选中生成结果可以查看并回填原请求参数。复制设置会创建新画布，带入提示词、品牌和生成规格，引用素材需在新画布重新选择。参考附件沿用 Loomic MIT 组件。比例图标逻辑取自 Toonflow MIT 的生成设置组件，许可证随源码保留。界面继续复用现有弹窗、实体选择器和主题。

## 接口与恢复

- 既有项目生成预览和批次入口新增可选图片规格与多参考字段，以及 `mode=video` 和视频规格。旧单图、版式、局部改图请求保持兼容。
- 图片和视频共用原租户授权、版本预检、提交幂等、Worker 租约和素材访问校验。视频供应商任务编号持久化，Worker 查询已提交任务。提交状态不明时，进入核对状态。视频用量单独记为 `content.video`。
- `ContentCanvas.data.recipe` 为可选配置。复制用既有新建画布接口的 `sourceCanvasId`。视频资产通过现有受保护文件入口提供 Range 响应。此次没有数据库结构迁移。

## 结果编辑与视频截帧

图片详情新增原参考图和当前页候选图对比，以及更换背景、调整光线、变换视角三个可编辑改图模板。图片详情与画布均可为单张参考图框选修改区域。生成模型返回候选图后，平台按原图尺寸合成选区，选区之外保留原图像素，结果作为新图保存。当前使用矩形选区，选择操作支持拖动及键盘数字输入。

视频结果和画布视频均可保存当前帧、首帧或尾帧。截帧在浏览器解码，沿私有项目素材接口保存。结果页保存后可继续作为图片参考，画布内保存为新图片节点。复用 Toonflow MIT 版 `videoPlayer.vue` 的独立解码和取帧逻辑，项目文件与权限接现有平台。截帧不调用模型。

隔离环境验证了矩形选区的全图像素比对、原图与候选对比、结果页保存尾帧、画布保存首帧和产物复用。方舟模型仍使用替身，付费调用为 0。此次范围为已有图片和视频工作台的结果操作。

## 资产、图片工具与模板验收

资产总览和项目内资产共用名称搜索、类型和排序，支持原文件预览和本页多选下载。画布选图可在当前项目或企业资产中按名称查找。图片详情和画布均可裁剪、旋转和镜像，复用 Pillow 另存 PNG。画布把新图放在原图旁。探索支持搜索图片和视频模板，填入创作框后由用户提交。音乐生成、数字人和动作模仿后置。

本地隔离验收通过 45 次媒体 HTTP 检查、11 项画布状态检查、22 项图片媒体、37 项 Studio 和 88 项画布回归。包含纯处理生成三种新图、原图字节保持、图视频混合 ZIP、匿名拒绝及无效资产拒绝。内置浏览器实测搜索、素材预览、ZIP 下载、画布选图、旋转和刷新持久化、图片详情按比例裁剪和视频模板回填。付费模型调用为 0，本次未发布。
