## 当前缺口

现有画布的对象是图片与备注。底部的全局生成框保存本浏览器会话草稿，运行时发送单图参考、提示词和比例，单次一张。请求已经有来源节点、预检、幂等请求键和版本保护，生成结果回到画布。现有UI没有可编辑的步骤配置、模型能力驱动规格、结果参数回填和跨步骤引用操作。企业已经可以配置生图与视频模型渠道，画布需要消费这些能力并按已授权型号展示有效的选项。

## 建议的第一条工作流

1. **配置图片步骤。** 提示词、品牌规范、企业授权的模型、参考图和输出比例放在同一面板。规格按模型支持提供2K/4K，默认2K单张；有明确费用的候选张数由用户选择并在提交前显示。
2. **把结果接到下一步。** 选中图片结果可以新增“参考改图”步骤，固定引用这一张结果，生成后保留原图与候选。允许查看该次实际模型、提示词、参考图、规格与费用记录，并复制为新草稿。
3. **保存及复用。** 服务端存步骤配置和结果关联，刷新后恢复。企业可从同一张画布复制创作模板，模板保存可编辑参数，运行前重新校验模型授权、引用素材权限和费用。
4. **接入视频步骤。** 图像链路验收后，用选定图片作为 Seedance 首帧。显示时长、分辨率及首帧决定的比例。一次手动提交只运行当前步骤，用户可以确认画面后再进入下一步。

方舟 Seedream 4.5 文档支持2K/4K和多参考，组图的 `max_images` 是上限。若产品承诺固定生成 N 个候选，需由任务侧管理实际返回数量与费用。Seedance 1.0 Pro Fast 首帧模式的尺寸与比例受模型约束，时长和分辨率按模型能力校验。规格层由 API 和 Worker 共同验证。 [方舟生图接口](https://docs.volcengine.com/docs/ark/image-generation-api?lang=zh) · [方舟视频接口](https://docs.volcengine.com/docs/ark/create-video-generation-task-api?lang=zh)

验收场景为产品图换背景。重新打开画布后仍能修改下一步的参数，查看已运行版本的实际设置，下载选中的候选图。覆盖跨租户引用、模型变更、重复提交、处理中刷新、部分失败和停止任务。先用模拟模型走全链路，再用一张真实图片核对配置送达和产物规格。

## 创作输入框与视频入口

本轮通过已登录的即梦创作首页核对了生成偏好、创作类型，以及视频模式下的模型、输入帧、比例、清晰度和时长。技能搜索与管理参考用户提供的截图。即梦的创作类型决定本次要做什么，生成偏好决定选定类型的具体规格。企业工作台可沿用这层结构，生成页和画布共享参数能力。

| 入口 | 建议交互 | 执行边界 |
| --- | --- | --- |
| 创作类型 | 工具栏显示当前的图片生成、视频生成或创作助手。选择后保留原模式草稿并显示本模式参数。 | 创作助手沿现有默认文本渠道，用来拟提示词、卖点或分镜。需要生成媒体时先展示任务参数，用户提交后执行。 |
| 生成偏好 | 工具栏显示当前规格摘要。图片展开比例、清晰度、张数。视频展开比例、清晰度、时长。显示实际使用的企业模型。 | 默认值可一键恢复，显式提交时固定实际参数。服务端与Worker验证型号能力、企业渠道版本和素材权限。只有一个可用模型时展示其名称。 |
| 附件与主体 | 统一选择本地上传、企业资产和主体。主体用现有产品档案，展示明确的附件名和预览。 | 图片可以有多个参考。视频首帧须显式选择。模式切换保留各自附件，用户可以明确将图片结果带入视频。 |
| 技能 | 提供可搜索的企业场景入口，优先电商套图、产品卖点短片、品牌社媒图。 | 首批技能填入可编辑模板参数。多步技能通过步骤配置、结果和运行状态记录来实现。 |
| 图片结果与画布 | 图片卡和选中图片工具栏均提供“生成视频”，预填当前图片为首帧。生成页仍可直接切到视频模式。 | 视频结果保存到本项目，生成记录显示状态、实际规格、播放与MP4下载。 |

视频现状已核对源码。企业模型设置可以保存视频渠道，工作台的生成请求目前只有图片相关模式，Worker和素材呈现仍为图片流程。视频要接上异步提交、任务状态恢复、结果下载落盘、权限保护及播放下载，已有图片和画布记录可继续使用。

默认建议为图片 2K、1 张，视频 720p、5 秒、1 条。视频首版用企业配置的 Seedance 1.0 Pro Fast，支持文生视频和单图首帧，首帧模式默认跟随原图比例。该方舟型号支持 480p、720p、1080p 和 2～12 秒。首尾帧、有声视频及视频编辑等选项按实际型号能力开放。即梦界面的型号名称和选项应与方舟 API 的型号能力分别判断。 [即梦创作](https://jimeng.jianying.com/ai-tool/home) · [方舟型号能力](https://docs.volcengine.com/docs/ark/video-generation-tutorial?lang=zh&redirect=1) · [方舟任务参数](https://docs.volcengine.com/docs/ark/create-video-generation-task-api?lang=zh)

视频验收以“选中已生成的咖啡产品图 → 用作首帧 → 显示规格和费用依据 → 刷新后继续看到同一任务 → 播放并下载本项目 MP4”为主线。隔离环境覆盖重复提交、提交结果不确定、轮询恢复、过期供应商链接、模型配置变更和跨企业访问。待隔离链路通过后，才安排一次短时真实视频验收。
