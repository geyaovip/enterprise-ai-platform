## 界面文案与信息密度（2026-10-31）

资产页用「生成历史 / 画布」切换浏览。侧栏保留创作记录和最近画布，搜索放在资产页和画布列表。画布标题行的「全部」在悬停或键盘焦点进入时显示，触屏常显，直达资产的画布视图。

资产两页使用同一套顶部工具。右侧搜索图标展开输入框，回车应用，Esc 收起，当前关键词可直接清除。第二行保留类型、范围、时间和排序。进入批量模式后，选择数量、全选和操作集中在列表上方。生成历史批量下载原始素材，画布批量复制成员可访问的详情链接。

本节按用户最新要求执行，适用于品牌内容全部页面、弹窗、空态、结果和兼容管理页。浅色与深色创作主题同样遵守[公共文案与信息密度规则](../ui/02-组件与交互.md#界面文案与信息密度2026-10-28d-093)。本节优先于下方历史页面设计。

- 默认保留标题、清晰主操作、必要表单标签、业务内容、真实状态；删除无必要的次要标签、说明、辅助描述和冗余微文案。不默认添加 slogan、教学段落或区块帮助说明。
- 先去掉重复文案，再靠布局、视觉层级、间距与具体按钮文案解释界面；清晰度下降时先改结构，不补回大段说明。移除说明后，新用户仍应知道下一步点哪里、点击会发生什么。
- 可选的规格细节、模型型号、选区方式等放在相关操作旁的 info＋tooltip；没有信息价值的内容直接删除，不将全部旧文案搬进提示。复用公共 InfoTip，支持焦点、点击、Esc、读屏描述关联和窄屏。
- 可见表单标签和必要可访问名称必须保留。提示词是业务内容，不能作为冗余文案删除；placeholder 不代替标签，图标按钮须有明确的可访问名称。被视觉隐藏的标签仍须与控件正确关联。
- 费用影响、提交/费用未知、权限/配置阻断、未保存修改、共享范围与危险或不可逆后果必须在决策位置直接可见，不能藏进 tooltip。创作保留简短付费提示与单次数量，恢复原请求不能写成重新生成。
- 生成按钮明确命名“生成图片”；示例明确为可点击按钮，填入需求后仍由用户发起生成。品牌/版本、审核状态、实际尺寸、错误及恢复入口保留；默认成功能力不常驻解释。
- 审查覆盖桌面和手机、空态/有结果/错误、弹窗与键盘。截图可证明所见布局，不能替代真实读屏或完整无障碍合规验证。

## 视觉与布局决定

沿用[公共UI](../ui/00-公共UI规范.md)的语义变量、字体、字号、控件、弹窗、焦点、错误反馈与账号通知，保留创作区的专用布局和双模式配色；不复制组件库或聊天浮窗。图片预览背景可用中性灰或透明棋盘；主题切换不能修改原始图片、品牌数据、图层色值、参考图或导出内容。

创作区可采用专用业务布局：大预览、参考素材、可折叠助手、多尺寸结果板和局部工具条。统一 UI 不要求将编辑器做成 ERP 表格，也不要求保留即梦的活动横幅、积分促销或作品社区。独立主题只有在后续有明确收益与实施安排时再设计。

普通操作以任务、品牌、产品、用途命名。模型名、分辨率能力、请求日志与供应商参数进入高级设置；当前生效模型与费用依据仍可查看。没有实际接通的工具不显示可点击入口。

### 开始创作

首页显示一个主要输入框，支持自然语言和参考上传。只要求足够完成当前任务的资料：品牌、产品、目标与交付规格。可从已有资料选择，不反复填写。首次无品牌时提供最短的资料建立路径；允许无品牌试稿，但正式送审或交付前须绑定规范版本或明确记录免品牌策略。

发起需求后，助手将意图整理为项目需求。价格、日期、型号、必要声明、品牌/产品版本、数量、尺寸以及预计产生的生成项直接显示在生产清单中。用户可以改字段，也可以用对话改清单；模型推断的事实标为待核对，不自动采用。

金额包含币种，活动日期包含年月日与适用时区。确认清单时一并展示模型可用性、是否向外部供应商发送参考素材、估价或估价范围，以及批次预算。用户一次确认明确范围的生成操作。后续超出数量、费用上限、资料范围或模型用途时更新清单再确认，不给每个内部技术步骤增加确认。

### 编辑与助手

桌面宽屏主预览占可用空间主体，右侧助手建议宽度320至400px并可收起；素材与图层按需打开，避免同时铺开多条侧栏。顶部只保留项目、已绑定品牌、保存状态、版本和送审/导出等当前主操作。

用户选中图片或文字后，在附近显示对应操作。文字直接修改；图片可替换、裁剪或局部修改；锁定项给出锁定原因和有权修改入口。助手引用当前选择，以可见的对象标签表达作用范围。全项目助手与所选对象工具共用一处意图输入焦点，避免两个大输入框竞争。

“把价格改为299”优先修改结构化文字图层；“只改背景”展示选区和保留元素。“换一种风格”等需要重新调用模型的操作显示新生成项与费用。对话中的建议先成为可采用修改，不因模型回答已完成而覆盖当前作品。

每次采用修改产生作品修订。撤销/重做处理本地编辑历史，已送审/批准快照保持不变。版本对比展示图片与文字变化；保存成功以后才显示“已保存”。上传、自动保存或版本冲突失败时保留本地未提交内容，不能静默覆盖服务器新版本。

### 多规格与批量生成

首版内置方图1080×1080、竖图1080×1440、竖屏1080×1920三个通用输出预设，具体渠道要求在模板/规格中另行定义，不将通用预设标为已验证的平台投放规格。相同比例的不同像素输出优先使用同一素材重排或导出，不默认按规格重复生成付费背景。

批次由“产品资料版本 × 需求变体 × 交付规格”展开，显示每项来源。生成前给出总项数、预计外部请求数和预算；大批次先试制少量样本再由人员继续。初始建议每批最多20个产品资料、60个交付项，具体上限在容量与成本验证后确定，由服务端实施，不能只限制前端。

结果默认网格呈现，每张卡包含缩略图、产品、规格、版本及真实状态。支持只看失败/待核实、同产品比较、多选采用和已选项导出。跨页选择显示准确数量与范围，不能用当前页面的状态代替全部结果。

已成功项不因其他项失败而回滚。失败项先区分“供应商明确拒绝”“已提交可查询”“提交结果未知”“生成成功但入库失败”。只有明确可重试的步骤才提供重试；其余给出查询/恢复动作，避免用户多次点击造成重复费用。

### 审核与导出

送审页显示固定版本、品牌/产品版本、规格和需核对事项。审核者可以在作品上批注、通过或退回，返回原因可定位到作品或图层。任何采用的新修改都形成新修订并使当前送审对象需要更新，不能继承旧批准。

正式导出默认仅包含已批准或按企业策略明确免审的版本。创作者可有权下载带“草稿”标记的预览。ZIP包附清单：作品、规格、文字稿、版本、批准/免审状态；不放 API Key、内部请求日志或失效的供应商链接。

## 状态反馈与异常

| 场景 | 用户看到的反馈与恢复 |
| --- | --- |
| 模型未配置/未开放 | 保留资料、模板与手工编辑；生成区说明不可用原因与有权配置入口 |
| 排队或执行 | 显示实际阶段、已完成项与取消；没有依据时不显示百分比或剩余秒数 |
| 关闭页面 | 已提交的后台任务继续；再次进入从服务器恢复，不自动创建新请求 |
| 取消 | 区分“未提交已取消”和“已请求停止，供应商处理中”；可能已产生的费用仍可核对 |
| 用量或提交结果未知 | 显示待核实，暂停对应范围的新自动调用；查询原请求或人工处理 |
| 权限或应用撤销 | 停止提交/恢复调用；清除不可访问的预览，说明联系管理员 |
| 自动保存冲突 | 保留本地修改，提供查看服务器版本和另存修订；不自动全量覆盖 |
| 引用失效 | 指出缺失素材/版本；允许查看仍有权的历史快照，重新生成前补齐 |
| 导出失败/过期 | 保留原作品和导出清单；重新打包，不重新调用生成模型 |

## 响应式与可访问性

1440/1280px覆盖完整编辑；1024/900/768px将助手和资料改为切换面板。390/320px优先保留发起、预览、选版本、审核和下载；精细图层操作提供可触达的面板，不强行缩成桌面画布。手机不承诺完整专业编辑与桌面等价。

颜色不能是状态唯一表达；图片工具提供名称，拖拽有按钮或键盘替代，选区和修改目标有文字摘要。沿公共规范验证焦点、Tab/Esc、IME、触控目标、缩放、减少动态效果和文本对比度。预览缩放不改变导出像素，透明背景不依赖浅色画布辨识。

## 首版交互验收样例

同一产品生成三个渠道规格，保留商品和Logo，将价格与活动日期直接改写，只对背景做局部重绘。关闭页面后恢复任务，比较新旧修订，提交其中两个版本审核，审核后导出。对话、表单和图片操作必须指向相同作品版本；此样例的工程与效果判定见[验收计划](04-实施阶段与验收.md)。

## 轻量画布模式

创作使用“生成 / 画布”切换，同一项目可来回切换并保留生成输入和画布排布。画布首版只做图片、备注、参考改图和原图下载，不引入专业海报图层/流程编排界面。工具有可访问名称，操作提示优先放入info；费用与未知提交、放弃修改和回收后果保留。完整契约见[16](16-轻量创作画布.md)。
