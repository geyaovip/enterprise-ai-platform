## 阶段与交付

| 阶段 | 范围 | 退出条件 |
| --- | --- | --- |
| 当前方案阶段 | 产品、交互、统一UI取舍、源码评估、接入缺口与验收设计 | 文档可追溯，范围与状态一致；业务代码、配置和数据库未改 |
| 接入与基础创作 | content注册、岗位/对象权限、导航与助手上下文、品牌/产品版本、私有素材、模板和手工编辑 | 无ERP/CRM企业可独立使用；四应用导航/上下文隔离；手工图文可保存和恢复 |
| 单件真实生成 | 少量媒体模型、生产清单、预算预占、Worker、单件生成/局部修改、用量与失败恢复 | 授权真实样本验证效果；中断/未知/取消不造成盲目重发；原图与文字准确性可核对 |
| 首版完整闭环 | 多规格批次、版本对比、审核、通知、ZIP导出、回收与备份恢复 | 通过本页场景与工程矩阵；记录已知不足、容量和费用边界 |
| 后续视频与扩展 | 视频、配音字幕、专业画布、按需跨应用来源 | 单独确定样本、预算、版权/资料授权和验收；首版不预建空入口 |

完整首版包含“接入与基础创作”到“首版完整闭环”。中间阶段可以用于隔离验证，不能把只完成手工编辑或模型接口称为首版已交付。

## 实施前收口

- 选定首批使用者和实际产品资料，确认主渠道、尺寸、文字语言、品牌规范及人工基准。
- 首批渠道已由用户确定为火山方舟，图片 `Doubao-Seedream-4.5`、后续视频 `Doubao-Seedance-1.0-pro-fast`，复用现有Key。接入时核实实际API标识、账户权限、可用能力、鉴权、数据处理、价格单位、异步查询、幂等与取消方式；指定型号不等于已验证接通。
- 在可用的现有组件/编辑器基础上验证文字图层、Logo、图片、锁定与导出；只做实现需要的最小技术验证，不先开发通用设计平台。
- 本项目测试不设总预算硬上限，按用户要求节约使用；企业生产预算、并发和存储期限仍按产品规则配置。默认并发先保守实施，按真实样本调整；不得把文档建议值当作容量结果。

## 核心业务验收

| 场景 | 预期结果 |
| --- | --- |
| 从产品资料生成三种规格 | 同一品牌/产品/需求快照，规格准确，图文与成品可回查 |
| 修改价格与日期 | 修改结构化文字；无需重新生图，数字和日期与确认值一致 |
| 保留产品和Logo只改背景 | 展示作用范围；核对保留区域和蒙版合成，边缘效果由人员判定 |
| 修改已批准作品 | 新修订不继承旧批准；旧批准和旧导出仍可追溯 |
| 品牌规范更新 | 历史任务保持原版本；新任务明确选择新版本并显示差异 |
| 批次部分失败 | 成功项保留；重试只针对明确失败步骤，不重跑整批 |
| 查询超时或供应商结果未知 | 保留原尝试、预算和外部ID；不自动发起另一笔付费调用 |
| 页面关闭与Worker重启 | 页面恢复原任务；有外部ID继续查询，无确定结果进入待核实 |
| 创作与审核分工 | 创作者不能越权通过；有权审核者仅决定送审版本 |
| 免审交付 | 企业管理员明确选择策略，成品标明免审与操作者；不伪造审核人 |
| 导出过期或失败 | 重打包已选版本，不重新生成素材或重复扣媒体费 |
| 产品来源后续接ERP/CRM | 双端应用和对象授权均通过；快照来源可追溯，撤权不继续刷新/发送 |

## 工程验收矩阵

| 维度 | 必须覆盖 |
| --- | --- |
| 身份与开通 | 未登录、未开通/撤销、套餐未包含、停用成员、切企业、content-only企业 |
| 对象隔离 | 双租户ID互换、项目参与人变更、私有素材、缩略图、导出、历史与通知链接 |
| 并发与版本 | 重复提交、同键异参、多人保存冲突、双Worker、过期租约、迟到结果/回调 |
| 费用与恢复 | 预占/结算唯一键、未知消耗、生成成功入库失败、取消已发生费用、预算同时耗尽 |
| 存储与清理 | 文件伪装、超像素/超大小、异常媒体、引用保护、回收恢复、临时文件清理 |
| 端到端行为 | 点击/对话调用同一服务与范围；版本、任务、审核和下载回执均持久化 |
| UI与可访问性 | 1440/1280/1024/900/768/390/320px，键盘/IME/触控、焦点、缩放、减少动态效果 |
| 共享回归 | ERP/CRM/MES应用识别、AI scope、统一登录、账号/通知、管理端及原有配额政策 |
| 运维与恢复 | 同库迁移、私有卷备份、数据库与媒体一致性、恢复读取、兼容部署和回退 |

真实模型测试沿2026-10-30用户授权：不设项目测试总预算上限，但不得随意测试。先完成离线/替身验证，只在必要接口联调和效果验收时用少量样本真实调用；优先复用已有结果，避免重复生成、无目的对比和并行大批量测试。每次记录验证目的、模型、输入版本、实际/未知用量与结果；出现提交或费用未知先核对原请求，不盲目重发。视频尚未进入实施阶段时不为试用接口提前生成视频。界面和替身验证不代替模型效果，模型通过也不代替权限、恢复和客户接受度。

## 产品效果如何判断

使用同一套已授权产品和品牌样本，对比人工流程与工作台流程。记录完成时间、中途修改次数、人工返工点、可交付版本数量、每个采用成品的已知成本和未知费用项。

价格、日期、型号和声明等结构化字段必须与确认值一致；Logo和受保护产品区域按模板/图层及必要像素核对。背景自然程度、商品外观、品牌调性和审核可用性由品牌/业务人员逐项评价。不把所有结果合并成未经定义的“品牌一致率”，也不用生成数量代表采用率。

模型生成耗时、排队和整体任务耗时分别记录，P95需要足够样本。沿公共UI的即时反馈目标处理按钮与页面；图片生成不承诺统一几秒完成，预估进度不冒充实际结果。

## 发布与回退准备

发布申请前列明新应用注册、数据库迁移、私有媒体卷、能力配置、企业开通、共享UI影响和回退版本。先在隔离环境验证升级与恢复，再按明确授权发布。迁移采用兼容方式；停用内容应用可停止新提交，恢复时继续查询已有请求，不能通过回退丢失调用与费用记录。

回退时保留品牌、作品、任务、用量和媒体，隐藏不可用入口；供应商尚在执行的请求继续有可核对的归属。生产状态、真实模型结果和客户意见应另写有日期的证据记录，不能回填本页把计划改写成验收通过。
