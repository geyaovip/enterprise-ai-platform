## A01 首版质量复核

先把首版已有142项内容检查、助手14项、HTTP适配18项、媒体22项及已有浏览器/容器证据映射到真实用户动作，不以数量本身判断产品完整。

重点复核以下行为并补对应的有效验证：

- 标题、价格、日期、声明、TXT正文与可见图层是否一致；修改后的版本和审核状态是否准确。
- 锁定字段、品牌/产品/模板引用及私有素材的跨项目、跨企业访问；素材被替换或共享范围撤销后的行为。
- 查询参数、重复请求、过期预览、同键异参、迟到结果、Worker中断、撤权后的入库与下载。
- 已成功生成但保存/导出失败时能否恢复原结果；未知提交和费用待核对是否被误判为可免费重试。
- 作品、版本、批次、导出、用量和审核队列在超过现有读取上限时的完整性。
- 未配置模型、无生成权限、未开通应用、离线和过期导出的解释与恢复入口。

该清单制定时没有运行新增检查；后续实施中的修复和验证已分别记录在[08](08-图文日常创作开发与验收.md)，不据代码阅读直接宣布其他路径存在漏洞。开发时发现影响资料正确性、权限、重复付费或数据恢复的问题，先修复再进入新增功能。

## A02 模块组织

当前`ContentService`约2100行、`ContentPage.tsx`约2500行；后续功能继续叠加会扩大编辑、任务和审核之间的改动影响。拆分服务现有职责，不拆独立应用或数据库。

| 区域 | 目标职责 |
| --- | --- |
| 资料服务 | 品牌/产品/模板的版本、发布与引用 |
| 项目与授权 | 需求、参与人、共享、对象访问与回收 |
| 作品与编辑 | 图层、草稿、修订、结构化变更与校验 |
| 生成执行 | 清单预览、付费提交、持久尝试、恢复和结果采用 |
| 审核与交付 | 审核决定、交付资格、导出任务和文件授权 |
| 媒体适配 | 指定模型的能力、输入输出、任务状态与用量回执 |
| 前端页面/组件 | 首页、资料、项目、编辑器、审核、素材、设置分别维护；共用选择/表单/状态组件 |

业务写入仍经各自Service；页面与AI工具调用相同服务。跨服务事务和租约由明确的用例入口持有，不能在拆分时丢失原有原子写入、审计或幂等约束。保持公共入口兼容，业务代码不直接读取ERP/CRM内部表。

## A03—A05 编辑体验和版本

### 编辑操作

统一图层变更操作模型，支持选择、移动、缩放、裁剪、文字/颜色修改、排序和允许的锁定变更。拖拽与属性表单使用相同操作，不维护两份互相覆盖的状态。鼠标松开或输入确认构成一次可撤销操作，避免每个指针事件都写历史。

键盘能够选择图层、微调位置并撤销/重做；中文输入不被快捷键截断。手机优先保障查看、改字、替换素材、审核和下载，复杂精修可集中在桌面。触控选区和裁剪应有清晰边界，不靠悬浮提示才能完成。

### 工作草稿

拟增加应用自有工作草稿职责，可复用平台的身份、授权和存储基础，但不把画布草稿塞入通用聊天输入草稿。

草稿至少记录项目/作品、成员、基础正式版本、草稿修订号、结构化编辑状态和同步请求键。画布历史存资源引用，不反复保存Base64图片。自动同步节流、有版本校验，成功同步和仍在本地的状态清楚可见。

正式保存或送审时，从明确草稿快照产生不可变作品修订。自动保存、正式版本与审核决定分开；不把自动保存当作已经审核或交付。过时草稿不能覆盖其他成员新保存的版本，冲突时保留当前输入供比较和重新采用。

### 渲染和模板约束

为预览/导出建立版本化版式规则，包括坐标、字体、换行、对齐、裁剪和溢出判定。先提供少量可分发字体，在浏览器与服务端使用相同字体版本；字体加载失败时提示，不默默用另一套字宽导出。

长标题、带货币符号的价格、日期、英文参数和声明不能在导出中静默丢失。允许在品牌定义的最小字号范围内适配；仍溢出时要求调整版式。模板中区分品牌变量、产品/活动字段和可自由编辑文案；跨品牌复用时按新品牌解析，不把旧色码当成需要画进背景的文字。

单次生成的背景在多尺寸之间优先重排/裁剪复用。更改已选尺寸的价格或文案时，预览所影响的具体版本，采用后生成这些版本的新修订；原审核结果不随之复制。

## A06 文案建议采用

沿已有文本助手与模型设置增加结构化建议，不新增一套聊天产品或文本模型管理。建议应携带来源快照、目标项目/作品版本和字段差异，例如只改标题或只改行动语。

可先提供以下操作：生成若干标题候选、精简正文、按品牌语气调整、按渠道压缩长度。数量和目标字段由用户选择或明确预览，避免模型自主扩展大量候选。

将价格、日期、型号、规格、声明与允许变化的营销表达区分。采用建议前核对事实；采用已有建议是确定性写入，不再调用模型。原资料或目标版本已变化时，提示重新核对，不自动覆盖新编辑。

## A07—A08 任务和平台配置

导出请求冻结准确的版本和格式，创建持久任务后返回，Worker合成并通知取件。页面关闭不丢结果，重复请求回到同一任务，失败重试只做打包。下载继续复核交付资格、对象权限和有效期。

作品/版本/批次/导出/用量与审核范围补齐服务端分页、排序、过滤和计数；缩略图复用同一对象权限，网格列表不默认读取全部原图。容量和文件处理验证使用替身及已生成素材，避免为了压测调用真实模型。

媒体配置引用平台既有凭据与加密边界，声明用途、型号、端点、能力和配置版本。队列提交后不能悄悄换成另一个型号；恢复已有结果不应因当前默认型号变更而把已发生费用释放成0。当前Key继续复用，配置迁移不能要求用户在前端重新粘贴Key。

操作界面展示“请求未提交、生成中、正在保存、结果待核实、已完成/费用待核对”等实际状态，提供对应恢复动作。模型和账单细节进入有权人员可查看的记录；常规创作页不堆API字段。

## 联合验收脚本

| 场景 | 期望结果 | 生成调用要求 |
| --- | --- | --- |
| 首次完成素材包 | 从基础品牌、产品到三规格图文，另一成员审核后导出 | 背景按清单生成，多尺寸优先复用 |
| 改活动价和日期 | 只更新选定尺寸的新修订，画面与TXT一致，旧批准不自动延续 | 不调用图片模型 |
| 拖动、撤销、重做 | 图层与属性表单同步，锁定元素不被普通操作移动 | 不调用模型 |
| 刷新和断网恢复 | 恢复已同步工作草稿，未同步和冲突状态可识别 | 不重发生成请求 |
| 旧文案建议采用 | 目标已变化时保留当前编辑，要求重新核对 | 采用动作本身不调用模型 |
| 背景局部修改 | 选区对应实际背景坐标，保护区域/商品/文字按规则核对 | 仅明确的新修改项调用一次 |
| 长标题/价格/声明 | 预览和导出一致，溢出被提示或在允许范围内适配 | 不用重新生图解决排版 |
| 部分失败与恢复 | 成功项保留，明确拒绝项单项处理，已保存结果恢复入库 | 未知提交不自动另发付费请求 |
| 导出失败和过期 | 同一批已选作品重新打包，权限与审核重新核对 | 不调用生成模型 |
| 多人审核与撤权 | 不能自审/越权；撤销成员或项目权限后停止有权范围外的写入/下载 | 不通过重试绕过授权 |
| 大集合 | 超过原读取上限仍能分页找到准确记录，计数与可见范围一致 | 使用替身/已有媒体 |
| 平台兼容 | content-only企业正常使用；ERP/CRM/MES、账号、通知、AI scope与试用策略保持正确 | 回归不发起无关模型调用 |

工程验证通过后，用一套已授权的真实品牌/产品资料，对比人工流程与工作台。重点记录首包完成时间、改价耗时、返工原因、最终采用版本及实际已知费用。真实样本尚未取得时，可以完成工程交付，但不能把模拟素材认作客户验收。
