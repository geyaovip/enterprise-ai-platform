# 轻量创作画布

2026-11-02，用户明确授权“评估后直接加”，并提供即梦“生成 / 画布”切换参考。该授权仅覆盖本页轻量范围，早期路线中的专业画布与视频扩建仍不自动推进。验收与发布状态见 [D-137](../137-轻量创作画布与验收.md)。

## 入口与范围

- 创作使用“生成 / 画布”两种模式。生成页不变成编辑器；已有创作进入画布时沿用同一项目，首次纳入最多20张现有项目图片，后续可通过添加图片选入。
- 画布支持上传、当前项目图片和企业共享素材、拖动与键盘排布、平移、缩放、适应视图、文字备注、图片等比缩放、移除节点、撤销/重做。最多100个节点，进行中的任务预留位置。
- 选中图片后输入修改要求，使用当前企业生图配置，结果追加到原图旁并避开已存在内容。未选图片时直接生图；原图与作品历史保留。
- 自动保存位置、尺寸、备注与视图；选中原图可直接下载。画布与创作项目共用名称、回收站和恢复。首版不提供图层合成导出、局部蒙版、连线流程、多人实时光标或视频节点。

## 复用取舍

Loomic 的 `canvas-editor.tsx` 依赖 Excalidraw、Next dynamic、主题、Supabase accessToken、自有画布保存/缩略图接口及 WebSocket/视频工具。整套移植会引入广义白板和额外数据契约。本版不复制其画布源码、不新增 Excalidraw 依赖，借鉴选区回调、恢复完成后保存与防抖同步思路，使用现有 React 和平台组件开发轻量交互。已有参考附件组件及 Loomic MIT 许可保留。

模型渠道、任务排队、幂等提交、Worker、审计、计量、素材处理/下载、项目权限、品牌约束和回收机制均复用平台现有实现。Toonflow 分镜链与 InvokeAI 本地推理/专业画布不接入本版；既有开源体验证据仍沿 [10](10-开源创作工具与即梦全流程体验.md)。

## 数据与权限

新增 `ContentCanvas`，每项目最多一个，字段为企业、项目、版本、节点/视图 JSON 与时间。关联企业和项目并随项目物理清理级联；日常删除沿项目软删除。其他应用表和权限不变。

节点只接受有限坐标/尺寸的图片资产编号或纯文本备注，不接受外部URL、HTML、脚本或任意插件。新素材导入重新检查权限；跨项目导入复制到目标项目，避免共享目标时扩展源项目权限。现有不可用素材可移动/移除，但缩略图、文件和生成仍检查当前权限。查看者不能修改，也不能借画布绕过作品审批下载草稿。

接口基于 `/api/v1/tenants/:tenantKey/apps/content`：

| 接口 | 行为 |
| --- | --- |
| GET /canvases?page=&q= | 当前可访问画布，20条分页 |
| POST /canvases | 新建私有项目画布，或为有写权限的现有 projectId 创建/返回画布 |
| GET /canvases/:id | 当前版本、节点、可访问素材元数据与未完成任务数 |
| PUT /canvases/:id | 携带 version 保存，冲突返回409 |
| POST /canvases/:id/images | 携带 version、nodeId、assetId 与位置导入，重复 nodeId 幂等 |
| POST /projects/:id/batches | 原有生成请求可选 canvas 绑定，原请求兼容 |

画布读写沿 `content.read/create` 和项目范围，生图另需 `content.ai.use`。画布绑定含编号、版本、可选原图节点与落点；提交在事务中验证同企业、同项目、原图与版本、容量，使用现有请求编号和预览凭证。旧请求的指纹与历史任务保持兼容。

Worker 在作品完成事务中追加结果节点，以任务编号作为节点编号，重放不会重复插图；与保存/提交共用画布锁。失败或未知结果继续沿现有状态与人工核对，不自动重试付费请求。

浏览器以企业/成员/画布隔离保留引用型草稿与原提交凭证；不保存模型密钥或图片base64。保存与生成前同步，远端新增结果和不同节点改动可合并；同一节点同时修改则保留本页草稿并阻止覆盖，用户明确放弃后再载入最新内容。离开未保存页面保留确认。撤销不跨越远端更新，避免抹掉异步结果。
