# 品牌内容创作官与企业模型配置

2026-11-02，D-135，按本轮用户新增要求实施；最终发布状态见[135](../135-内容创作官与企业模型发布.md)。

品牌内容创作官复用现有`content.assistant`及内容权限。入口在工作台顶栏，统一文案为“询问AI”；“品牌内容创作官”用于岗位身份和对话标题。对话提供创作需求、标题建议、品牌核对及生成进展四项快捷提问；点击只填入输入，不自动发送。项目内打开时带入当前项目引用，服务端仍核对成员与项目权限。官网新增第四位数字员工，与工作台共用职责定义，原十项工作场景保持。

企业管理的“应用与服务→企业模型”分别配置文字、生图、视频。每项只有模型名称、API地址和API密钥，保存不探测模型，不额外产生测试费用。密钥不回显，保存后关闭即清空前端字段；配置及恢复默认均走管理员权限，恢复默认说明密钥移除后果。文字沿现有企业配置；图像和视频沿现有基础设施加密存储，按企业与用途隔离，无新数据库迁移。

未自定义文字模型时，在平台显式启用默认渠道后使用既有批准的DeepSeek Flash。优先级为企业自定义、已有运营预配置、平台默认；不会借用其他企业的密钥。默认对话保持原试用政策，媒体自定义不会变成无限聊天授权，也不修改媒体请求限额。

生图继续使用Seedream兼容接口。预览与任务记录具体型号和渠道版本，Worker提交前复核；存在待处理或待核对图片任务时拒绝切换配置，不自动重发收费请求。平台默认渠道的旧任务指纹保持兼容。自定义生图请求实际使用所属企业的地址、型号和密钥；这些凭据不进入任务快照、素材或公开元数据。

视频模型可以独立保存和读取，默认型号沿用户指定的Seedance Pro Fast。本轮不扩展图片工作台的视频创作流程；该配置不作为视频生成已上线的宣传依据。官网数字员工职责聚焦现有图文与图片工作。

接口为`GET /api/v1/tenants/:tenantKey/model-settings`、`PUT .../:kind`与`POST .../:kind/reset`，kind为text/image/video。图像与视频使用版本校验，重置后保留递增版本并移除密钥，避免旧表单覆盖新配置。文字兼容原有配置接口与保存校验。
