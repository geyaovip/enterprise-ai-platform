## 资产列表选择交互续验

1. 即梦默认卡片以素材预览为主，批量模式显示选框。选中后，顶部出现选中数量、可用操作与取消选择。[默认](../../output/jimeng-audit-20261103/33-即梦资产默认.jpg) · [选中](../../output/jimeng-audit-20261103/34-即梦资产选中.jpg)
2. 工作台移除每卡重复的下载、参考图和更多按钮。鼠标悬停、键盘焦点进入或批量模式均显示原生选框。点击缩略图默认预览，在选择模式下切换选中状态。上方工具栏按单选或多选显示操作，保留企业权限和现有受保护下载入口。[默认](../../output/jimeng-audit-20261103/35-本方资产默认.jpg) · [单选](../../output/jimeng-audit-20261103/36-本方资产单选.jpg) · [多选](../../output/jimeng-audit-20261103/37-本方资产多选.jpg)
3. 隔离浏览器验证预览、Tab 到选框、空格选择、全选、实际 ZIP 下载、单选后用作视频首帧，以及 390 像素视口无横向溢出。触屏选框常显由 CSS 输入能力查询控制。[窄屏](../../output/jimeng-audit-20261103/38-本方资产窄屏.jpg)
