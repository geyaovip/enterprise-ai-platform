## 实际体验步骤

1. 重新进入昨天的“咖啡品牌冬季社媒宣传图”对话。原图和生成参数仍可查看，未重新生成原图。
2. 打开图片详情，操作标准下载。首次出现水印设置提示，保持默认并关闭；后续下载按钮有处理中反馈，但工具未捕获落盘文件。
3. 点击“用作参考图”，原图自动进入 Agent 模式输入区。随后切换到图片生成，核对 Seedream 4.5、1:1、2K、1 张及 3 积分，输入背景修改要求。收尾复核发现切换后参考缩略图已消失，提交前未重新添加；历史记录也没有参考附件。
4. 提交一次修改描述的新图生成：要求保留杯子、蒸汽和光线，把背景改为米色并去掉白色矩形。结果生成成功，积分 40 → 37；由于参考附件未确认保留，不将它记为参考改图成功。
5. 从修改结果点击“生成视频”。默认进入 Seedance 2.0 mini 的全能参考；切到首尾帧后，选择 Seedance 1.0 Fast，图片自动作为首帧。
6. 核对 5 秒、720P、单个输出、10 积分，提交一次固定镜头蒸汽视频。生成完成，积分 37 → 27。
7. 在列表中预览视频，实际观察到循环播放、播放时间推进和蒸汽运动。详情的原画流持续缓冲，单独保留未通过边界。
8. 打开图片的“智能改图”弹窗，试用点标记与撤销；没有点击应用，没有额外付费调用。
9. 点击“去画布编辑”，在新标签页自动建立含一个图片节点的画布。命名为“咖啡品牌·流程体验”，新增手动文本节点，输入“一杯在手，冬天慢一点”，拖动排布。
10. 等待已保存再刷新。画布名称、图片、文案和两个节点的排列保留；刷新后的视图重新适配，不等于保持原缩放值。
11. 关闭本轮新建的画布标签页，刷新原对话。三条生成记录、新画布入口和视频参数均可恢复。离开主创作页后再进入对话，记录仍可访问。

新图没有白色矩形，背景为米色，但杯身形状、蒸汽和台面同时发生变化。提交前截图中的参考槽为空，生成历史也没有参考缩略图，因此只能确认“修改描述后出图”，不能确认参考图被模型使用，也不能把外观变化归因为即梦参考编辑能力不足。先前口头更新中的“参考改图成功”已在本记录中纠正。为节约积分，没有重试；真正带参考附件的编辑效果仍待单独验证。

视频的列表预览中，杯子基本稳定，能看到蒸汽缓慢升起；本轮没有做逐帧像素保真或长视频稳定性评测。

智能改图使用的是独立的标记加文字界面，默认显示 Seedream 5.0 Lite；本轮只体验标记和撤销，不能把普通参考改图的结果当成智能改图模型效果。

## 对 UI 和交互的具体认识

### 主创作流程

- 左侧放对话和画布历史，中央集中一个输入区；输入、参考图和少量参数在同一处。
- 结果按时间追加，保留输入、模型、尺寸与来源；详情能看到图片生成到视频生成的过程。
- “用作参考图”直接把结果送回输入区；“重新编辑”回填需求；继续修改建议放在结果之后。
- 图片和视频详情的处理工具集中在结果上下文里，不需要用户先进入编辑器。

### 轻量修改与专业画布分开

- 智能改图是一个聚焦的弹窗：图片、标记、撤销、修改描述和应用。
- 画布是独立入口和独立项目，有节点、文本、连线、生成器、素材和导演工具。
- 手动文本是另外的节点。本轮没有证据表明它把 AI 生成的整张图片自动拆成可编辑标题、商品、价格等语义图层。
- 采用即梦的视觉与主路径，不意味着要把专业画布和全部高级工具搬进首版。

### 需要改进或谨慎采用的地方

- 切换 Agent / 图片生成会影响参考附件。本次切换后参考图消失，提交时未及时发现；界面应明确提示附件变化并在提交前显示有效参考图。
- 模型与参考模式相互限制。处于全能参考时旧模型不可选；要先切换到首尾帧。不可选原因依赖悬浮提示，用户容易困惑。
- 模型列表有滚动区域，旧模型位于下方；只看到列表中的文字不代表选项在当前视窗可点击。
- 上次已观察到切模型会重置输出数量；费用和数量必须随当前选择明确显示。
- 初次下载夹有水印设置，鼠标悬浮还有会员推广；企业工作台的核心下载流程应减少这些干扰。
- 专业画布仍有很高的工具密度。它适合独立的高级创作空间，不作为日常图文生成的默认首页。
- 本轮是桌面个人空间体验，没有验证移动端、团队权限、企业品牌规则或完整可访问性；不能据截图宣称这些能力通过。
