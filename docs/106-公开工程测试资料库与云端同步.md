在项目根目录执行：


```bash
systemctl status apaas-nasa-corpus.timer apaas-nasa-corpus.service
cat /opt/apaas/public-test-corpus/index/nasa-background.json
sudo systemctl disable --now apaas-nasa-corpus.timer
sudo systemctl stop apaas-nasa-corpus.service
```
