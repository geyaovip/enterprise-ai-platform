# 内容创作官与企业模型发布

2026-11-02，D-135，已发布至 https://zhixingark.cn 。用户要求新增内容工作台数字员工、更新官网，并明确文字、生图、视频均可在企业配置，对话先使用平台默认文字模型。

## 交付范围

- 工作台顶栏增加“品牌内容创作官”，复用现有内容助手、业务工具与权限。四项快捷提问为创作需求、标题建议、品牌核对、生成进展，点击只填入输入框。项目内打开时自动引用当前项目；已存在的对话保留自己的项目引用和历史。
- 企业管理的“应用与服务 → 企业模型”分别配置文字、生图、视频。每项只有模型名称、API地址、API密钥；保存即用、不探测、不增加连接测试。密钥加密、不回显，恢复默认有清晰的移除后果；图片配置使用版本保护，待处理任务完成前不能切换。
- 文字优先沿用企业自定义、已有运营预配置，最后使用平台显式启用的默认DeepSeek Flash。默认渠道只读取平台既有凭据，不借用其他企业的配置，原默认试用和自定义渠道额度政策保持。
- 生图按企业读取实际型号、地址与密钥，任务记录渠道指纹，Worker提交前复核。默认继续Seedream 4.5。
- 视频型号、地址与密钥可独立保存、读取、恢复默认，默认沿Seedance Pro Fast。本轮没有开放视频创作流程，不将配置界面表述为视频生成已经上线。
- 官网增加第四位数字员工，与工作台共用职责定义；沿六页、四应用、十场景结构，提供实际图片案例和申请开通入口。保留经D-134验收的工作台界面图，没有用本轮裁切不完整的截图替换。

所属契约与规范见[内容15](content/15-品牌内容创作官与企业模型配置.md)、[内容03](content/03-平台接入与数据契约.md)及[UI02](ui/02-组件与交互.md)。本轮无新增数据库迁移，无新增前端/后端依赖，没有给其他企业默认开通内容应用或扩大用户权限。
