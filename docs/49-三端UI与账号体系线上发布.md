1. 基于已运行镜像增量构建；生产依赖与本地锁定依赖一致检查通过，新增账号代码在镜像中可导入。后端与三端生产构建、网关路由检查通过。

4. 应用兼容迁移后切换API/Worker，健康通过再发布三个前端。此次迁移只增加账号/创建人字段并允许邮箱为空，没有删除旧业务数据。

6. 新旧release、镜像及三个前端版本ID均保留。回退前停止新写入、保留新增注册和业务回执；优先回退应用/前端并保留新增字段，不删除迁移或新注册数据。需要数据库恢复时按08在隔离库演练与核对，不能盲目覆盖生产。
