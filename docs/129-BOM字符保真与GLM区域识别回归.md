# BOM字符保真与GLM区域识别回归

日期：2026-10-30；D-129。状态：本地功能优化和真实模型实验完成，未部署。最后续跑的13项全部返回；续跑只使用GLM，没有新增Kimi调用。

## 结论

**针对旧31处错误，原30处身份误读中21处恢复逐字正确、1处无损拆列、8处仍错；另1处数量7误读成1，本次GLM读回了7，但该行身份又拆到了不同字段。按整行标注字段验收，实际是21处通过、2处部分改善、8处仍错。** 这不是31套独立图纸，也不是OCR修复了22处。

**不能把实验方案整体替换默认流程：同一批旧输入上，还产生12处原来正确、这次误读的身份文字；另有字段拆分和多机型范围丢失。** 旧64输入的严格整行匹配由1152/1186降至1046/1186，虽然实际身份文字错误由23降至18，仍未通过质量不退步的门槛。因此撤回GLM主识别自动附加局部图及试验附加提示；默认GLM主请求保留原强基础提示和整页图。保留冲突拦截、逐行比较、来源保护、任务兼容和用量保护等确定性改进。

以上是实验读数与代码验收的不同结论：22个原错误字段恢复是实验结果，不是22条整行通过或已上线的修复数；安全保留版本通过程序回归，但不能拿已撤回实验的76输入成绩冒充它的生产识别率。

## 样本与口径

- 原始问题来自D-127比较的124个模型结果，同图多模型、裁切及重编码结果有重复；30处身份文字错误、1处错量是错误出现次数。
- 本轮逐条追踪31处：GLM旧错25处、Kimi旧错3处、Terra旧错3处；对应28个不同的文件/行位置、12个文件输入、11张去重像素图。Terra的3处仅作跨模型对照，不能算作GLM原有错误的修复收益。
- 原有64个字节不同文件输入，像素去重61张；新增12个输入，合计76文件输入、73张像素不同图，1301条标注明细。相同来源变体和重编码不算独立客户项目。
- 新增：4份NASA装配PDF，各取整页及受控照片/扫描变体共8输入；旧中文线束资料新增2个受控扫描变体；2份新单零件PDF作负例。共6份新公开源PDF、115条正例明细，113条有单数量标注。没有新增真实手机拍摄正例。
- 新标注在调用前冻结并对照源PDF文字层及图面复核。模型包不包含标注或正确答案，未导入知识库；固定旧评分器，不把名称拆分或列错位改成通过。身份文字诊断另区分逐字正确、无损拆分和错误。
- 最终76个结果由两轮续测46次GLM成功请求、前阶段4个本轮GLM回执及26个同图同基础提示的历史回执组成。新增有局部图的请求28次；这是完整来源加局部图的实验，不是只发裁剪图。

## 已保留的本地功能优化

1. **按行比较两次视觉结果。** 优先唯一印刷序号，再用唯一精确身份对齐；重复序号无法唯一定位时不拿第一条硬配。不再因为一行有差异就给全页相同行添加差异提示。
2. **冲突身份不自动选物料。** 两次身份、版本或制造商读数冲突，或无法唯一对齐时，禁止自动绑定目录物料；保留原件与两次结果，让人工确认。不会根据已知测试答案或相似历史件号直接改字。
3. **冲突数量不自动采用。** 两次数量/单位/机型数量不一致，模型自己的原数量文字与结构化用量矛盾，或明确多机型却给无归属数量时，采用值留空、保留读数并要求核对。PC/PCS与2/2.0等确定等价表达避免无意义误报。
4. **按可见风险控制复核。** 本地默认GLM优先；Kimi最多一次有理由复核，显式禁用后不调用。版本后缀、小区域混合尺寸、数量自相矛盾等风险可触发复核；单纯表密、正常A/R及合法多机型表不必全部买第二次识别。保留BOM_VISION_GLM_FIRST=false恢复旧几何分流。
5. **局部图只保留给Kimi复核/既有Kimi首读路径。** 几何检测生成最多一个、含表头与首尾边界的候选区域，始终带整页来源，最多4MiB；不用OCR或生成式补画。GLM自动增加局部图的实验未通过整体回归，已从服务默认主流程撤回。Kimi新提示/局部图仅有有限控制样本，不能承诺完整组合收益。
6. **升级兼容旧任务。** 旧已完成任务继续查看和人工核对；提示/预处理版本变化后，禁止对旧结果追加复核，先返回409而不是清掉已有结果。原生结构化页同样提前拦截无效复核。
7. **保留有界用量和恢复。** 请求前持久化、摘要复用、最多一主一复核、未知/截断停止、不自动重试；GLM单次300秒、Kimi360秒，输出16384 Token、总量异常65536。规则/提示摘要随版本变更，避免复用错误配方。

这些功能提高冲突可见性和采用结果的安全性，不等于能确定纠正所有V6/V8等字符。BOM自动OCR交叉核验继续删除；知识库扫描文档转文本OCR保留。没有新增数据库迁移、自动知识入库或生产业务数据修改。
