# D-168 · 外部客户端六应用确认式记录操作

DeepSeek Harness 插件和 WorkBuddy 连接器共用知行方舟的记录提案和网页确认。连接时由用户选企业、按需勾选 `<app>.records`。旧只读授权继续可查。服务器按当前岗位提供工具，并在确认时再次检查授权、企业、记录版本和业务依据。

| 应用 | 新增、查询和修改 | 删除的业务动作 |
| --- | --- | --- |
| ERP | 采购草稿。修改本人草稿的备注或明细基础单位数量。 | 具备采购审批权限时取消本人采购草稿，保留单据历史。 |
| CRM | 运营任务草稿。修改本人草稿的标题、目标或方案。 | 取消本人任务草稿。 |
| MES | 生产计划草稿。根据已发布 BOM 准备计划，修改数量、截止时间或备注。 | 具备计划发布权限时取消未发布计划。 |
| GEO | GEO 项目。修改项目、品牌、竞品和采样配置。 | 停用项目及监测计划，保留历史报告。 |
| 品牌内容 | 创作项目。保存已定稿脚本为项目需求，修改项目名称或需求。 | 移入回收站，向未完成的生成任务发出取消请求。 |
| 制造业进销存 | 待审核制造订单。查客户、成品和仓库后准备接单，修改本人待审核单的交期。 | 取消本人待审核单。 |

## 客户端操作

1. 更新 Harness 插件，或导入 WorkBuddy 专家和同名连接器。明确要求开通记录提案权限并在网页勾选。
2. 先查记录及版本。AI 创建提案并给出确认链接；用户登录知行方舟，核对企业、改动和后果。
3. 点击确认才保存。两端均可凭提案 ID 回查实际记录和状态。取消、过期、权限变动和版本冲突均会保留原业务记录。

## 验收

隔离 PostgreSQL 使用 47 条迁移，覆盖 Harness 回调和 WorkBuddy 回调两套 OAuth/PKCE 接入，六应用读取及 36 次确认写入。233 项断言覆盖只读不发现写工具、提案不落业务、纯 Bearer 无法确认、重复确认、取消、旧版本拦截和真实回执。六个 Harness 包在隔离配置完成安装。WorkBuddy 生成六个专家和六个连接器 ZIP，沿用既有连接器标识。客户端协议测试使用自动化会话，真实桌面模型对话仍需逐个复测。
