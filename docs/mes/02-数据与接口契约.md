## 数据与事务

Owner为MES模块。迁移 `20261023110000_mes_v1` 新增8表：`MesMemberGrant`、`MesMaterial`、`MesBom`、`MesBomReview`、`MesPlan`、`MesWorkOrder`、`MesReport`、`MesCommandReceipt`。

- 业务UUID与tenantId共同约束跨表引用；数据库保存同企业FK、数量/状态CHECK和同产品唯一发布版部分索引。
- BOM行以JSON保存稳定行UUID及物料SKU/名称/类型/单位快照；计划保存不可变requirements和bomVersions。不是任意字段/代码配置能力。
- 写入序列化到企业MES事务锁，当前成员与应用行加共享锁，事务内重新鉴权、版本检查、业务写入、审计和幂等回执。此方案优先正确性，大型工厂并发容量需另测后细分锁。
- 每次写入携带UUID `requestKey`；同成员/命令/键相同参数返回原结果，不同参数409。前端失败保留键，不能因网络断开直接换键重写。
- 更新/状态操作携带正整数version；授权首次version=0，之后使用返回值。BOM审查还核对reviewId/reviewVersion。
- 列表默认20、最多100，page/q/status由服务端校验。物料选择器active=true，kind=production限成品/半成品；目录检索不自动带完整BOM树。

## 错误和恢复

400字段错误；403无权/停用/自审；404对象不存在或不在范围；409版本、状态、重复编号、数量、BOM循环/缺子BOM、待处理审查和幂等冲突。失败保留输入，版本冲突重新读取并人工核对；已有成功回执不重写。

迁移为增量建表，没有旧应用迁移脚本。回退应用前先关闭MES与AI闸门，保留已产生业务表，不以删表代替回退；生产执行需按平台备份/发布规范进行。

## D119：BOM视觉后台任务

复用AiTask（kind=`mes-bom-vision-v1`）、AiModelUsage及持久原件卷，无新增数据库迁移。权限要求：MES物料读取、BOM写入、MES AI使用；每次提交、轮询、原件读取、运行和最终交付重新鉴权。任务仅创建成员可见，其他成员及通用AI任务路由不可读取该任务。

基础路径 `/api/v1/tenants/:tenant/apps/mes/boms/intake`：

| 方法与后缀 | 行为 |
| --- | --- |
| POST `/jobs` | 上传与同步整理相同的source/productId，持久保存并幂等排队；返回id/status/reused |
| GET `/jobs` | 仅当前成员未完成任务列表，用于重新打开恢复 |
| GET `/jobs/:id` | 进度、来源、按页模型/差异、用量、有效期、完成后的核对候选；不发模型请求 |
| POST `/jobs/:id/cancel` | 停止当前任务；已发出用量不能撤销或视为零 |
| POST `/jobs/:id/recheck` | `{pageIndex:0..23}`，对完成任务尚未用Kimi的该页复核一次，重新核对 |
| GET `/jobs/:id/sources/:fileId` | 校验SHA的原件base64，仅成员原件权限下可见 |
| GET `/jobs/:id/sources/:fileId/pages/:page` | 已准备的PNG页，不从轮询重新渲染或请求模型 |

输入至多6文件、合计8MiB，图片至多1200万像素/单边10000；全部资料至多24页/300候选行，单个采用装配最多200行。保留原同步`POST /intake`和`POST /page`作本地解析/预览。

视觉sourceEvidence增加`vision:{jobId,fileId,pageIndex,models,usageIds,promptSha256}`及`sourceItem`。视觉method为`vision-glm`/`vision-kimi`，须factReviewed和对应事实快照。保存/发布验证租户、原件SHA、任务页、指定产品和真实reported模型回执，人工修改不覆盖源字段。没有可信几何框时不提交bbox/pageSize；模型不能制造定位框。

任务终态超过7天清理原件与页缓存，保留用量账本；历史已核对BOM保留来源摘要和审核依据。不是知识库文档，不自动索引客户附件。参见[分流规则](07-BOM视觉识别分流规则.md)和[本次测试/发布](../119-BOM视觉模型接入与发布.md)。
