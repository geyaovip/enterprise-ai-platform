# 数据与接口契约

## 数据与事务

Owner为MES模块。迁移 `20261023110000_mes_v1` 新增8表：`MesMemberGrant`、`MesMaterial`、`MesBom`、`MesBomReview`、`MesPlan`、`MesWorkOrder`、`MesReport`、`MesCommandReceipt`。

- 业务UUID与tenantId共同约束跨表引用；数据库保存同企业FK、数量/状态CHECK和同产品唯一发布版部分索引。
- BOM行以JSON保存稳定行UUID及物料SKU/名称/类型/单位快照；计划保存不可变requirements和bomVersions。不是任意字段/代码配置能力。
- 写入序列化到企业MES事务锁，当前成员与应用行加共享锁，事务内重新鉴权、版本检查、业务写入、审计和幂等回执。此方案优先正确性，大型工厂并发容量需另测后细分锁。
- 每次写入携带UUID `requestKey`；同成员/命令/键相同参数返回原结果，不同参数409。前端失败保留键，不能因网络断开直接换键重写。
- 更新/状态操作携带正整数version；授权首次version=0，之后使用返回值。BOM审查还核对reviewId/reviewVersion。
- 列表默认20、最多100，page/q/status由服务端校验。物料选择器active=true，kind=production限成品/半成品；目录检索不自动带完整BOM树。

## 路由

页面前缀 `/t/:tenantKey/mes`，API前缀 `/api/v1/tenants/:tenantKey/apps/mes`。下表API路径相对该前缀。

| 页面 | API与动作 |
| --- | --- |
| `/` | GET `/dashboard`，GET `/metadata` |
| `/materials` | GET/POST `/materials`；PATCH `/materials/:id` |
| `/boms`、`/boms/new` | GET/POST `/boms` |
| `/boms/:id`、`/boms/:id/edit` | GET/PATCH `/boms/:id`；POST `/publish`、`/reviews`、`/review-resolution`（均接该BOM路径） |
| `/plans`、`/plans/new` | GET/POST `/plans`；POST `/plans/preview` |
| `/plans/:id`、`/plans/:id/edit` | GET/PATCH `/plans/:id`；POST `/plans/:id/actions`（release/cancel）；POST `/plans/:id/orders` |
| `/orders`、`/orders/:id` | GET `/orders`、`/orders/:id`；POST `/orders/:id/actions`（start/cancel）；POST `/orders/:id/reports` |
| `/reports` | GET `/reports`；POST `/reports/:id/review`（approve/reject） |
| `/settings` | GET/PUT `/settings/access`；GET `/members`（仅有效MES成员摘要） |
| `/audit` | GET `/audit`（最近100条） |
| `/ai` | 通用 `/ai/*` 会话、异步任务、SSE、确认和记忆接口，scope固定mes |

公开契约：`mes.bom.create_draft`、`mes.plan.create_draft`，声明确认、schema和同事务执行；Reader仅公开bom/plan/order并重新鉴权。暂不登记ERP协作事件，不能从MES绕过所有者直接访问ERP表。

应用目录复用平台运营交付 `/operator/operations/tenants/:id/apps/mes` 和企业启用接口；不自动为所有企业开通。套餐应用目录动态读取manifest。

## 错误和恢复

400字段错误；403无权/停用/自审；404对象不存在或不在范围；409版本、状态、重复编号、数量、BOM循环/缺子BOM、待处理审查和幂等冲突。失败保留输入，版本冲突重新读取并人工核对；已有成功回执不重写。

迁移为增量建表，没有旧应用迁移脚本。回退应用前先关闭MES与AI闸门，保留已产生业务表，不以删表代替回退；生产执行需按平台备份/发布规范进行。
