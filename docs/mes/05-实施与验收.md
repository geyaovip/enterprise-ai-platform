# MES实施与验收

日期：2026-10-23。决策D-057。本记录保留D-057工作区和隔离QA事实；后续D-058真实模型与生产发布见[06](06-真实模型验收与线上发布.md)。

## 已实现

- 独立MES注册、路由、应用岗位及交付/启用接入；MES-only企业不依赖ERP授权。
- 物料、BOM草稿/修订/发布、多级需求展开、计划不可变快照、工单派发/开工、分批报工/审核、生产进度和审计。
- Provider事实/原生读工具循环、需求预览、BOM审查问题、一次确认业务草稿；独立MES助手白名单和默认关闭的生产AI闸门。
- 公共Shell、应用切换、手机菜单、AI浮窗与对象引用；全部业务页面、设置授权、列表分页和未保存输入保护。
- 收紧无效入口：已有报工不能取消工单，已分配完不再派工，有有效工单不显示取消计划；异步需求预览防重复请求，编辑后忽略迟到的旧预览。

## 验证环境

Node24.21.0；独立PostgreSQL容器 `suite-ui-20261020-db`，127.0.0.1:54329、数据库suite_phase1_qa。只在该库从25迁移增至26迁移；新增 `20261023110000_mes_v1`，未连接生产数据库。

自动测试使用 `erp-flow-test-mes-*`、`erp-flow-test-mes-ai-*` 独立假数据企业，结束清理所属企业和数据；独立模型计量账本保留模拟测试证据。浏览器QA端口API4636/Web4637，企业为显式假数据批次。

复现入口（在本项目目录执行，显式启动上述隔离DB后）：

```sh
pnpm --filter @suite/api build
node apps/api/scripts/run-mes-local-qa.cjs migrate
node apps/api/scripts/run-mes-local-qa.cjs mes-flow.cjs
node apps/api/scripts/run-mes-local-qa.cjs mes-ai.cjs
```

该脚本只接受列出的本地测试，读取专用容器凭据并仅传入子进程环境，不打印或写入凭据；不启动、迁移或清理其他数据库。
