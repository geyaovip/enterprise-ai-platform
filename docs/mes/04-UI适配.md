# MES UI适配

公共基线：ui/00 v1.4与ui/01～06；单一品牌紫色、共享Shell/ApplicationSwitcher、PageTitle、Field、Dialog、ConfirmDialog、DialogAction、Notice、Pager及AiConversation。独立注册MES应用，手机从菜单切换，不创建另一套账号和后台。

| 页面 | 核心内容/主要动作 |
| --- | --- |
| 生产概览 | 全范围或受派指标、合格进度、逾期、计划入口；新建计划/分析进展 |
| 物料 | 搜索/分页、类型、单位、启停；新建/编辑，身份字段只读 |
| BOM | 版本列表、行快照、当前审查/结论；编辑草稿、创建修订、人工发布 |
| 计划 | 编号、产品、数量、期限、不可变物料需求、工单；预览/保存草稿、发布、派工 |
| 工单 | 作业、受派、合格/不良、报工历史；本人开工/报工，无数据才取消 |
| 报工与审核 | 待审核/通过/拒绝、数量和依据；一次确认审核，不展示自审按钮 |
| 设置/审计 | MES岗位分配、真实写入历史；不新增平台级角色或第二个成员账号 |

列表查询显式应用/重置，URL保存q/status/page，返回保留条件；小型目录选择器支持搜索，超过50条提示缩小范围。多级明细用独立编辑页；小表单用公共弹窗、固定真实提交动作；编辑页路由和刷新均保护未保存输入。失败保留原输入和requestKey。

概览进度沿公共8px无边框progress，显示真实value/max和数量；二维业务表在自身容器横滚，手机明细字段重排。设置本期只有岗位一类内容，不制造空白目录。

AI顶栏与对象深链接使用同一浮窗（桌面560px，手机全屏）、独立mes scope、四个制造场景快捷问题。引用production/bom/plan/order；点击业务对象入口才带已保存ID，常驻入口不自动读背景对象。关键参数/确认/回执直接展示，默认记忆与有权知识不增加勾选。

共享AiConversation增补MES scope、对象名、快捷问题、结果返回；ERP/CRM/两个管理域保留各自行为。MES CSS仅维护业务布局，不重新定义主题、控件、进度条或AI外壳。

各视口/操作的实际证据以05为准，不把规范目标视为已经验证。原生手机键盘、辅助技术和真实模型另行记录。
