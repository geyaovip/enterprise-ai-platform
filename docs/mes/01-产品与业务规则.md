# 产品与业务规则

## 范围与能力来源

目标：电子制造团队从物料、BOM 到计划、工单、报工审核和生产进度的完整闭环；AI 使用当前生产事实形成可核对的分析和草稿。

| 来源 | 本期能力 |
| --- | --- |
| MES核心 | 物料目录、BOM版本/发布、多级展开、计划快照、派工、开工、分批报工、审核、进度、审计 |
| 平台公共 | 账号/企业/成员、应用交付启用、授权入口、AI Runtime/会话/记忆/任务/计量/确认、公开命令 |
| 后续独立建设 | ERP库存/采购关联、真实缺料、领退料、替代料、设备、质量检验、工艺路线、复杂排程 |

同 SKU 不代表与 ERP 相同商品。MES需求是理论用量，不表示库存、可用数、采购建议或实物流转。成员使用平台账号，不复制旧 MES 登录、注册或模型配置。

## 岗位与范围

平台管理员（本企业 admin）拥有MES所有业务权限，仍不能自审。其他成员通过 MES 设置授权一个应用岗位；不增加全局平台角色。

| 岗位 | 能力 | 数据范围 |
| --- | --- | --- |
| 计划员 | 物料/BOM维护、BOM发布、计划创建/发布、派工、AI | 当前企业MES |
| 主管 | 查看目录/生产、派工、报工审核、AI | 当前企业MES |
| 操作员 | 查看受派计划切片/工单、本人开工与报工、AI | 仅受派工单、本人报工；隐藏整单计划量和物料需求 |
| 只读 | 目录、生产与报工查询、AI分析 | 当前企业MES；没有写工具 |

MES关闭、成员失效或岗位撤销后接口立即拒绝；AI发送、工具、流式输出/终态、历史和确认分别复核。

## 物料与BOM

- SKU企业内唯一；SKU、类型、基础单位不可修改。成品/半成品基础单位固定为件；物料名称可修改，历史快照不重写。
- 新BOM只选有效成品/半成品；最多50行，组件不能重复或直接引用自身。用量为大于零的十进制字符串，最多3位小数；损耗百分比0至小于100，最多2位小数。
- 草稿可编辑；每次编辑版本递增，旧版审查不再作为当前审查。重新审查建立新记录，旧处理结论不会自动应用。
- 发布前核验当前版本、有效物料、多级环/深度（最多10级）、半成品子BOM、当前审查结论。同产品最多一个已发布版本，旧版归档。
- 计划展开使用当前发布的子BOM，记录整棵树所用版本。最多5000次节点访问/1000种叶物料；逐层精确运算，同物料汇总后向上保留3位小数。
- 当前审查的每条问题都要填写“核实保留”或“误报”及至少4字符的依据才可发布；若需改设计，编辑BOM使审查失效，再核对新版本。未用AI不阻断手工生产；确定性校验始终执行。
- 已发布BOM或未完成计划使用的物料不能停用。发布不自动修改ERP或创建采购。

## 生产闭环

1. 草稿计划选择同产品当前已发布BOM，数量为1至1000万的整数件，截止时间晚于创建/编辑时刻。服务端保存物料、用量和BOM版本快照。
2. 计划草稿可编辑；发布后不可编辑。后续BOM发布不会更改该计划快照。
3. 已发布计划派发工单：有效且有报工权的受派成员、正整数计划量；非取消工单合计不得超过计划量。派工同时递增计划版本，防并发分配。
4. 受派人开工后可分批报工；合格、不良非负整数且合计大于零。已审核数量+待审核数量+本次数量不得超工单量。
5. 主管/管理员审核，不能自审。拒绝需理由且不计进度；批准事务内重算数量、更新工单、报工和计划状态，保留所有原记录。
6. 工单已审核合格+不良达到计划量即结束。所有有效工单已结束且分配量等于计划量时计划结束；不良不会伪装为合格，结束时合格率可以低于100%。
7. 工单仅在无任何报工时可取消并释放分配量；计划仅在无有效工单时可取消。没有清空生产历史的删除入口。

进度=已审核合格数/计划量；不良独立统计。概览用数据库聚合全量指标，计划进度区域按截止时间展示最多20条；操作员使用受派量作为分母。
