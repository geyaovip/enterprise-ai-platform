# 管理端与官网体验优化

2026-11-02；D-134。已按用户授权完成优化、验收及上线。线上版本与边界见下方实际回执。

## 改动

企业管理：应用入口与岗位设置补齐CRM、MES、品牌内容；交付/启用、知识配置和成员环境分层表达，保留读取失败与配置缺失的区别。自定义模型不再误称“平台默认模型”，仍为三个字段保存直用。成员、部门和停用按钮包含对象名称，危险后果保留。

订阅与支持：空账单、授权和套餐使用卡片内紧凑空态；现有错误、读取状态、计费未知和授权流程保留。平台运营同步状态语义、对象名称和具体确认动作。

官网：保持六页、三位数字员工，增加第四个业务应用“品牌内容”和第十项内容创作场景；流程为需求生图→参考改图→原图下载。复用D-132真实生成的两张咖啡图，本轮不调用模型。品牌为虚构示例，开通入口联系管理员，不默认向所有企业开放。四应用卡片为2×2，手机单列。

## 验收与发布保护

浏览器在本地隔离数据库验收企业管理、平台运营和官网；成员运行中、读取失败、未配置、停用、首次启动、排队及启动失败由本地替身提供，仅用于状态展示，不构成真实运行服务验收。模型生成在该验收环境强制阻断，配置展示使用替身；官网生成图来自D-132真实回执。

仅发布三个前端及对应文档。API、Worker、Prisma迁移、模型凭据、会话、试用额度和其他业务逻辑保留；不提高生产账号平台运营权限，不调用生成模型，不保存生产授权或记账。

冻结发布源基于D-133归档，按明确白名单复制修改。后端及其他业务文件逐项哈希核对，前端保留上一版静态资源，避免已打开页面加载失败。三个前端与服务器源码指针分别有明确旧版本可回退。
