# 官网与应用介绍页

更新：2026-10-23。D-040原方案在D-053进入整体实现，D-059补齐MES与品牌/正式域名；当前实施/验证/发布状态见[56](56-官网与独立产品页上线.md)和[47](47-项目现状与文档维护.md)。原2026-10-14的“CRM准备中、介绍页未实现”为历史阶段，已由当前状态覆盖。

## 当前入口与职责

| 路由 | 职责 |
| --- | --- |
| `/` | 知行方舟总官网，产品选择、公共能力与使用入口 |
| `/products` | ERP、电商CRM与MES目录及当前交付范围 |
| `/products/erp` | ERP适用团队、进销存/账款/协作、真实演示界面、业务流程与AI使用条件 |
| `/products/crm` | 电商客户数据、购买/复购、分群、人工运营任务、效果观察及当前边界 |
| `/products/mes` | MES物料、BOM、多级需求、计划/工单、报工审核与受控AI |
| `/login`、`/register` | 统一账号密码入口；应用按企业和成员授权使用 |
| `/t/:tenantKey/erp`、`/t/:tenantKey/crm`、`/t/:tenantKey/mes` | 登录后的实际业务应用；与公开介绍页分开 |

采用一个品牌总官网、各应用独立产品页，共用域名与发布，不新增独立官网服务、API或数据库。独立产品页可直接分享，刷新无需登录；账号、企业与应用授权继续由平台控制。

## 公开表达

- 各应用单独介绍适用团队、具体业务、真实产品画面、工作流程及入口；当前功能与未来规划明确区分。
- ERP、CRM、MES已有业务版本，按企业授权开通。CRM以人工经营能力为当前范围，AI尚未开放；不宣传已接通电商平台、自动群发或会员权益。
- ERP助手按已授权业务事实与操作提案介绍，需企业启用和模型配置；重要写入保留人员确认。
- 产品截图仅含演示数据；不公开账号、企业身份、真实客户资料或竞品截图，不使用未经验证的收益数字。
- 复用真实注册/登录流程，不增加无人接收的试用/咨询表单、虚构价格或无效联系入口。

## UI、路由与索引

公共UI见[ui/00](ui/00-公共UI规范.md)，官网适配见[ui/07](ui/07-公开官网与产品页.md)。五页共用页头/导航/页脚、紫色品牌、字体与组件，产品只承担业务内容差异。

公开HTML在构建时生成，无需启动业务React或查询租户数据。私有应用由app.html启动，保持noindex；产品未知路径返回404。尾斜杠和index.html形式重定向到规范公开路径，保留来源参数。具体见[05](05-路由与接口契约.md)。

每页独立title、description和分享图；sitemap只含公开五页。正式域名为zhixingark.cn，canonical、og:url、分享图片与sitemap统一正式来源，详见ui/08。D-060补齐组织/站点/网页/面包屑及产品结构化数据、图片抓取、真实404及分享信息；旧公开官网308至正式域名，登录/企业/API保留兼容。实际发布见[60](60-官网代码SEO优化与发布.md)。

## 验收

1. 未登录直接读取五页完整正文，深链接刷新正常，不出现业务壳或登录墙。
2. 产品导航、跨产品链接、页内锚点、注册和登录入口真实可达；登录后由现有授权规则选择企业和应用。
3. 桌面、平板、手机及320px窄屏不横向溢出；菜单键盘操作、图片比例、焦点和减少动态效果可用。
4. 业务、管理端、Cookie/API路径维持原契约；已打开客户端所需的旧哈希资源继续保留。
5. 公开描述与实际交付相符，工程验证不代替原生手机、搜索收录、真实模型或客户业务验收。

当前品牌/域名规则见[UI08](ui/08-品牌与正式域名.md)，发布和验证见[59](59-品牌官网与正式域名发布.md)。
