# D-155 官网业务场景与首屏优化

2026-11-07 按用户授权发布至[正式官网](https://zhixingark.cn/)。发布范围为首页和五个公开栏目。

## 走查与对照

1. 线上原首屏的通用插图占据了大部分空间。访客点进其他栏目才能看到一个具体结果。
2. 首页连续陈列数字员工、场景和应用，三组入口的侧重点需要访客自己理解。业务应用页的应用名称适合已知道要找什么的访客。
3. 参考 Linear 把具体工作放入首屏的产品示例、Rippling 按需选择应用的路径、Notion AI 把能力选项与产品界面并排呈现的结构。[Linear](https://linear.app/)、[Rippling](https://www.rippling.com/)、[Notion AI](https://www.notion.com/product/ai)

## 改动

- 首页四个静态可切换示例覆盖订单缺料、客户回访、BOM 核查和 AI 品牌可见度。可读的结果放在界面图之前。产品图使用隔离环境的实际界面及示例数据，完整界面可放大。
- 五个工作问题各自链接到完整场景与对应业务应用。独立介绍原文依据、访问权限与人员确认，提供数字员工、企业知识和邮件咨询入口。
- 官网导航优先排列工作场景，栏目标题区缩短，工作场景选择器整理为桌面六列、手机三列，五个应用在手机上采用三加二布局。沿用六条规范路径及旧链接兼容。
