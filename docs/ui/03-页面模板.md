# 公共页面模板

D-114（2026-10-29）：企业管理「应用与服务」保留一个「企业自定义大模型」区块，只填模型名称、模型API地址和API密钥后保存；不增加来源模式、连接测试按钮或必须先测试的步骤。保存不代表模型可用，失败在实际使用时按现有错误方式反馈。见[114](../114-企业自定义大模型简化.md)。

D-073：邮箱登录继承Turnstile与服务端倒计时；不常驻真人勾选项，必要挑战使用compact居中，避免窄屏裁剪；迟到但未提交的有效校验结果在当前组件短暂保留，不要求重复验证。见[73](../73-登录防刷与Turnstile.md)。

D-072：三端账号页统一为邮箱验证码登录，首次验证后自动创建账号，不再展示独立注册/日常密码登录；历史账号关联与账号安全沿[72](../72-邮箱验证码登录与会话持久化.md)。默认已登录时进入原企业空间，不因普通更新重新验证。

更新：2026-10-28。各应用按本页组织页面，字段和业务状态由应用适配文档定义；公共组件行为见 [02](02-组件与交互.md)。模板是设计结构，不代表已有通用页面生成器。

| 类型 | 推荐结构 | 主动作与恢复 |
| --- | --- | --- |
| 概览 | 当前企业/应用→时间范围→关键指标→待办/近期事项 | 查看具体事项；空企业给有权初始化入口，未知指标不先填0 |
| 业务列表 | 单一主标题→主操作→类型/筛选→结果→分页 | 查询/重置、创建、查看详情；恢复已应用查询和位置 |
| 资源详情 | 返回＋资源名称/状态→主要业务内容→下一步→历史/依据 | 根据状态与权限办理；返回逻辑父级，关联资源单独链接 |
| 创建/编辑 | 返回＋页面标题→基础字段→对象/明细→必要设置→保存/提交 | 真实校验、防重、版本冲突、失败保留输入、离开保护 |
| 分步导入 | 文件/来源→映射→校验预览→确认→后台结果 | 每步明确已保存范围；提交后从批次地址恢复，错误可定位 |
| 批量任务 | 选定范围→完整预览→确认→执行/部分结果 | 说明选择范围、影响数量、取消边界；结果不明先核实 |
| 双栏工作区 | 左列表/分组→右默认详情 | 当前选择明确，窄屏分级并保留列表位置 |
| 设置 | 左目录→右默认内容→就地保存/反馈 | 个人/企业/平台权限分开，刷新可回到合理位置 |
| 报表分析 | 口径/窗口/截至时间→结果→明细/依据 | 指标名称、周期和单位清楚，必要口径使用短标签，不常驻大段解释，不把相关性写成归因 |
| 通知/任务中心 | 未读/类型→消息/任务列表→详情→实际办理入口 | 已读与完成分开，直达有权对象或具体任务 |
| 打印/导出 | 明确范围与版本→纸面内容/文件→校验结果 | 隐藏导航/操作区，保留标题、金额、单位与页内可读性 |

## 页面文案与清晰度

继承[UI02文案规则](02-组件与交互.md#界面文案与信息密度2026-10-28d-093)。页面标题、主操作、筛选和结果形成稳定层级；同一区块不再叠加重复的小标题、副标题或操作教程。空态保留当前原因与可执行下一步，错误不隐藏；创建/编辑保留可见标签、单位、必需校验和提交后果。以新用户能辨认“下一步点哪里、点击后发生什么”为验收条件。

## 标题、返回与操作区（D-095）

桌面业务页标题初始在内容区，滚动离开后进入固定顶栏；手机一级、二级页面标题从首次显示起就在顶栏，内容区不重复标题或预留空白。一级页左侧为导航，二级页为返回。表单字段、备注、预览/保存操作分区留白，不把操作行直接贴在上一区块底部。桌面两列在手机变单列后仍使用相同纵向间距。该手机规则按D-102覆盖D-095的初始位置规则。

独立业务列表和详情中的只读记录集合遵守UI02分页规则；编辑中的单据行、BOM录入行、批量导入核对与打印/导出文档按完整编辑或纸面范围组织，不将界面的分页切片误用于实际保存、批量选择或导出。导航菜单、固定统计卡片和业务正文不机械增加分页。

## 表格、卡片与详情

表格优先展示名称、关键状态、业务结果和更新时间，操作位置一致；长文本可省略但提供全文路径。横滚限制在表格容器；行可点击时提供键盘入口，避免把行按钮与内部按钮嵌套。

信息卡按名称、实际状态、数据和时间组织，不默认填充功能介绍段落；同类卡片对齐，封面保持实际比例，无图使用等尺寸占位。图片和媒体有内容意义时才放入；下载对应当前真实资源/版本。

详情先展示主要内容和结果，确有第二类内容才加页签；只读不伪装成禁用表单。编辑和详情的字段口径一致，历史版本标明时间、版本和可执行范围。

## 登录、注册与企业引导

三端共用 `AuthScreen`，各端仅传递登录标题，沿同一邮箱身份和会话。`/register`收敛至`/login`，不另建CRM/MES登录页。

- 当前采用邮箱验证码登录，无独立注册、日常密码登录或旧账号迁移入口；公开验证码校验不接受原账号密码。
- 邮箱、六位码输入和登录按钮始终同屏，获取/重发及倒计时位于验证码右侧，发送后只更新状态提示并聚焦验证码。使用一个支持自动填充、数字键盘和完整粘贴的输入框，不拆分六个焦点；修改邮箱清除旧挑战，切回同邮箱保留未结束冷却。见[80](../80-单页邮箱验证码登录与发布.md)。
- Turnstile按需显示，通过后自动收起；发码与登录分别展示明确等待状态。重发倒计时来自后端，不阻止输入已有验证码登录，失败不得自动重复发信。
- 已有会话按180天续期/365天绝对期限保留，普通发布不清理登录。本人邮箱设置保留验证码验证，不支持两个账号合并或转移成员权限。
- 没有企业的普通用户进入企业引导，自行创建企业或接受管理员邀请；邮箱验证不授予平台角色或其他企业权限。
- 不展示验证码日志、密钥和调试参数。认证接口与当前验证见[72](../72-邮箱验证码登录与会话持久化.md)、[73](../73-登录防刷与Turnstile.md)、[75](../75-邮箱登录交互与移除账号迁移.md)，状态见[47](../47-项目现状与文档维护.md)。

## 角色、范围与跨端导航

工作台供成员处理业务；企业管理处理本企业组织、服务和知识；平台运营处理已授权运营职责。用户、租户、应用、对象权限逐层核对，跨端共用身份不扩大权限。

企业和应用可识别但不重复摆多个选择器。切换范围处理未保存内容、关闭旧范围显示和订阅，重新取得当前权限。跨端链接使用部署配置的可信来源；从通知或AI打开详情仍重新鉴权。

## 公开官网与产品页

公开页面使用同一品牌、字体和语义颜色，采用营销页面排版，展示产品适用人群、业务结果、真实截图与当前状态。应用介绍和登录后的业务地址分别维护。具体路由、搜索收录、素材和交付状态见 [44](../44-官网与应用介绍页.md)；规划中的 CRM 产品页不能标成已上线。


### 注册与登录的等待反馈（D-064）

- 三端共用账号模板；提交期间锁定输入、防连续提交，8秒出现等待提示，20秒超时恢复操作。
- 注册超时/断网不等于注册失败，应提示结果待确认并引导先登录；不自动重复POST。
- 20秒仅用于账号注册/登录请求，不作为AI或其他长任务的全局超时。
