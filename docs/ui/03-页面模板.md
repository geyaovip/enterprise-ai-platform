# 公共页面模板

更新：2026-10-23。各应用按本页组织页面，字段和业务状态由应用适配文档定义；公共组件行为见 [02](02-组件与交互.md)。模板是设计结构，不代表已有通用页面生成器。

| 类型 | 推荐结构 | 主动作与恢复 |
| --- | --- | --- |
| 概览 | 当前企业/应用→时间范围→关键指标→待办/近期事项 | 查看具体事项；空企业给有权初始化入口，未知指标不先填0 |
| 业务列表 | 单一主标题→主操作→类型/筛选→结果→分页 | 查询/重置、创建、查看详情；恢复已应用查询和位置 |
| 资源详情 | 资源名称/状态→主要业务内容→下一步→历史/依据 | 根据状态与权限办理；返回逻辑父级，关联资源单独链接 |
| 创建/编辑 | 基础字段→对象/明细→必要设置→保存/提交 | 真实校验、防重、版本冲突、失败保留输入、离开保护 |
| 分步导入 | 文件/来源→映射→校验预览→确认→后台结果 | 每步明确已保存范围；提交后从批次地址恢复，错误可定位 |
| 批量任务 | 选定范围→完整预览→确认→执行/部分结果 | 说明选择范围、影响数量、取消边界；结果不明先核实 |
| 双栏工作区 | 左列表/分组→右默认详情 | 当前选择明确，窄屏分级并保留列表位置 |
| 设置 | 左目录→右默认内容→就地保存/反馈 | 个人/企业/平台权限分开，刷新可回到合理位置 |
| 报表分析 | 口径/窗口/截至时间→结果→明细/依据 | 指标名称、周期和单位清楚，必要口径使用短标签，不常驻大段解释，不把相关性写成归因 |
| 通知/任务中心 | 未读/类型→消息/任务列表→详情→实际办理入口 | 已读与完成分开，直达有权对象或具体任务 |
| 打印/导出 | 明确范围与版本→纸面内容/文件→校验结果 | 隐藏导航/操作区，保留标题、金额、单位与页内可读性 |

## 表格、卡片与详情

表格优先展示名称、关键状态、业务结果和更新时间，操作位置一致；长文本可省略但提供全文路径。横滚限制在表格容器；行可点击时提供键盘入口，避免把行按钮与内部按钮嵌套。

信息卡按名称、实际状态、数据和时间组织，不默认填充功能介绍段落；同类卡片对齐，封面保持实际比例，无图使用等尺寸占位。图片和媒体有内容意义时才放入；下载对应当前真实资源/版本。

详情先展示主要内容和结果，确有第二类内容才加页签；只读不伪装成禁用表单。编辑和详情的字段口径一致，历史版本标明时间、版本和可执行范围。

## 登录、注册与企业引导

三端共用 `AuthScreen`，各端仅传递登录标题；公共 `/login`、`/register` 使用相同品牌、字段布局、错误反馈和密码显隐，不另建 CRM 登录页。

- 系统账号密码为当前认证方式；注册无需邮箱或第三方应用，原邮箱账号兼容。账号格式、密码长度和接口以 [身份契约](../46-三端AI助手与系统账号注册.md) 为准。
- 注册成功回到登录，保留账号、清空密码；错误保留可修正输入。不得默认选择平台运营身份或要求用户用界面选择角色。
- 没有企业的普通账号进入企业引导：创建自己的企业，或接受管理员邀请；已有成员也可从工作台账号菜单/企业选择页进入 `/onboarding`。
- 创建企业、邀请加入、账号注册为不同结果，分别呈现成功。新注册不会自动获得平台运营权限；无权管理端提供进入工作台和切换账号入口。
- 界面不展示密码、密钥、验证码日志或开发参数。账号恢复复用受控邀请/恢复流程，不制造未接通的邮件或短信入口。

以上新流程已本地实现，生产是否具备以 [47](../47-项目现状与文档维护.md) 的环境状态和发布记录判断。

## 角色、范围与跨端导航

工作台供成员处理业务；企业管理处理本企业组织、服务和知识；平台运营处理已授权运营职责。用户、租户、应用、对象权限逐层核对，跨端共用身份不扩大权限。

企业和应用可识别但不重复摆多个选择器。切换范围处理未保存内容、关闭旧范围显示和订阅，重新取得当前权限。跨端链接使用部署配置的可信来源；从通知或AI打开详情仍重新鉴权。

## 公开官网与产品页

公开页面使用同一品牌、字体和语义颜色，采用营销页面排版，展示产品适用人群、业务结果、真实截图与当前状态。应用介绍和登录后的业务地址分别维护。具体路由、搜索收录、素材和交付状态见 [44](../44-官网与应用介绍页.md)；规划中的 CRM 产品页不能标成已上线。
