# 应用身份与切换

更新：2026-10-23。所有新业务应用继承本契约。参考用户所附 WorkBuddy 的当前应用胶囊、搜索、最近使用和应用列表层级；主题、基础组件与 AI 外壳继续沿自动化运营公共基线。

## 信息层级

- 平台品牌和企业名称独立显示；当前应用具有图标、名称和展开箭头，不与业务菜单混排。沿D-051不重复展示用途介绍段落。
- 侧栏只展示当前应用的有权菜单，ERP 不附加 CRM 入口，CRM 不展示 ERP 业务设置。
- 企业公共服务与账号继续复用；访问知识、通知、账号时保留当前应用上下文，不自动切回 ERP。
- PC 从侧栏顶部应用胶囊打开；手机先展开菜单，再从菜单顶部同一入口切换应用。手机顶栏仅保留菜单、页面标题与AI入口，不重复放置应用切换。

## 应用面板

- 提供搜索、最近使用、企业已开通、当前状态及“进入”提示。整行可点击，直接进入，不增加选中后的确认步骤。
- 仅显示服务端已交付、企业已启用、用户可访问且已有前端注册的应用。不用假推荐、未交付 MES 或空应用商店填充。
- 名称 / 简称 / 用途即时筛选，无结果有明确空态；最近使用来自当前账号、企业、浏览器会话的实际访问。
- 原生 dialog 提供焦点限制和背景隔离；打开聚焦搜索，Tab 移动、Enter 跟随链接、Esc / 关闭 / 点击外部收起并返回入口。侧栏快捷键让位于最上层 dialog。
- 桌面宽400px、圆角20px；手机距左右12px，自适应宽度。长列表独立滚动，关闭、搜索和说明可达；不改变普通业务弹窗规格。

## 切换与恢复

- 使用 React Router 链接，保留已有编辑器的未保存离开保护，不强制刷新绕过提示。
- sessionStorage 按用户 / 企业 / 应用记录上次菜单页；不存表单、名单、详情对象、搜索内容，不跨设备同步。
- 恢复前按当前菜单权限复核，只能回本企业、本应用的允许菜单；详情、AI、外部或失效地址不恢复，无记录回有权概览或首个菜单。
- 应用标识、菜单、页面及 AI scope 同步；切换关闭旧 AI 浮窗，历史仍归原应用。CRM AI 闸门按 CRM15，不因 UI 改动开启。
- 单应用企业仅显示实际已开通应用，当前身份仍明确，不补虚构入口。

## 公共实现与接入

`ApplicationSwitcher` / `ApplicationChoice` 从公共 components 导出，`application-switcher.css` 从公共 styles 引入；图标来自 lucide。工作台提供可信目录、有权目的地和最近使用；`apps/web/src/application-navigation.ts` 管理受限恢复。管理端继续使用独立管理域，不混入业务应用目录。

新增应用注册简称、用途和路由后复用本组件。验收包含双应用 / 单应用、撤权、搜索、历史、公共服务、未保存离开、手机、Tab / Esc / 焦点。实际环境和边界见[52](../52-应用切换体验优化.md)。
