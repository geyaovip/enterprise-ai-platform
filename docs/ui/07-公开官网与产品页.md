# 公开官网与产品页

更新：2026-10-23，D-053/D-059。官网与应用共用品牌、紫色语义、字体及基础交互；公开页采用营销布局，后台页面继续使用业务Shell。

## 页面结构

- 首页：一句定位、真实产品画面、ERP/CRM/MES入口、公共能力、ERP助手、交付、常见问题与账号入口。
- 产品目录：已提供的ERP和电商CRM分开介绍，MES已有独立产品页，介绍当前制造执行业务与受控AI。
- 应用产品页：适用团队、核心工作、真实界面、功能、业务流程、当前范围及关联应用；每页可以独立分享。
- 不公开任何租户业务页面或账号信息。产品图使用明确标记的演示数据；截图去除账号、企业身份及私有联系方式。

## 视觉与交互

- 主色/悬停/浅色背景沿公共主题 `#6554D9 / #5543C4 / #F0EDFF`，正文/边框沿公共规则；平台与三应用使用共享原创矢量标识，源与使用规则见[UI08](08-品牌与正式域名.md)。
- 页面共享页头、产品导航、页脚、按钮和间距，不给不同产品重新造主题。官网没有业务侧栏。
- 内容区最多1184px；840px以下导航收进菜单，支持Esc收起并回到按钮，点击导航后关闭；320px至桌面可阅读。
- 主要链接使用真实a，触控区域至少44px；焦点可见，支持减少动态效果。公开文案保留价值、范围和必要使用条件，减少重复理念与技术细节。
- 产品截图保留完整信息比例，不拉伸、不把示意包装成真实经营结果。图片均为静态展示，真实操作进入登录后的应用。

## 内容和边界

ERP介绍采购、销售、库存、账款和岗位协作；电商CRM介绍购买行为、复购、分群、人工任务和结果观察。CRM AI尚未开放，自动外部同步/群发/会员权益不在当前范围；不虚构客户案例、转化数据、价格和联系方式。

注册/登录链接复用现有账号流程；应用依赖企业开通与成员权限，不将注册等同于所有应用自动可用。未提供真实接收流程时，不放空咨询表单或无效试用按钮。

## 渲染和索引

五个公开页构建成可匿名读取的HTML，公开页不加载业务React入口；应用壳为独立app.html。业务、登录、注册与管理入口保持noindex。

每页独立title、description、OG分享信息；ERP/CRM/MES使用各自演示产品图。sitemap只列五个公开页。D-060起robots声明正式地图并限制API抓取；账户、企业和管理HTML用meta及响应头noindex，不在robots中阻止爬虫读取noindex。正式来源为 `https://zhixingark.cn`，构建与Worker的 `PUBLIC_SITE_ORIGIN` 统一canonical、og:url和sitemap；www以308跳转主域。品牌、来源与多端路由规则见[UI08](08-品牌与正式域名.md)。

路由契约见[05](../05-路由与接口契约.md)，实现/发布证据见[56](../56-官网与独立产品页上线.md)。

## SEO代码契约（D-060）

- 五个公开页输出完整HTML，唯一title、description、H1、canonical；OG/Twitter元信息及图片alt一致，OG包含实际尺寸。首页预加载主图，非首屏截图lazy/async且明确宽高。
- JSON-LD共用可见内容源：Organization、WebSite、WebPage/CollectionPage、BreadcrumbList、产品ItemList、应用SoftwareApplication。无公开价格、评分和评论时不添加相关字段，不宣称已满足Google软件富媒体展示资格。
- 旧workers.dev仅公开官网、公开别名和robots/sitemap永久308至正式来源，保留查询参数；企业/登录/管理/API不随SEO规则跳域。
- 普通未知公开路径返回真实404；保留已知账户和/t/:tenant/*业务壳。noindex用于私有HTML、品牌页及错误响应，公开产品图片和品牌图形可抓取。robots不替代鉴权。
- sitemap只含五个规范URL，不用构建时间伪造lastmod、priority或更新频率。构建后运行public-pages、cloud-routes与seo检查；发布后核对正文、响应头、重定向/404、robots/sitemap及业务兼容。实际结果见[60](../60-官网代码SEO优化与发布.md)。
