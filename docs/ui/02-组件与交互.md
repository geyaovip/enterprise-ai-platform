## 按钮与表单

2026-11-03 D-144：标准输入、下拉和按钮共用9px圆角和常规40px高度；创作输入区、AI对话输入和紧凑工具保留各自合理尺寸。主操作用品牌填充，普通按钮用表面底色和细边，列表操作沿用文字样式；AI入口默认透明、悬停/展开才显示柔和底色。企业名称属于静态上下文，使用普通文字。复合控件只由外层显示焦点，保持Tab、方向键、Enter、Esc、原有字段标签和危险操作后果。不要在应用内重新覆盖全部按钮或字段样式。验收与前后对照见[144](../144-公共控件视觉统一与发布.md)。

D-140：账号菜单内的`AppearancePicker`使用有可见“外观”名称的fieldset和三项真实按钮，文字为“浅色 / 深色 / 跟随系统”，以`aria-pressed`表达唯一选择；保留Tab、Enter/Space、可见焦点。切换外观不关闭菜单、不提交表单、不退出账号；Esc沿账号菜单规则关闭并恢复头像/昵称入口焦点。默认、持久化与配色契约见[01](01-视觉与布局.md#浅色深色与跟随系统)。

2026-11-03补充：弹窗通过`open=false`关闭和条件渲染直接卸载，都必须恢复到仍可见的触发入口。从列表“更多”打开的弹窗恢复到“更多”，不能落到已隐藏的浮层选项或页面背景；存在其他打开弹窗时不抢夺焦点。验收覆盖真实浏览器的关闭、Esc、点外关闭和窄屏，DOM替身不代替原生浮层行为。

### 界面文案与信息密度（2026-10-28，D-093）

2026-10-31补充：本节同样约束独立主题的创作应用与其兼容页面/弹窗；品牌内容不得因参考即梦而加入默认 slogan、重复模式标签或教学段落。主操作须可识别，例如“生成图片”；必要费用、范围、阻断和危险后果直接可见，次要规格使用 info＋tooltip。应用适配与验收见[content/02](../content/02-创作交互与UI规范.md)。

- 默认只保留标题、必要字段标签、主操作、真实数据和状态。避免不必要的次要标签、说明文字、辅助文案、描述性文字及冗余微文案；不默认添加 slogan、教学段落或每个区块下的帮助说明。
- 由布局、视觉层级、间距、分组和清晰的主操作解释界面。重写时先去掉冗余标签和说明；清晰度下降时优先优化结构与按钮文案，不立刻补回解释段落。
- 操作使用具体动词和对象，如“选择 CSV 并预览”“确认导入 12 条”“撤销授权”。去掉说明后，新用户仍应能识别下一步入口、操作对象和点击结果。
- 确需补充的筛选条件、指标口径、格式/数量限制等次要信息，优先放在相关标题、字段或按钮旁的 info 图标与 tooltip。直接删除没有信息价值的内容，不把全部旧文案搬入提示。
- 保留必要的可见表单标签和可访问名称；placeholder 只承载示例或格式，不替代标签，也不重复“请输入＋字段名”。图标按钮必须有具体可访问名称，如“高价值沉睡筛选条件”，不能统一命名为“提示”。
- 必填、单位、错误及恢复方法、权限限制、未保存离开、金额/库存影响、批量范围、授权范围、删除与不可逆操作的后果必须在做决定时直接可见，不得仅放在 tooltip 中。不可通过精简文案隐藏实际限制或改变业务含义。
- 业务方案正文、客户记录、审计回执、原文引用和数据来源属于用户内容，按业务需要展示；不按装饰文案批量删除。成功/失败/处理中等真实反馈保留，默认能力无须常驻解释。
- 公共组件 `InfoTip` 由三端及应用共用：鼠标悬停、键盘焦点及点击可展开；图标有名称，触发器以 `aria-describedby` 关联 `role="tooltip"`；Esc先关闭提示，再交给所属弹窗，失焦/点外部关闭。指针可进入提示阅读，窄屏防越界，触屏可点开，不能依赖原生title或hover作为唯一入口。提示内不放操作或必需表单。
- 不为整洁移除读屏名称、键盘焦点、状态播报、错误关联和危险确认；不能只用颜色表达状态。保持标题语义及合理阅读顺序，不增加无意义的隐藏说明。

本次全量源码检查、代表页面的浏览器验证及范围见[93](../93-全页面文案精简与UI规范.md)。

- 页面、表单、弹窗每组突出一个主要动作；普通动作灰底细边框，主动作紫底。记录行操作按下一节使用主色文字。永久删除/不可逆后果才用危险语义；放弃本轮输入采用普通副动作。
- 导航使用链接，状态变更使用真实按钮和 form。提交有真实 disabled/防重，按钮尺寸稳定；失败保留输入，聚焦错误或提供明确错误定位。
- 字段标签在上，错误在下并与输入关联；可选补充信息优先用相邻info提示。PC按内容可两列，长文本/规则独占一行，手机单列；只读详情以文字/键值展示。
- 表单字段/fieldset、备注等完整区块到操作区默认20px，按钮组内部12px；不得让按钮贴住textarea或相邻卡片边缘。复杂表单用独立操作行，手机换行后保留纵向间距。Field标签/错误的内部间距由组件维护，不通过说明文字或空段落撑开。
- 密码复用 `PasswordInput`，显隐位于输入内部，切换不提交表单；登录/注册/修改密码使用正确 autocomplete。
- 金额、日期、数量、可选值和文本长度由应用 schema 定义；允许清空再输入，客户端不静默夹值或截断。隐藏按钮仍须服务端鉴权。
- 标签采用逐项增删、去重和空白检查；Enter只采用当前标签，IME组合确认不触发表单提交。集合序列化不改变UI的逐项操作方式。

## 列表与卡片的记录操作（D-139）

- 操作列及重复的记录卡片动作使用共享 `RecordActions`：常规操作主色文字、无常驻描边和填充，不将每行都做成一组重按钮。沿企业主色，创作应用沿自身深色主题；不使用多种彩色区分普通动作。
- 通常直接呈现1—2项高频操作。知识文档、报价和客户卡片的低频动作收进“更多”；配置类短动作组可保留直达，不能把唯一的“启用”等操作藏成空操作组。
- 导航和下载保留真实链接、原URL/参数/下载属性；业务写入保留真实按钮、权限、版本、忙碌/禁用及重复提交保护。仅调整显示方式，不能使文字操作绕过原确认或直接提交。
- 删除、作废等危险动作可用危险色文字，但仍保留具体动词、对象和原有后果提示/确认；不能只用红色表达危险，也不能把普通取消都标红。
- 保留文字命中区，桌面最小32px高，窄屏/粗指针最小44px高；键盘焦点清晰，悬停可识别，禁用项不可点击。不得全局改写 `td button` 或通用 `.row-actions`，以免影响行内字段、表单和弹窗的提交按钮。
- “更多”采用共享原生Popover顶层浮层，保留真实按钮/链接及Tab顺序，以有名称的操作组呈现，不冒充未实现方向键语义的menu。入口关联展开状态及浮层ID，名称包含所属记录；无权限选项时不显示空入口，禁用项不能执行。
- 浮层在视口边缘定位，不能被表格横滚容器裁剪；打开聚焦首个可用项，Esc/外部点击关闭。选项打开弹窗后，关闭弹窗应恢复到可见的“更多”入口；页面滚动和视口变化关闭浮层，浮层内部滚动保持展开。

## 查询、排序与分页

D-102正式客户体验基线：

- 列表读取、读取失败、业务空态互斥；失败不能同时显示“还没有记录”、空表头或未经证实的0条。错误附近提供重试，保留筛选范围；权限和登录错误保留其具体含义，写请求不得自动重发。
- 手机优先呈现关键词、主要类型/状态和查询、重置。日期等次要条件可收进“更多筛选”，已填条件数量保持可见；展开状态、控制关系和完整标签可供读屏识别。折叠不清除条件，桌面保留常用条件直达。
- 空集合只出现一份空态，成功无结果与初次无数据分别使用准确文案。无数据不保留空表头/页码；有数据后的真实分页保持可用。
- 弹窗的主要提交放在固定底栏，绑定原表单，保留原生必填校验。失败保留输入和实际ID，新增错误自动进入可见区域并聚焦错误；不把错误留在弹窗背后或看不到的上方。
- 修改表单关闭需保留既定未保存保护；按钮不重复出现取消。归档等有后果的动作先展示影响，按业务契约填写原因，明确确认后执行，默认聚焦安全取消；权限、版本和幂等字段不因视觉优化省略。
- 资源控件保留一个清晰标签及可访问名称，不允许label嵌套或重复读出标签；键盘栏目切换跳过禁用项。实际触屏、读屏和完整对比度验收单独留证。

| 行为 | 契约 |
| --- | --- |
| 多条件查询 | 输入值暂存，点击查询或搜索框Enter一次应用，回第一页 |
| 重置 | 清空当前列表条件并立即恢复默认结果；不清除企业、其他列表或资源待选集合 |
| 页签/类型/时间导航 | 可即时生效，页面适配文档写明；保留仍适用的已应用筛选并重置页码 |
| 查询失败 | 有旧结果时明确“未更新”；没有结果时显示失败与重试，不能显示假零 |
| 分页 | 默认20；跨页保留范围、已应用筛选和排序；有数据时页脚显示总数、页码、上一页/下一页，单页也保留并禁用越界按钮。工具栏无需重复显示同一总数。总数为0时隐藏整个分页区，包括总数、页码和翻页按钮；初始无数据及筛选无结果共用此规则，空态保留必要的原因和下一步 |
| 越界页 | 删除导致页码越界时回到最后有效页；不展示与总数矛盾的空页 |
| 返回现场 | 恢复企业/应用、已应用查询、排序、页码/每页数及合理滚动位置 |
| 导出 | 写明当前页、筛选结果或完整周期；另核对导出权限和字段隐私 |

D-095：每个可增长的记录集合必须分页或采用明确的增量加载；不把接口固定取前100条后再本地切页当作完整分页。服务端按权限和筛选范围先计算总数、再排序和截页，排序增加稳定唯一键；完整的小型数组可用`PagedCollection`在客户端分页，已经由服务端分页的结果不能再次切片。查询/页签/范围变化回第一页，删除或数量减少后回到有效页。表格分页放在横滚容器外，手机按钮至少44px，不被浮层或底栏遮住。

多个列表各自保存状态，查询状态与待提交表单状态分开。URL/sessionStorage可保存非敏感界面条件，不存完整名单、凭据或替代服务端业务数据。

## 选择器

应用切换沿[UI06](06-应用身份与切换.md)：应用胶囊→搜索/最近使用/企业已开通；与业务菜单分开，点击即进入，不套用多选确认。

单值选择器靠近触发点，边缘翻转/收缩；长列表提供搜索。键盘支持方向键、Home/End、Enter/Space、Esc并恢复焦点；手机按场景使用可达面板。

D-096：需要搜索的单选采用一个可输入的复合框，不将常驻搜索框与原生select上下并列。共享`SearchSelect`在同一控件显示选中名称、搜索输入及展开箭头；只有选择候选项才提交实际ID，任意搜索文字不能绕过必填。Esc或离开输入取消搜索并恢复已选名称，清空明确撤销当前选择。方向键移动候选，Enter选择；可编辑文本中的Home/End/Space保留文本编辑语义，IME确认不触发表单提交。分页候选支持加载更多，方向键抵达末项可加载下一页；搜索范围变化重新从第一页加载，保留已有业务筛选和权限边界。

复合框必须保留可见标签、具体可访问名称和aria-required；按combobox/listbox/option表达展开、选中及活动后代，键盘焦点始终可见。加载、无结果与读取失败分别显示，失败可重试且不丢已选值。弹层匹配控件宽度，按可见视口翻转/收缩；弹窗内放入所属dialog，避免被横滚容器裁剪。实现和本地证据见[96](../96-BOM可搜索复合选择框.md)。

D-098：资源单选统一沿上述复合框，包括客户、供应商、商品、单据、商机、成员、部门、仓库、企业、知识空间和渠道等。完整已授权选项用`ChoiceSelect`，服务端分页资源用`EntitySelect`；应用负责真实权限、筛选、状态、版本及联动，不复制搜索框＋select＋独立候选分页。

- 状态、币种、角色、业务类型等少量固定枚举保留原生select；关键词＋状态＋日期等独立查询条件继续分开。多选、授权组合及“全部组织/全部渠道”的语义保持多选，不能套单选后丢掉其余值。
- 选中值始终是实际ID；仅搜索不改变值，取消搜索恢复原名称。选中名称与ID快照分开，两个同名对象之间的切换也须触发修改/未保存保护；只搜索再取消不得误报修改。未加载到名称时保留原ID，不静默采用第一项。
- 远端候选在展开时读取、搜索250ms防抖、每批20条，按ID追加去重；重新展开和查询/对象类型变化从首批开始。保留当前客户、企业、类型及资格条件，不能用客户端显示文字代替服务端条件。数量有限的摘要不冒充全历史集合。
- 切换客户清空原关联商机，切换往来类型清空原对象；多行各自搜索，删除前一行不能丢掉后续行名称或误换ID。缓存只保存当前界面范围的选中名称，不替代重新鉴权和服务端事实。
- 组件和候选各自的禁用状态保留，键盘跳过不可用项。存在后续候选时，当前批次无可选项仍提供加载更多；表单必填、失败保留、金额/库存后果、授权范围和确认流程不能被替换控件时删掉。
- 只保留复合控件外边界，应用样式不得重新给内部文本输入叠一层边框；鼠标/触屏和键盘焦点、手机44px触控及窄屏弹层边界沿公共主题。

本批源码检查、实际适配与验证边界见[98](../98-资源选择与筛选统一优化.md)。

多选打开时复制已采用值为待选集合；搜索/分组/分页不清除勾选，显示已选数量。确认后才写回表单，取消恢复旧值。“本页全选”和“全部结果”明确区分；未实现全部结果选择时不展示该入口。不可用项显示原因，确认时重新核对权限和归属。

上传、选择采用、移除本次引用和删除库内文件分别命名；取消采用不隐式删除上传原件。

## 普通弹窗与确认

- 少量字段用普通560px弹窗，复杂表单可用900px；长流程用独立页面。圆角12px，标题16px居中，左右等宽预留，关闭固定右侧；标题和底部不加装饰横线。
- PC与视口留至少24px，手机至少16px；内容区独立滚动，标题/关闭/提交始终可达。底栏不能覆盖表格分页或最后一项。
- 打开记录触发点，焦点进入模态并限制Tab，背景不可交互；关闭恢复合理焦点。危险确认默认聚焦安全操作，Esc先处理最上层。
- 有修改的表单不通过遮罩隐式丢弃。`Dialog`/`ConfirmDialog`/`ActionPanel`共享现有行为；业务仍负责保存、校验、版本与幂等。
- D-070：表单已有返回/取消等次要动作时，可用`DialogAction replacesClose`移除重复的底部关闭；标题关闭与未保存保护仍有效。不要为默认自动能力增加选择器、成功状态行或重复操作。
- AI使用独立的非模态浮窗/手机全屏契约，见04，不套普通业务弹窗关闭语义。

## 未保存输入与返回

| 能力 | 离开方式 |
| --- | --- |
| 支持真实草稿保存 | “是否保存修改？”：副按钮“不保存”、主按钮“保存”；Esc/关闭留页。保存成功才离开，失败保留输入；不保存不删除旧草稿 |
| 只能完整保存 | “继续编辑/放弃修改并离开”；不提供无效的半成品保存 |
| 文件已上传/批次已提交 | 展示已经保存与尚未提交的范围，关闭展示与取消任务分开 |
| AI输入/工作单 | 按明确的保留能力处理；内存保留、服务器草稿和业务draft分别标记 |

二级页面通过`PageTitle back`传入真实链接/按钮，统一在标题左边显示返回箭头；保留原目标、路由保护、键盘焦点与可访问名称，滚动切换标题位置不能丢失已聚焦的返回入口。不在右侧主操作或表单上方重复放返回。

编辑→详情→列表、子对象→所属资源；页面内返回按逻辑父级，浏览器历史另处理。跨模块来源可以作为可信关联链接，不能导致返回循环或接受任意外部returnUrl。

路由离开、切企业/应用/账号都须处理未保存输入；切换后清空旧范围数据和订阅，丢弃不再匹配范围/版本的异步结果。浏览器刷新/关闭采用实际支持的提示，不承诺销毁前异步保存成功。

## 异步与反馈

### 进度条与分布条

- 所有新应用的原生 `progress` 共用公共主题：8px高度、浅紫轨道、品牌紫填充、两端圆角，无边框、阴影或浏览器默认浮雕。
- 用真实 `value/max` 表达比例，保留可访问名称和相邻实际数值。无数据用真实零值；没有可计算比例的任务不伪造百分比。
- Chromium/WebKit轨道与填充、Firefox填充规则集中在 `packages/frontend/src/theme.css`；应用CSS只负责行列布局，不复制一套轨道样式。当前消费者为CRM经营概览和效果报表，实施/浏览器边界见[55](../55-公共进度条样式优化.md)。

| 状态 | 用户应能理解的结果 |
| --- | --- |
| 加载/提交中 | 保留结构和输入，局部反馈、防重；本地忙碌不等于服务器已收到 |
| 排队/准备/执行 | 来自真实任务阶段，无真实百分比时使用不定进度 |
| 成功 | 以持久化或真实回执为准，给出资源/结果入口 |
| 失败 | 已保存内容、原因和可执行恢复方式；不自动清空或重复写入 |
| 结果未知 | 先查原requestKey/回执，提示待核实，避免换键重试 |
| 无权/已删除/停用 | 停止展示不再授权的数据，提供有权的返回或管理入口 |

字段错误紧邻字段；持续错误使用区块提示；短Toast用于已复制/已保存等短反馈；长期结果进入任务/通知。初次无数据、查询无结果、失败、无权和资源已删除分别呈现。通知已读不代表业务完成。

关闭进度显示层停止该层计时/订阅，后台持久任务按自身生命周期继续；重开读取状态，不重新执行。动画不写业务状态，生成中的文字不等于业务已提交。

## 键盘与可访问性

真实button/a/label、可访问名称和选中/展开状态；焦点可见、顺序合理且不被固定栏遮挡。Tab/Shift+Tab、Enter/Space、Esc、方向键及IME按控件语义处理；非模态AI不圈住整个页面。

状态变化适度播报，不逐token或每秒重复打断。支持长文字、缩放、减少动态效果；关闭非必要动画后仍能识别状态。实际触控、原生手机键盘、辅助技术和颜色对比须分别留证，静态页面不代表通过。


D-071初始焦点：普通弹窗打开后聚焦可编程聚焦的标题，不自动高亮关闭按钮；显式原生autofocus字段保持原行为。危险确认仍默认聚焦安全取消项。鼠标/触屏按钮点击使用原有hover/选中底色，键盘Tab/Shift+Tab仍呈现可见焦点，禁止全局移除键盘轮廓。输入框、文件选择器及应用搜索外框共同继承公共焦点规则。


## D-089：共享读取、只读资料与提交边界

- `useApiData`的path变化代表范围变化；新范围首帧隐藏旧数据，请求版本阻止迟到结果覆盖。读取默认20秒超时并可重试；不可把读取超时策略套到有副作用的写入上重发。
- `DataResult`处理loading/error/reload；失败不同时展示“暂无数据”，成功空态由应用传入。相同范围刷新可保留旧数据并显示更新状态，失败时不冒充成功或真实零值。
- `DetailFacts`使用dl/dt/dd承载只读字段，资料布局不借用输入表单；动作在独立区域，移动端按共享断点重排。
- 写入busy需同步锁补足React状态更新前的窗口，服务端幂等/版本/权限仍不可省略。弹窗实际提交动作使用DialogAction；可选高级字段可折叠，必需字段与错误保持可达。

本批实现、三端发布和已验证范围见[89](../89-上线前全局检查与体验优化.md)。


## 管理端状态与官网能力表述（2026-11-02，D-134）

- 能力交付、企业启用、配置是否存在、执行环境状态分别表达；“未配置”不等于“尚未开通”，配置存在也不能写成模型调用成功。状态读取失败必须显示失败，不降级成未配置。企业自定义大模型沿三字段保存直用，不新增探测按钮。
- 成员、部门、应用、套餐等重复行操作保留简短可见按钮，并在可访问名称中包含对象；确认弹窗主操作明确写出动作，危险操作后果、取消和权限保护保留。
- 订阅、账单和授权的正常空态在所属卡片内简洁展示；读取中、失败和重试不能当作空数据吞掉。应用入口与岗位设置只在应用已交付且启用时显示。
- 官网只展示已实现和已验证的能力。数字员工职责应与所属应用的现有工具、数据和权限一致，角色展示与工作台共用定义；按企业开通，申请入口不承诺自动获得权限。真实生成案例标注虚构品牌，界面图使用隔离测试数据。业务场景的输入、步骤、输出及发布前人工核对直接展示。


## 企业模型与应用数字员工（2026-11-02，D-135）

企业模型按文字、生图、视频三种用途独立配置，复用一个三字段弹窗：模型名称、API地址、密钥；不增加连接测试、额外模式切换或常驻额度。默认与企业自定义来源据实显示，配置存在不等于已验证连通。密钥不回显，恢复默认保留清晰的移除密钥后果。兼容协议及当前入口能力放入命名明确的InfoTip。

应用数字员工复用已有工具与权限；工作台顶栏入口统一为“询问AI”；快捷提问和官网职责共用岗位定义。快捷提问只填入，不自动发送；项目内打开时显示当前项目引用。角色身份通过对话标题和岗位介绍表达，不增加欢迎口号或说明段落。


## 正式客户交付与界面文案复核（2026-11-02，D-136）

适用于官网、业务工作台、企业管理、平台运营，以及ERP、CRM、MES、品牌内容的列表、详情、表单、弹窗、空态、错误和权限状态。按正式客户交付实施和验收，不以Demo或原型作为功能、数据和交互的完成标准。

- 默认只保留业务标题、必要字段、真实数据与状态、清晰的下一步操作。先删冗余标签和说明；清晰度下降时调整分组、视觉层级、间距和按钮动词，不用教学段落或slogan补空白。标题、字段、按钮已经说明的内容不另写一遍。
- 确有信息价值的次要规格、格式、指标口径、兼容协议使用相邻且名称明确的InfoTip；删除无价值文案，不把全部旧文字搬进tooltip。保留键盘、触屏、Esc关闭及焦点恢复。
- 可见表单标签、必填/单位、图标按钮名称、焦点、错误关联及状态播报必须保留。placeholder不替代标签；可访问名称应包含可见操作文字，并补足具体对象，兼顾读屏与语音定位；卡片整体作为链接时，避免把整段图片alt和描述拼成冗长的操作名称。
- 删除、授权、库存/账款影响、费用、未保存内容和未知执行结果等决策信息直接可见，不能藏在tooltip。按钮应让新用户理解操作对象与结果。
- 正式入口不得出现硬编码的Demo、演示系统、MVP、功能占位、假成功、假进度或未经实现的承诺。未配置、未开通、无权限和读取失败分别准确表达，并给出实际可用的下一步；不能将错误画成成功空态。
- 官网优先使用当前产品的实际界面。虚构数据、业务示例及AI生成案例据实标识，不把示意图写成已上线截图，不把合成数据和设计案例写成客户实绩；不为去Demo化删除或改名用户已有的测试业务记录。
- 界面采用客户业务语言，不暴露开发阶段、内部权限戳、测试ID或技术实现作为业务结果。授权范围戳可供后端校验和审计，不能作为“业务记录依据”呈现；真正引用的业务对象、版本、原文与审计回执保留。
- 操作必须落到真实服务和持久化状态；刷新恢复、失败保留输入、重试范围、权限/租户隔离及危险确认按实际能力验收。视觉检查、替身测试、真实模型和生产验收分别记录，不用一类证据代替其他结论。
- 发布前覆盖全部现有页面源码及可访问导航，另检查代表性的填写、失败、空态、危险确认、键盘和手机宽度。报告说明页面/状态覆盖及未验证边界，不把“全页面检查”写成全部角色、全部数据组合或完整读屏认证。

## 真实用户任务与解释文案（D-150）

- 从用户目标检查页面：新企业开始使用、邀请同事、建立业务资料、导入及回读、创作并下载、查看失败并恢复。页面可打开不等于流程闭环。

- 未配置状态只在阻断当前任务时展示。管理员可配置的，链接直达相应设置和用途；无权限的明确联系对象。没有可用方案的面板不堆叠全部禁用的选择器。
