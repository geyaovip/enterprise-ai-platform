| AI展示 | `AiDialog`、`AiProcessView`、ai-dialog.css | 应用Provider、事实、工具、工作单及回执适配 |
| AI交互链 | `AiConversation`、`services`、api/hooks | 核对现有scope和固定ERP逻辑，完成新应用适配再接入 |

## 新应用接入顺序

1. 读取00及本目录01～04，核对现有共享实现和最新项目状态。
2. 编写应用UI适配：使用者、菜单/页面、主要动作、领域状态、权限/范围、异步和字数/批次限制、工作单及回执。
3. 把已有组件、公共缺项和应用专用组件分清。公共缺项更新本规范及共享实现，业务特殊组件由应用维护。
4. 接入可信应用注册、通用身份和导航；验证无ERP的独立应用企业，不复制登录/组织/通知后台。
5. 分别验证功能、权限、浏览器交互、响应式和真实模型/业务效果，记录环境和证据。
6. 申请发布前列出迁移、兼容、共享组件影响、回退与验收范围，保留旧应用。

## 公共变更与例外

基础颜色、字号、断点、Shell、账号/通知和AI外壳统一维护。业务差异优先通过组件参数与应用内容适配；确需改变公共行为时先记录场景、影响和决定，并同步所有消费者。

已有主题/组件不能只为CRM做无条件全局覆盖。改公共组件时覆盖工作台、企业管理、平台运营及已接入业务应用；应用专用表单不因同名自动提升公共模块。版本变化记录于00并同步适配文档，历史验收留存原日期与环境。

## 响应速度与实际操作效率（D-032）

以下是工程优化目标，尚非已达成指标或对外SLA：

| 场景 | 目标 | 测量口径 |
| --- | --- | --- |
| 点击/提交反馈 | 200ms内 | 动作到真实忙碌反馈；提交成功按服务器持久化另计 |
| AI处理进度 | 就绪无拥塞时1秒内 | 与界面反馈和首字分开；本地占位不冒充模型收到请求 |
| 常用列表/详情/筛选 | P95两秒内 | 动作到可读数据，骨架/假零不算完成 |
| 普通AI首字 | P95五秒内 | 点击发送到浏览器绘出首个非空白回答字符，含准备、排队、检索、网络和渲染 |
| 简单AI完整回答/单步辅助 | P95十五秒内 | 完整回答或有效操作预览；写入按独立回执 |
| 文件/批量/多步骤 | 持久任务和真实阶段 | 按数据量/步骤记录完整耗时，不统一承诺十五秒 |

分别记录首次、空闲恢复、连续、成员切换、多人、知识与业务写入场景，报告样本数、P50/P95、最大值和失败率；小样本只报告观察值。用户明确不展示“正在提交消息”作为处理进度。AI首字、首段、完整结束及业务回执分别计时；性能历史样本见 [43](../43-自动运行与工作体验优化.md)，不代替新应用实测。

## 文案密度与可访问性验收（D-093）

- 对照路由清单检查三端、ERP/CRM/MES、登录/引导/邀请、知识/消息/订阅/连接授权、详情/表单/弹窗/打印、公开五页与404；记录源码覆盖和实际浏览器覆盖，不能相互替代。
- 先删冗余文案，再检查标题层级、间距、分组、主操作与按钮结果是否自解释；不要以给每个区块补一句说明通过验收。
- 必要字段标签可见且与控件关联，图标按钮名称具体；placeholder不是唯一标签。数据、单位、校验、错误恢复、读屏名称和状态播报保留。
- 逐项确认删除/不可逆、授权、批量导入、金额/库存变更、未保存离开的后果直接可见。确认弹窗不能只有一个信息图标。
- info提示分别验证键盘Tab/Shift+Tab、Esc、点击/外部关闭、模态内层级及窄屏边缘；hover提示可移入阅读，触屏不能只能长按或hover。浏览器模拟不等同原生触屏/读屏软件验收。
- 公共组件改动检查全部消费者；浏览器报告注明日期、视口、数据来源、截图、通过项与未覆盖项。构建通过不等于生产发布或完整无障碍认证。

## 标题、返回、留白与分页验收（D-095）

D-102补充：手机一级和二级页首次渲染即在顶栏显示唯一H1，内容区无重复标题/占位；分别检查导航和返回、长标题、断点切换。桌面初始内容区及上滑入顶栏继续回归。正式客户体验检查同时覆盖加载失败→重试→成功空态/结果、空表格、长弹窗失败可见性、原生校验、未保存保护及有后果动作确认。范围与本地证据见[102](../102-正式客户界面与交互检查优化.md)。

- 所有业务Shell首屏标题在内容区；上滑越过标题后只显示一个顶栏标题，回顶部恢复且布局不跳动。键盘聚焦返回时滚动，焦点仍可达。
- 二级页返回在标题左边，名称与目标具体；手机隐藏抽屉。返回一级列表后恢复抽屉。修改表单后返回仍触发未保存确认，继续编辑保留输入。
- 检查表单、textarea、预览、提交及卡片间距，至少覆盖桌面、390px与320px；表格横滚不带走分页，不造成整页溢出。
- 用超过两页的数据验证第1页、第二页、尾页实际记录不同、总数正确和边界按钮禁用；检查单页、空态、查询/范围重置及删除越界。服务端权限过滤在count/skip/take之前。
- 完整内存集合用PagedCollection；分页接口用Pager或传pagination，公共usePagedData/usePagedArray负责请求页码与范围重置。不得双重切片；接口固定上限需明确范围或补齐服务端分页。编辑/打印范围不随UI切页缩小。
- D-101：总数为0时，公共Pager不渲染分页区，PagedCollection同步继承；检查初始空列表、筛选无结果及清空后恢复。隐藏分页不跳过有效页归正，后续恢复有数据时仍可正常翻页。
- 本次源码清单、三端构建、隔离服务验证和代表浏览器证据见[95](../95-标题返回间距与列表分页.md)。规范目标与本次已验证状态分开记录。

## 资源单选适配验收（D-098）

- 先区分资源单选、固定枚举、多选及独立筛选，不能按select标签批量改成同一种语义。完整选项中保留禁用值、空值/全部范围和真实change事件；远端资源的查询、总数、稳定排序和权限边界属于API契约。

- 回归对象联动、编辑/来源回填、候选资格、业务版本、提交的实际ID、失败保留、多行搜索和删行后名称。显示名称缓存按当前表单/录入面板及完整接口路径隔离，不能用它当作对象存在或可写的证据。
- 核对模态内候选层、Esc层级、焦点、禁用项、390/320px、单外边框；原生手机输入法、触屏及读屏软件另行验证。实际本地结果与未覆盖项见98。
