# 公共视觉与布局

更新：2026-10-23。适用范围与优先级见 [00](00-公共UI规范.md)。数值来自当前共享主题和自动化运营最终规范；应用引用同一实现。

## 颜色与语义

| 用途 | Token | 值 |
| --- | --- | --- |
| 品牌/主动作 | `--brand` | `#6554D9` |
| 主动作悬停 | `--brand-hover` | `#5543C4` |
| 选中浅底 | `--brand-soft` | `#F0EDFF` |
| 画布/表面 | `--canvas` / `--surface` | `#F6F7FB` / `#FFFFFF` |
| 正文/次级/辅助 | `--text` / `--muted` / `--hint` | `#202535` / `#596174` / `#687185` |
| 分隔边框 | `--border` | `#E3E6EE` |
| 成功/警告/危险 | `--success` / `--warning` / `--danger` | `#187B4D` / `#956000` / `#BF3434` |

输入边界、聚焦和禁用有专用组件规则：普通输入边界当前为 `#A7AFBD`，不把所有边界统一淡化为装饰分隔色。应用使用语义变量，不按 ERP/CRM 分配不同主色。图表可使用可区分的系列色，同时提供名称、单位、窗口及文本数据，不能仅靠颜色解释结果。

普通文字对比目标至少 4.5:1，必要控件边界和大字至少 3:1；目标须在实际背景、状态和字号下测量，不因列出色值就宣称达标。

## 字体、密度与间距

| 内容 | 基线 |
| --- | --- |
| 字体 | 系统中文字体栈：`-apple-system/BlinkMacSystemFont/PingFang SC/Microsoft YaHei/sans-serif`，无额外网络字体依赖 |
| 页面主标题 | 24px / 32px / 600；手机使用共享顶栏的自适应标题规则 |
| 区块/弹窗标题 | 16px / 24px / 600 |
| 正文/PC输入 | 14px，正文约 1.7 行高 |
| 表格正文/字段标签 | 13px；标签字重 500 |
| 辅助说明/表头 | 12px；不将错误或必读内容压成难读小字 |
| 手机主要文本输入 | 16px，验证聚焦、输入法及可见区域 |
| 间距 | 优先 4/8/12/16/20/24/32px，使用组件现有间距 |
| 圆角 | 控件 6px、普通卡片 10px、弹窗/AI浮窗 12px；AI输入与工作单按 04 |

同一页面层级、按钮密度和表格留白一致。长名称、连续英文、金额和状态不能挤掉主要动作。金额和数量比较列右对齐、采用等宽数字，币种/单位来自业务契约；缺失值、真实零值和未加载分开。

## Shell 与页面骨架

- 桌面白色侧栏 224px、顶栏 56px；品牌、企业/应用范围和底部账号可达，导航独立滚动。内容最大宽 1600px，常规桌面内边距沿共享样式的 32px。
- 侧栏呈现分组和当前页面，不增加每个应用独立的顶栏/账号/通知。当前页面只出现一个主标题；`PageTitle` 将标题置于顶栏，页面操作留在内容区。
- 顶栏右侧统一“询问AI”，PC 图标加文字，手机图标。当前入口常驻，权限/服务状态决定内容和可执行性，见 04。
- 手机顶栏的菜单按钮、标题和AI按钮按内容区的同一水平中心线居中；菜单显式使用 `align-self:center`，不能继承旧版靠上对齐。图标尺寸可不同，触控区域仍为44px；安全区另计入顶栏内边距。
- 设置使用左目录、右默认内容；选中项与内容一致。手机使用同一设置分组的自适应菜单，不复制第二套业务状态。
- 菜单、弹窗、历史选择层与通知按共享层级处理。原生 dialog 的 top layer 以浏览器行为为准，不能只提高 z-index。

## 断点与触控

| 视口 | 统一行为 |
| --- | --- |
| ≥960px | 桌面侧栏常显；960–1199px使用共享紧凑留白 |
| 768–959px | 侧栏抽屉；业务内容按宽度换行；AI仍为PC浮窗 |
| ≤767px | 手机顶栏/控件规则，AI全屏；普通业务弹窗受视口限制，不自动全屏 |
| ≤359px | 增加窄屏标题、长内容与操作可达性检查 |

PC主要控件 40px，手机主要输入/按钮/关闭/导航点击区至少44px；图形大小与点击区分开。表格行内低频按钮可采用共享紧凑规则，手机提供足够触控范围。

Grid 使用 `minmax(0,1fr)`，Flex 子项可收缩；确需二维比较的表格在自身容器横滚。主要动作、正文和错误不产生整页横向溢出。固定底栏预留真实高度及 `safe-area`，使用动态可见视口处理输入法。

图标沿已有 Lucide/品牌资产，普通图形约16–20px；图标按钮有可访问名称，装饰图标隐藏于辅助技术。hover、长按和拖拽均提供触控/键盘替代入口。
