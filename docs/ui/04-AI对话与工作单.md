## 标题、历史与新对话

- 标题居中、左右预留88px；标题栏PC最小64px、内边距12px 16px，手机最小60px加安全区。右侧加号和关闭，图标有可访问名称。
- 标题按钮显示“当前标题+下拉箭头”；空会话为“新对话”。长标题单行省略，完整名称可读。
- 历史菜单搜索当前成员有权的企业/应用会话，按今天/昨天/更早分组，显示时间和选中态；PC宽`min(336px,面板宽 - 24px)`，手机`min(320px,面板宽 - 24px)`，底部“新对话”可达。
- 打开历史先处理当前输入，聚焦搜索；空历史与搜索无结果分开。Esc先收历史再回标题，不同时关闭多个工作层。

| 操作 | 结果 |
| --- | --- |
| 从常驻入口打开 | 默认新对话；空白未发送会话不创建服务器记录 |
| 面板已打开再次点入口 | 保留当前对话，避免重复创建/重置 |
| 新建对话 | 保留有能力保留的当前输入与工作单，切空白欢迎区；不删除历史 |
| 选择历史 | 显式恢复有权消息和可恢复状态，重新鉴权；恢复不重跑命令 |
| 关闭 | 关闭显示并恢复入口焦点，已提交任务继续其生命周期；再次打开默认新对话 |
| 切企业/应用/成员 | 处理未保存内容，清除旧范围显示、订阅与缓存，拒绝旧异步结果 |

## 上下文与保留能力

常驻入口不自动读取背景客户、单据或未保存表单。用户显式点击“分析此对象”后，才传递已保存ID/版本并展示引用范围；若支持移除引用，移除后不再进入后续提示。引用、知识与业务事实在发送、恢复、SSE读取和终态重新鉴权。

**三种保存分别管理：**未发送问题、会话工作单、正式业务草稿。保留聊天工作单不能偷偷创建业务任务。保存失败保留在当前工作区并给出真实重试；没有持久化能力时明确说明。

ERP/管理端未发送问题仅在面板生命周期内存保留，刷新前提示；CRM已有独立服务器会话草稿，保存/恢复失败必须提示，不反复展示成功状态，见[CRM14](../crm/14-AI对话框与工作单.md)。该能力不因共享外壳自动复制到MES或其他范围。

## 欢迎、消息与输入

- D-070覆盖D-048旧展示：默认记忆、知识参考与回答路由对日常使用无感，不放勾选、模式选择或常驻成功说明。请求使用auto；业务域按实际能力与权限自动参考知识，两个管理域仍不接知识检索，原偏好和服务端约束不变。
- 会话沿SSE/轮询恢复，无须刷新会话。生成时展示真实阶段；读取完成后不重复方式/步骤计数/工具卡。失败、业务操作参数与回执保留；已展开工作单不重复参数和同义入口，收起后仍能打开。
- 欢迎区共用简短问候“你好，有什么可以帮你？”及少量应用问题；使用本系统品牌，示例不能预填虚假经营数字。
- 输入上方四个快捷操作，应用定义名称/问题/工作单。PC自然宽度排列/换行，手机横向滑动、触控至少44px，不引发整页横滚；点击只准备问题或工作单。
- 用户气泡右对齐并随内容收缩，助手与工作单左对齐；正文换行、长文和依据全文可读。消息区使用自动化运营Demo原始PNG点阵，资源为packages/frontend/src/assets/ai-chat-dots.png，24px素材按12px重复，不能被普通背景规则覆盖。
- PC输入区内边距12px 14px 14px；输入圆角16px、最小高度118px，右下圆形发送按钮，预留空间；手机输入区、关闭及发送可达。
- Enter发送、Shift+Enter换行，IME组合确认不发送；工作单多行字段遵守自己的Enter语义。空白禁用，请求中防重复，失败保留原问题。
- 字数为应用能力参数：当前 ERP/管理端4000字符，CRM目标600字符；前端提示、服务端校验和测试一致，回复及方案正文另按领域契约限制。
- 用户上翻历史不强拉到底部；生成内容按实际增量更新，停止/取消、待核实和失败分开呈现。关闭显示不撤销已提交交易。

## 工作单与执行回执

工作单嵌入消息区，使用正式字段、错误、提交/恢复状态，避免每步跳页。公共外壳PC内边距18px/手机14px/≤360px12px、圆角16px；内部区块16px/手机12px、圆角10px，标题、移除和字段位于边框内。

| 状态 | 展示要求 |
| --- | --- |
| 建议/生成中 | 可编辑内容、事实依据与假设；没有回执时说明尚未保存 |
| 准备采用 | 保护人工输入，替换前显示差异或核对，晚到建议不能覆盖新编辑 |
| 待确认 | 展示全部具体参数、版本、范围和后果；高影响动作明确人工确认 |
| 执行中 | 真实阶段、防重和独立停止动作；确认成功与业务成功分别呈现 |
| 已完成 | 真实对象ID/状态/版本与可访问业务链接；名称、数量、金额等用户可核对 |
| 失败/待核实 | 保留输入和关联，先查原回执，禁止仅换键重复执行 |

工作单与普通页面共用应用schema、权限和业务Service；成功不靠模型自述。后续“继续此操作”恢复原状态，不重新提交。模型原始推理、密钥、内部JSON和无权联系信息不展示。

D-048：新公共对话可根据自然语言生成业务提案，不需预先勾选。请求同时带`allowAction:true,requireConfirmation:true`；服务端将所有提案保存为待确认，不提前写业务对象。待确认工作单自动展示，关键参数和回执直接可读；用户在工作单点一次“确认执行”，不再重复弹相同确认框。确认接口继续核对权限、对象、版本、previewHash和幂等。删除会话/记忆等破坏性操作保留确认。默认生成提案不扩大角色权限，两个管理域仍只读。

## 三端与应用差异

ERP业务助手使用有权ERP事实和受控Tool；企业管理助手仅当前企业管理统计；平台运营助手仅已授权平台聚合统计。两个管理助手均为只读，拒绝业务写入与知识检索参数，运营身份、服务企业与计量边界见 [46](../46-三端AI助手与系统账号注册.md)。

CRM等应用增加自己的Provider、事实、快捷问题与工作单；不沿用ERP对象或管理域权限。通用对话外壳不产生新的默认“万能助手”。

## 实现与验收边界

`AiDialog`为共享外壳；`AiConversation`已有ERP、CRM、MES和两个管理域的独立scope。应用分别拥有事实、工具、权限和会话；后续应用仍需完成自己的接入，不能只复制外壳就宣称业务可用。

检查默认新对话、历史搜索/分组/恢复、快捷操作、长文、IME、关闭/失败保留、继续不重复写、撤权、真实回执和焦点。桌面、767/768边界、390/320px、矮窗、原生手机键盘分别留证；统一验收与性能目标见 [05](05-应用接入与验收.md)。


## 公共记忆管理（D-047）

D-070起，记忆管理位于标题的「对话记录与设置」菜单，日常输入区不常驻管理项；删除会话也进入此菜单并保留确认。使用公共Dialog/TabBar/Field，个人记忆和企业约定分开；普通成员可读企业约定，管理员可维护。类型影响常驻偏好/按需检索，只在管理页保留，新建沿原默认回答偏好，编辑保留原类型。新增/修改/有效期/删除/暂停恢复、空态、加载和冲突仍可管理；触控至少44px，主操作在底部，保留原生校验与未保存保护。

只保存用户明确填写并确认的文字，界面说明范围、后续生效及聊天原文独立保留。正常消息不堆摘要/检索计数，影响结果的降级必须说明；无引用时不反复显示“未引用”提示，不标“永久记住”或保证每条采用。记忆默认启用，无勾选前置步骤；用户可在管理页主动暂停/恢复，暂停控制后续检索，原聊天仍属于历史。个人/企业范围由当前Tab确定，新增时无需再次选择相同范围。公共组件为`AiMemoryPanel`，五个范围共享展示，不混用应用或租户数据。完整数据/删除/检索边界见[50](../50-AI分层记忆与上下文.md)。


## MES接入记录（D-057）

共享AiConversation已增加明确mes scope、制造场景快捷问题、production/bom/plan/order引用与结果返回；复用同一浮窗/手机全屏/记忆/确认外壳。MES Provider提供事实和草稿，未发送输入仅面板内存保留。CRM服务器草稿不因此自动复制到MES。当前本地、浏览器与真实模型边界见[mes/05](../mes/05-实施与验收.md)，不把新增scope视为生产AI已开放。

## 资料整理到表单（D-063）

ERP/CRM/MES业务表单共用AiIntakePanel，与对话浮窗共用主题/Field/Notice/按钮；业务资料输入不是新会话，不自动引入聊天记忆。页面直接展示资料和全部识别明细、匹配状态、未知项及依据，不增加能力勾选。生成不修改表单，采用才回填；已有内容时按钮明确“采用并替换表单”。来源或表单变化使旧结果失效，切企业/应用拒绝晚到结果；失败保留输入。保存沿现有业务表单，不能把“已填入”显示成“已创建”。移动端控件至少44px，结果/长文件名不引发整页横滚。具体字段与日期验收见[63](../63-三应用真实场景与AI提效优化.md)。


D-071初始焦点：AI打开后聚焦面板本身（tabIndex=-1），不自动框住标题按钮；标题按钮按内容宽度居中，展开时使用浅紫底。手机从初始面板按Tab进入首个操作、Shift+Tab进入末项，首末循环；桌面保持非模态语义。关闭恢复入口焦点，菜单Esc返回标题，键盘可见焦点不移除。


## D-076 提示模式

NATIVE_AI_MODEL_ENABLED=false 时保留AI入口和历史；发送仅显示“AI 服务暂未开放，你可以先使用应用内的业务功能。”，不新增会话、任务、模型结果或业务动作。提示出现在消息末尾，隐藏重复欢迎内容。服务端和模型网关均拦截；WorkBuddy受控业务工具单独按连接授权执行。

D-088：公共AiIntakePanel增加明确的本地资料模式，用于MES多文件表格解析；不显示AI不可用提示或调用模型。识别结果可由应用提供受控编辑预览，结果修改后复核状态由应用撤销，表单变化仍阻止旧预览覆盖。其他应用原AI路径保留。具体格式及业务复核见[88](../88-MES图纸与物料清单拆BOM优化.md)。

## D-109：资料原件上下文适配

共享AiIntakePanel可将本次选择的原件上下文交给应用的核对预览；上下文随企业、应用和资料变化清空，不自动写入业务或持久化附件。MES的原图、补行和采用后再核对行为归[应用适配](../mes/04-UI适配.md)，不因此扩大ERP/CRM已有识别范围。实施与本地验证见[109](../109-扫描BOM复核与历史纠错优化.md)。
