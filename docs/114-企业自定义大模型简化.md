## 行为与范围

- 企业管理员在「应用与服务 → 企业自定义大模型」填写模型名称、模型 API 地址、API 密钥后保存。复用原有三个字段和保存操作，不新增页面或配置分支。
- `AiProviderSettings` 中已保存的企业配置是显式配置。读取、直接调用以及传给 Runtime Manager 的型号均按该记录原值执行，不再被 `NATIVE_CHAT_MODEL_ID` 覆盖。历史已保存配置也适用，原加密密钥不变。
- Runtime Manager 的保留 `suite` provider 由显式企业配置生成，各应用及快速/只读 Agent 统一使用该企业配置。平台默认型号、历史 CRM/MES 型号覆盖不再替换它；通用渠道不注入平台供应商的 `thinking` 参数。不依据模型名称推断图片能力。
- 未填写企业配置时，既有运营预配置 profile 与平台默认试用模型策略保持。Runtime policy 从 6 升为 7，沿原有租约与空闲更新规则执行。
- 保存只做现有字段、权限、地址与执行中任务检查，写入加密配置及审计；不调用模型、不自动探测。实际请求的失败沿现有业务错误路径反馈。
- 保留原有 HTTPS、公网域名与服务端允许名单约束，以及企业/岗位权限、业务操作确认、用量计量和每账号累计三次试用规则。本次没有解除这些限制，也不增加让企业自行配置的高级参数。
- 聊天配置不替换知识嵌入、重排或 OCR 独立配置；不修改 WorkBuddy 市场资产、旧应用、业务数据和数据库结构。
