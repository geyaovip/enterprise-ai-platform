用户在D-096生产计划BOM复合框之后，要求检查其他类似筛选/选择框并统一优化。检查工作台、企业管理、平台运营和共享包的原生select定义，区分对象单选、固定枚举、多选及独立列表查询；保留D-093文案密度、D-095标题/返回/间距及既有业务规则。

## 范围与实现

| 类型 | 统一处理 |
| --- | --- |
| ERP单据 | 采购/销售客户或供应商、商品明细、客户下关联商机、报价、商机新建、到账客户、开票合同、退货来源、补货供应商、对账/预收预付及未结账款、期初对象、调拨商品 |
| ERP元数据 | 仓库查看/盘点/调拨/退货/出入库仓库、成员/负责人、流程代理/转交、约定价格客户与商品、列表对象筛选 |
| CRM | 客户档案搜索合并、动态编辑器的资源ID字段、组织/渠道/负责人/目标分群/原记录、渠道与标签规则值；多条件值保留多个独立ID |
| MES | 共用Picker接入远端适配，保留已发布BOM、活跃物料和生产类型等条件；受派人、装配分组统一完整选项选择 |
| 管理/运营 | 部门/上级、知识空间/负责人/授权待选对象、通知所属企业、运营成员、订阅企业、服务套餐 |
| 保留 | 状态、币种、角色、来源类型、少量受支持适配器等枚举；独立关键词/状态/日期筛选；多选协作人、授权组织/渠道组合及审批人复选 |

初始清单有120处原生select定义（含86处动态候选），见[清单](../output/select-unification-20261028/select-inventory.json)。本批统一59处对象选择实现入口，包含动态编辑器和规则值两类条件分支；MES既有Picker另接入同一查询适配。逐项[完整候选](../output/select-unification-20261028/converted-client.json)、[远端候选](../output/select-unification-20261028/converted-remote.json)和[补充入口](../output/select-unification-20261028/coverage.json)记录实际范围。定义数量不是页面数量，动态分支可用于多个业务表单；没有声称逐角色/逐状态全部验收。

- `SearchSelect`统一视觉、标签、combobox语义、禁用/键盘、弹层、清空、错误与必填。
- `ChoiceSelect`处理完整已授权options，保留真实原生change事件、空值/全部语义和禁用候选。原生值快照保留实际ID，不能仅靠显示文字判断是否修改。
- `EntitySelect`处理现有分页API，展开读取、250ms防抖、每批20条、更多追加去重；输入查询不提交ID。关闭取消查询，换查询/类型/范围回首批；来源回填可按受权详情接口取得名称。
- 保留原onChange联动与提交结构。切客户清商机、切往来类型清对象、多行独立搜索、删行后名称缓存、开票合同版本、目标分群预览的ID和版本、保存失败保留均有代表验证。同名对象和仅鼠标选择也触发实际修改；仅搜索取消不误报。
- 内部实际ID快照不显示在界面或读屏树，不改变原来的业务请求字段。输入边界只绘制在外层，避免业务CSS给内部输入重复描边。
- 分群弹窗补齐关闭时的未保存保护；保留原规则、预览、写入权限和确认流程。

运营企业和CRM分群接口原本没有处理搜索词，本批补齐只读搜索、过滤前总数和稳定排序；参数/兼容见[05](05-路由与接口契约.md)。未给客户端扩大可读范围，也未改变业务对象的归属、写入、库存/金额、授权或审批规则。
