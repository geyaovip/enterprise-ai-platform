# ERP 功能追踪矩阵

状态：2026-09-29 的**开发与内部验收追踪清单**。旧功能依据 [13 能力盘点](13-三应用业务能力清单与领域归属.md)、旧 ERP [PRD](../../existing-business-apps/apps/electronics-erp/docs/01-产品需求.md)、[API/服务](../../existing-business-apps/apps/electronics-erp/backend/src/erp.controller.ts)与[Prisma 模型](../../existing-business-apps/apps/electronics-erp/backend/prisma/schema.prisma)；具体新 API 以 [05 路由契约](05-路由与接口契约.md) 为目标；实际验证见 [18 开发与内部验收记录](18-开发与内部验收记录.md)。新子 ID 隶属 [02 功能契约](02-功能与验收契约.md) 的 `ERP-01`～`ERP-07`。

状态中的“本机已验证”仅指本机测试租户中的代码、HTTP、数据库或浏览器流程，不代表真实模型、共享云和首客试用已验收。每行仍需按验收契约补齐最终证据。`Q-002` 表示首客旧数据是否导入尚未确定；它不阻挡空库新建。平台账号不复制旧 ERP 独立账号表。
