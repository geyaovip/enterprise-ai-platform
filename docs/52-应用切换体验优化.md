## 观察与实施

线上 CRM 原侧栏在“当前应用”下平铺 ERP / CRM，后面继续展示业务菜单；ERP 另有 CRM 入口，CRM 还展示 ERP 业务设置，应用与模块缺乏层级。

现已实现公共应用胶囊、独立图标、用途、搜索、最近使用、企业已开通与当前状态；移除混排入口。手机顶栏直接切换，公共服务保留应用上下文，切回恢复上次有权菜单页。契约见[UI06](ui/06-应用身份与切换.md)。

实现：公共 ApplicationSwitcher / CSS / ShellToolbar 插槽，工作台目录与 useApplicationNavigation；侧栏焦点逻辑在 dialog 打开时让位。无数据库迁移、API / Runtime / 模型配置变更，CRM AI 闸门不变。
