2026-10-30，D-126。按用户“线上更新一版吧”的授权，发布D-122独立OCR交叉核验及D-123任务通知、历史与核对暂存。API/Worker和三个前端均已更新，生产合成检查、正式资源核验和浏览器流程通过，测试数据已清理。GLM/Kimi分流保持，Terra仅保留D-124测试结论。

## 已上线的变化

| 能力 | 当前行为 |
| --- | --- |
| 独立OCR交叉核验 | 视觉识别后独立读取序号、数量，与候选比较并显示冲突、疑似漏行或未核验；保留原值，不自动改料、改量或追加模型 |
| 任务通知 | 整理完成、失败、停止时生成本人站内通知，点击直接打开对应任务；完成仍需核对，不表示BOM已经发布 |
| 历史入口 | BOM及整理区可打开本企业本人任务，支持状态筛选、分页和继续核对；读取历史和刷新不重新识别 |
| 核对暂存 | 修改约900毫秒后自动暂存，可跨设备恢复；请求幂等、版本冲突拦截，冲突页面保留当前输入 |
| 来源及复核保护 | 原视觉/OCR来源不能被暂存覆盖；修改数量、物料、单位等仍须重新确认，失效物料或单位变化使核对失效 |

原件及核对暂存沿任务保留7天，已保存BOM来源证据独立保留。暂存适用于已完成后台任务，未提交的本地文件及单独同步“本地整理”结果不属于跨设备暂存范围。站内通知复用现有刷新机制，不新增邮件或系统推送。复杂照片可能没有可靠OCR对齐，“一致”仅指已比较的序号/数量，不证明整行、整表或父子结构正确。

业务规则与限制见[122](122-BOM独立OCR交叉核验.md)、[123](123-BOM任务通知历史与核对暂存.md)和[MES视觉规则](mes/07-BOM视觉识别分流规则.md)。本次未接入Terra，未实现D-125品牌内容工作台，未向WorkBuddy投稿或新增MCP工具。
